= Протоколирование операций {wincl}а

Журнал сообщений {wincl}а предназначен для сбора данных о работе приложения.

Журналирование включается в конфигурационном файле `Navigator.dll.config`.

. В узле `Connection`, создайте атрибут `LogFile=путь_к_файлу_журнала.txt` следующим образом:
+
[source]
----
<configuration>
 ... 
 <navigator>
  <connection LogFile=путь_к_файлу_журнала.txt />
 </navigator> 
</configuration>
----
+
Просмотреть список сообщений можно непосредственно в файле по указанному пути.
