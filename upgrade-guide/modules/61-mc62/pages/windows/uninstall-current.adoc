= Удаление старой версии {dv} 6.1 на Linux

WARNING: Не удаляйте компоненты и конфигурационные файлы модулей с сервера Linux до полного переноса системы и её настроек на новый сервер под управлением Windows.

. Перед удалением сохраните настройки сервера (названия подключенных баз данных, учётные записи сервисов, имена почтовых профилей, настройки производительности сервиса Workflow, и другие), которые можно найти в конфигурационных файлах модулей.
+
При необходимости удалите все установленные компоненты с сервера Linux, следуя инструкции в руководстве по установке на Linux, раздел "xref:dv6@install-linux:ROOT:uninstall.adoc[]", или используя команды ниже. Машина Linux больше не потребуется.
+
[tabs]
====
{os1}::
+
 $ sudo apt-get purge 'docsvision-*'

{os2}::
+
 $ sudo dnf remove 'docsvision-*'

{os3}::
+
 $ sudo apt-get remove 'docsvision-*'
====
+
