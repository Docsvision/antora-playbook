= Удаление {dv} 6.1 с машины Windows

. Удалите все установленные серверные компоненты с машины Windows стандартным образом (используя меню "Установка и удаление программ"), модуль {pl} удаляется в последнюю очередь. Серверные компоненты были необходимы только для работы {cns}, начиная с НО 26.1, настройка системы выполняется с помощью {of-mc}.
+
Перед удалением сохраните настройки сервера (названия подключенных баз данных, учетные записи сервисов, имена почтовых профилей, настройки производительности сервиса Workflow, и другие), которые можно найти в Консоли настройки {dv}.
+
. Перезагрузите компьютер.
. Удалите стандартным образом компоненты {dv} на кластерах и отдельных машинах Windows, например, для модулей "{wf}", "Служба {ws}" и "{mc}"..
. Перезагрузите компьютеры.
