= Мастер настройки БД {dv}

Если на этапе обновления системы рабочие конфигурационные файлы были сохранены, при первом открытии {of-mc} на странице menu:Сервер приложений[Базы данных] отобразится таблица с подключенными базами данных, которые ранее были указаны в конфигурационном файле.

.Таблица "Базы данных" Консоли настройки {dv}
image::dev@mgmtconsole:servers:db-master.png[Таблица "Базы данных" Консоли настройки {dv}]

. Запустите _{mc}_ и перейдите в раздел menu:Серверы[Имя-сервера > Сервер приложений > Базы данных].
+
. Выполните настройку БД с помощью мастера баз данных, запускаемого из таблицы БД:
+
* Обновите текущую БД, см. полную инструкцию: "xref:./db-update.adoc[]".
* Подключите существующую БД, котороуй нет в списке, см. полную инструкцию: "xref:./db-connect.adoc[]".
+
Возможность выбрать БД по умолчанию из {of-mc} становится доступна только после полного завершения обновления, включая "xref:./post-config-server.adoc[]".
+
* Создайте новую базу данных, см. полную инструкцию: "xref:./db-create.adoc[]".

[WARNING]
====
Так как для {mssql} был изменён формат строки подключения к БД на более безопасный, прежде чем начать работать с этими базами, необходимо их отключить и подключить заново, установив флаг `TrustServerCertificate`.

Настоятельно рекомендуется использовать защищённое соединение, настроив {mssql} сервер в соответствии с инструкцией в руководстве по настройке системы, см. подробнее "xref:new-admin-console@engineer:ROOT:create-cert.adoc[]".
====
