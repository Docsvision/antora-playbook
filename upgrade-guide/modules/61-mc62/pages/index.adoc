= Обновление версии 6.1 до НО 26.1

Данный раздел описывает шаги по обновлению системы {dv} с версии 6.1 до Накопительного Обновления 26.1. НО 26.1 позволяет конфигурировать систему из {of-mc} версии 6.2, {mc} становится основным инструмент ом настройки {dv} и заменяет конфигурацию из файлов формата `.json`, а также почти полностью замещает {cns}. {cns} поставляется с комплектом утилит {rk}, {kvr} становится частью комплекта утилит WebClientToolKit, конфигурация DVWebTool производится через WebToolBuilder.
