. Обновите компоненты системы на сервере Linux командами:
+
[tabs]
====
{os1}::
+
[source,subs=attributes]
----
sudo apt-get update
sudo apt-get purge docsvision-externalapi
sudo apt-get install --only-upgrade docsvision-{update}*
----

{os2}::
+
[source,subs=attributes]
----
sudo dnf update docsvision-{update}*
----

{os3}::
+
[source,subs=attributes]
----
sudo apt-get update
sudo apt-get remove docsvision-externalapi
sudo apt-get install --only-upgrade=true docsvision-{update}*
----
====
