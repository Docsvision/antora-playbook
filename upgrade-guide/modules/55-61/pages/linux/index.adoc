= Обновление {dv} 5.5 до версии 6.1 на Linux

.Данный раздел описывает шаги по обновлению системы {dv} с версии 5.5 до версии 6.1 с конфигурацией системы из {of-mc} {mc-cu-mc} в ОС Linux со следующими версиями модулей:

* _{mc}_ {mc-from} до версии {mc-to}.
* _{pl}_ {pl-from} до версии {pl-to}.
* _{bo}_ {bo-from} до версии {bo-to}.
* _{dm}_ {ud-from} до версии {ud-to}.
* _{ad}_ {ad-from} до версии {ad-to}.
* _{wf}_ {wf-from} до версии {wf-to}.
* _{to}_ {to-from} до версии {to-to}.
* _{wincl}_ до версии {win-to}.
* _Служба {ws}_ {worker-from} ("Служба рабочих процессов" в версии 5.5.1) до версии {worker-to}.
+
NOTE: Основная настройка системы производится через {mc}.

+
* Если установлена система {dv} версии 6.1, модули которой нужно обновить, обратитесь к соответствующему разделу инструкции по обновлению системы: "xref:61-mc62:index.adoc[Обновление {dv} 6.1 с {mc} версии {mc-cu-mc}]".
****
