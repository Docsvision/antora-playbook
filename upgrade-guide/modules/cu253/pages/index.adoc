== Требования к обновлению

. Ознакомьтесь со списком требований:
+
* ПО {asp-bundle} обязательно должно быть установлено на всех серверах системы.
* ПО {net-r} обязательно должно быть установлено на машинах Windows и клиентских рабочих местах, использующих DvWebTool и DVSupService, на машине с {pu} и {kvr}, а также в собственных решениях и расширениях для {wc}а. ПО устанавливается автоматически, если подключен репозиторий Microsoft, для Astra Linux 1.7 потребуются xref:update.adoc#astranet[дополнительные настройки].
