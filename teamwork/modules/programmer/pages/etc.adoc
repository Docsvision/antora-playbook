= События, свойства, методы, обработчики

== События

[cols=",",options="header"]
|===
|Имя |Описание

|`cardDropping`
|Отменяемое событие. Происходит после того, как пользователь отпускает карточку над новым столбцом. В параметрах можно указать дополнительные метаданные, которые потом обработать в плагине в переопределении соответствующего метода.

|`cardDroped`
|Обычное событие. Происходит после того, как карточка была перемещена в новый столбец и значение поля успешно изменилось.

|`calculateIndicatorAggregateFunction`
|Обычное событие. Происходит в момент расчёта агрегатных функций для показателей столбца. В обработчике можно реализовать свою логику подсчета для стандартных\кастомных агрегатных функций.

|`createNewCardButtonClick`
|Отменяемое событие. Происходит в момент нажатия кнопки "Создать карточку" в столбце. Через аргументы события можно изменить список доступных видов для создания, а также значение флага `createFirstAvailableKindByType`, значение которого определяет, будет ли отправлен запрос на создание карточки при условии, что список доступных видов для создания пустой.

== Обработчики

Для удобства при создании собственных разметок для карточек на канбан-доске было создано два обработчика, которые позволяют открывать в новой вкладке карточку, из которой вызывается обработчик. Обработчики можно назначить на событие `*При нажатии*` любого необходимого элемента управления в разметке.

[cols=",",options="header"]
|===
|Имя |Описание

|`kanbanBaseHandlers_OpenCardView`
|Открытие карточки на просмотр.

|`kanbanBaseHandlers_OpenCardEdit`
|Открытие карточки на редактирование.


|===
