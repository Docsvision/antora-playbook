= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы пользователей. Справочник открывает возможности создания иерархической структуры номенклатуры дел в разрезе дело-том для создания xref:user:cases.adoc#createCase[дел] и просмотра xref:user:archive-docs.adoc[архивных документов], списанных в дело.

.Представление "Справочника номенклатуры дел"
image::6.1@webclient:layouts:nomenclature-directory.png[Представление "Справочника номенклатуры дел"]

[NOTE]
====
Элемент управления становится доступным только после установки компонентов модуля _{am}_.
====

== Свойства

include::6.1@webclient:layouts:partial$properties.adoc[tags=general]

=== Внешний вид

==== Режим отображения

Настройка отображения дерева номенклатуры дел.

При установке значения _Делопроизводитель_ дерево номенклатуры дел отображается в разрезе год-раздел-дело-том.

При установке значения _Архивист_ дерево номенклатуры дело отображается в разрезе фонд-опись-дело-том.

=== Информация

==== Вид документа для приказа

Вид карточки, который отрывается по нажатию на кнопку *Утвердить приказом*. По умолчанию вид _ОРД_ модуля управления документов.
