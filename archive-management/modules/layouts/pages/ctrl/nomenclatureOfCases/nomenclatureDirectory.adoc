= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы пользователей. Справочник открывает возможности создания иерархической структуры номенклатуры дел в разрезе дело-том для создания xref:user:cases.adoc#buttons[дел] и просмотра xref:user:archive-docs.adoc[архивных документов], списанных в дело.

.Представление "Справочника номенклатуры дел"
image::6.1@webclient:layouts:nomenclature-directory.png[Представление "Справочника номенклатуры дел"]

[NOTE]
====
Элемент управления становится доступным только после установки компонентов модуля _{am}_.
====

=== Внешний вид

// tag::disp[]
==== Режим отображения

.Доступны два значения:
*	Делопроизводитель -- отображает номенклатуру по годам с иерархией Год\Раздел\Дело\Том.
*	Архивариус -- отображает номенклатуру в разрезе архивных фондов с иерархией Фонд\Опись\Дело\Том.

==== Режим отображения дерева

.Доступны три варианта:
*	По умолчанию:
** Для карточек Дела и Раздела: MainInfo\Index + MainInfo\Tittle
** Для карточки тома: MainInfo\Number + MainInfo\Name
** Для карточки фонда: MainInfo\Index + MainInfo\Name
** Для карточки описи: MainInfo\Name
*	Дайджест -- отображает дайджест карточек, из которых построено дерево
*	Строка отображения -- выводится значение поля MainInfo\DisplayString. Поле заполняется автоматически при сохранении карточек "Объекты номенклатуры" или копировании номенклатуры между годами. Заполнение происходит при помощи отчёта `Archive_GenerateDisplayString`. Для изменения значений, записываемых в MainInfo\DisplayString, необходимо модифицировать хранимую процедуру отчёта `dvreport_get_data_\{36c74fe1-7d6a-4e8d-bbfb-2259da0ea3e3}`

WARNING: После установки обновлений модуля свою версию хранимой процедуры необходимо прогрузить повторно.

Данный режим отображения можно использовать, если в заголовках, отображаемых в дереве, необходимо вывести информацию, которая не может быть получена в дайджесте (например, поля связанных с "Объектами номенклатуры карточек").

==== Вид документа для приказа
