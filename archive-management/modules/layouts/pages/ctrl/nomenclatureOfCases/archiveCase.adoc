= Дело

Элемент управления `_Дело_` упразднён для модуля {am} версии {page-version}. Используйте "xref:6.1@webclient:layouts:ctrl/table/dataGridControl.adoc[]".

NOTE: Поиск в рамках ЭУ `_Дело_` осуществляется только по делам и томам в состоянии `Открыто`, а также по делам в состоянии `Закрыто` с активным признаком `_Разрешить списание в закрытое дело_`.
