=== Поведение

==== Включая недоступные для выбора

Флаг дает возможность выбрать вид, у которого в справочнике видов установлен флаг `*Недоступен для выбора*`.

==== Включая недоступные для создания

Флаг дает возможность выбрать вид, у которого в справочнике видов установлен флаг `*Запретить создание вида*`.

=== Ограничения

* ЭУ можно добавить только в виды дочерние к типу _Объекты номенклатуры_.
* В качестве поля в схеме данных можно выбрать поле ссылку на строку вида из справочника видов.
* В качестве поля в схеме данных нельзя выбрать служебные поля: `MainInfo\Kind` и `System\Kind`.
