= Работа с фондами номенклатуры дел

Для рабочего места сотрудника, являющегося архивистом, справочник представляет собой иерархическую структуру. Верхним разделом справочника является системный раздел _Фонд_, являющийся родителем для всех остальных.

Системный раздел может содержать неограниченное количество корневых фондов. Каждый корневой фонд может иметь неограниченное число подфондов первого уровня.

В подфондах первого уровня может быть создано произвольное количество подфондов следующих уровней. Глубина вложенности не ограниченная.

[#new]
== Создать новый фонд номенклатуры дел

Фонды создаются в состоянии `Проект`.

.Чтобы создать фонд:
. Установите фокус на системном фонде или на фонде, к которому необходимо создать подфонд
. Выберите один из доступных способов создания:
+
include::6.1@webclient:user:partial$excerpts.adoc[tags=createMethods]
+
. Заполните <<fields,поля>> нового фонда.
. Создайте желаемое количество фондов.
. Создавайте подфонды, повторяя шаги 1-3. Создать подфонд можно при помощи элемента управления image:6.1@webclient:user:buttons/blue-plus.png[Плюс в круге] или из пункта Создать фонд контекстного меню.
. Создавайте дочерние фонды до получения желаемой иерархической структуры.

[#edit]
== Изменение фонда номенклатуры дел

После создания фонд справочника может быть изменен при наличии соответствующих прав доступа.

.Чтобы отредактировать фонд:
. Выберите фонд номенклатуры дел, который нужно изменить.
. Измените фонд одним из доступных способов:
+
include::partial$excerpts.adoc[tags=edit-methods]
+
. Измените <<fields,поля>> фонда.
. Сохраните изменения, нажав кнопку *Сохранить*.

[#delete]
== Удаление фонда номенклатуры дел

Удаление возможно только при наличии соответствующих xref:security.adoc[прав доступа].

WARNING: Фонды удаляются со всеми дочерними элементами, включая описи, дела и тома. При удалении дела или тома, списанные в него архивные документы, не удаляются. Если в архивном документе была ссылка на дело или том, такая ссылка будет удалена.

.Чтобы удалить фонд справочника:
. Выберите фонд номенклатуры, который нужно удалить.
. Выберите в контекстном меню раздела пункт Удалить.
. Появится предупреждение, подтвердите действие кнопкой *ОК*.

[#digest]
== Дайджест фонда

При сохранении карточки фонда ей присваивается дайджест. Дайджест
формируется по следующему правилу

 <номер> <наименование>

* <номер> - значение поля _Номер_ карточки фонда
* <наименование> - значение поля _Наименование_ карточки фонда

[#buttons]
== Кнопки фонда

Для карточки фонда кнопок не предусмотрено.
