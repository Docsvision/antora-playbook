= Работа с томами номенклатуры дел

Тома могут быть созданы только в делах. Тома могут быть созданы в неограниченных количествах.

Создание доступно в рабочем месте сотрудника, не являющегося архивистом.

Посмотреть информацию о томе можно установив фокус на нем: в правой части экрана отобразится информация, указанная в выбранном томе, включая вкладку _Документы, списанные в дело_. На вкладке _Документы, списанные в дело_, отображаются карточки архивных документов.

[#new]
== Создать новый том номенклатуры дел

Тома создаются в состоянии `Проект`.

.Чтобы создать новый том:
. Выберите дело для создания тома;
. Выберите один из доступных способов для создания:
+
include::6.1@webclient:user:partial$excerpts.adoc[tags=createMethods]
+
. Заполните поля карточки тома, затем нажмите *Создать*.

.Окно создания нового тома
image::new-book-window.png[Окно создания нового тома]

[#edit]
== Изменение тома

После создания тома, его можно редактировать при наличии соответствующих
xref:security.adoc[прав доступа].

.Чтобы изменить том:
. Выберите раздел, в котором хранится дело
. Выберите дело, в котором хранится том
. Выберите том, вызовите контекстное меню
. Выберите *Редактировать*
. Измените <<fields,поля>> карточки тома

[#delete]
== Удаление тома

Удаление возможно только при наличии соответствующих xref:security.adoc[прав доступа].

.Чтобы удалить том:
. Выберите раздел, в котором хранится дело
. Выберите дело, в котором хранится том
. Выберите том, вызовите контекстное меню
. Выберите *Удалить*

WARNING: При удалении тома, списанные в него документы, не удаляются. Если в
документе была ссылка на том, такая ссылка будет удалена.

|Состояние |Состояние |Да |Нет |Текущее состояние карточки тома. При создании состояние `Проект`.

.Необходимо для отображения состояния тома дела номенклатуры дел:
* Если состояние `Проект`, то номенклатура дел еще не утверждена или не открыта, списывать документы в том дела номенклатуры дел нельзя.
* Если состояние `Открыто`, то номенклатура дел утверждена и открыта. В том дела номенклатуры можно списывать документы.
* Если состояние `Закрыто`, то делопроизводство по документам тома дела завершено. Списывать документы в том дела нельзя.
* Если состояние `В архиве`, то том дела с документами переданы в архив организации и находятся на архивном хранении в архиве организации.

Значение колонки заполняется в соответствии со следующим правилом:

* Осуществляется поиск карточки архивного документа, у которой в поле _Дело_ указан системный идентификатор на текущую карточку тома
* Если по результатам поиска карточка архивного документа будет найдена, то необходимо получить значение поля _Тема_ найденной карточки архивного документа и вывести его в текущую колонку
* Если по результатам поиска подходящая карточка архивного документа не будет найдена, то в текущую колонку ничего не выводится

* Если по результатам поиска карточка архивного документа будет найдена, то необходимо получить значения полей из схемы данных _Кол-во листов_ в карточке документа и значение поля _Кол-во листов в приложении_ в карточке архивного документа (Стандартные поля в схеме данных карточки документа), просуммировать их и вывести его в текущую колонку
* Если по результатам поиска подходящая карточка архивного документа не будет найдена, то в текущую колонку ничего не выводится

[#states]
== Жизненный цикл карточки вида "Том"

Жизненный цикл карточек в процессе работы определяется автоматом состояний:

. Проект -- начальное состояние карточки _Том_
. Открыто
. Закрыто
. В архиве
+
Изменение состояний выполняется по приведенной схеме.
+
.Автомат состояний карточки "Том"
image::ROOT:buttons-book.png[Автомат состояний карточки "Том"]

[#digest]
== Дайджест тома

При сохранении карточки тома ей присваивается дайджест. Дайджест формируется по следующему правилу

 <№> <заголовок тома>

* <№> -- значение поля _№_ карточки тома
* <заголовок тома> -- значение поля _Заголовок тома_ карточки тома

[#buttons]
== Кнопки тома

Для карточки тома настроены кнопки *Открыть*, *Закрыть* и *В архиве*,
позволяющие перевести дело в другое состояние. В зависимости от текущего <<states,состояния тома>> и xref:security.adoc[настроек безопасности], кнопки перевода дела в другое состояние могут быть недоступны пользователю.

Закрытие тома информирует о невозможности списания в него документов.
