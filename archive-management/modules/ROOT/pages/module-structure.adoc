= Структура модуля

Модуль _{am}_ включает следующие серверные компоненты:

. Библиотека карточек _{am}_, включающая карточки:
+
* Номенклатура дел
* Раздел
* Архивное дело
* Том
* Фонд
* Опись
* Архивный документ
+
. Загружаемые в справочники {dv} настройки:
+
* В Справочник видов карточек:
** Базовый вид карточки _Объекты номенклатуры дел_
*** Дочерний вид карточки _Раздел_
*** Дочерний вид карточки _Архивное дело_
*** Дочерний вид карточки _Архивное дело_
*** Дочерний вид _Фонд_
*** Дочерний вид _Опись_
** Базовый объект карточки _Архивный документ_
* В Конструктор состояний:
** Автомат состояний карточки _Раздел_
** Автомат состояний карточки _Архивное дело_
** Автомат состояний карточки _Архивное дело_
** Автомат состояний карточки _Фонд_
** Автомат состояний карточки _Опись_
* В Конструктор ролей:
** Стандартная роль "Ответственный" для карточки _Раздел_.
** Стандартная роль "Все" для карточки _Раздел_.
** Стандартная роль _Архивариус_ для карточки _Раздел_.
** Стандартная роль "Сотрудник подразделения" для карточки _Раздел_.
** Стандартная роль "Ответственный" для карточки _Архивное дело_.
** Стандартная роль _Архивариус_ для карточки _Архивное дело_.
** Стандартная роль "Все" для карточки _Архивное дело_.
** Стандартная роль "Ответственный" для карточки _Архивное дело_.
** Стандартная роль _Архивариус_ для карточки _Архивное дело_.
** Стандартная роль "Все" для карточки _Архивное дело_.
** Стандартная роль _Архивариус_ для карточки _Фонд_.
** Стандартная роль _Архивариус_ для карточки _Опись_.
** Стандартная роль _Архивариус_ для карточки _Архивный документ_.

[#roles]
== Роли сотрудников

Для настройки ролевой безопасности модуля _{am}_ предоставляются следующие ролиfootnote:[Администратором могут быть созданы дополнительные роли.], которые ограничивают права на выполнение операций с карточками определенных видов:

. Карточка вида «Раздел». Для карточки настроены роли:
.. _Архивариус_ (А) -- сотрудник, который состоит в группе _Архивариусы_
справочника сотрудников
.. _Ответственный_ (О) -- сотрудники, указанные в поле "Ответственные"
карточки раздела
.. _Сотрудник подразделения_ (СП) -- я в подразделении из поля
"Ответственное подразделение"
.. _Системная для WF_ -- стандартная системная роль. Должны быть даны все
права на все действия во всех состояниях (далее в матрице не описана)

.Ролевой доступ настроен согласно матрице доступа:
[cols="25%,25%,25%,25%",options="header"]

|Удаление карточки |О, А |- |-
|Чтение карточки |О, А |О, А, СП |А, О, СП
|Утвердить |А |- |-
|Закрыть |- |О, А |-
|Вернуть в проект |- |О, А |-

[#links]
=== Связи

* Связь с годом номенклатуры происходит через menu:MainInfo[InitialYearNomenclature].
* Связь подразделов/разделов с родительским разделом происходит через поле menu:MainInfo[ParentPartition].
* Связь разделов/подразделов с делами через секцию menu:PartitionsCase[]. Дело может быть связано с несколькими разделами.
* Связь томов с делами через поле menu:MainInfo[ParentCase].
* Связь фондов/подфондов с родительским фондом происходит через поле menu:MainInfo[ParentFund].
* Связь фондов/подфондов с родительским фондом происходит через поле menu:MainInfo[ParentFund].
* Связь описей с делами происходит через поле menu:MainInfo[ParentInventory].
