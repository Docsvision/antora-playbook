= Руководство разработчика Docsvision AI

Библиотека `DocsVision.AI.API` предназначена для упрощенной работы с AI API. Она инкапсулирует HTTP-взаимодействие, сериализацию/десериализацию моделей, работу с файлами, маскировкой данных, транскрибированием, чатом и озвучиванием текста.

Основной класс для работы с API -- AiClient.

.Библиотека автоматически:
* Подключается к API по настройкам из `ai.config`;
* Настраивает HttpClient, добавляет ключ авторизации;
* Работает с multipart/form-data для передачи файлов;
* Поддерживает асинхронные операции;
* Поддерживает режим маскировки персональных данных.

.Обязательные параметры `ai.config`:
* AiAddressECM -- адрес API;
* AiApiKeyECM -- ключ авторизации;
* AiServiceECM -- алиас AI сервиса по умолчанию.

.Пример создания клиента:
 AiClient client = new AiClient();
