Предоставляет свойства и методы для регистрации базового расширения аутентификации

* *Пространство имён:* `xref:Platform:Authentication/Authentication_NS.adoc[DocsVision.Platform.Authentication]`
* *Сборка:* `DocsVision.Authentication.dll`

== Синтаксис

[source,csharp]
----
public interface IRootAuthenticationExtension : IAuthenticationExtension

== Методы

[cols="60,40",options="header"]
|===

|`GetSettingsType<T>(AuthenticationExtensionType)`

.Параметры:
* `extensionType` -- тип расширения аутентификации

*Возвращаемое значение*: `Type`-- тип настроек

|`GetSettings<T>(AuthenticationExtensionType)`
a|Получает настройки определённого типа

.Параметры:
* `extensionType` -- тип расширения аутентификации

*Возвращаемое значение*: `T` -- настройки определённого типа

|`GetExtensionType(AuthenticationExtensionType)`
a|Получает тип расширения

.Параметры:
* `extensionType` -- тип расширения аутентификации

*Возвращаемое значение*: `Type`-- тип расширения
