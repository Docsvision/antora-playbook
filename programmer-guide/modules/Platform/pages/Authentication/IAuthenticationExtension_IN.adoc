= IAuthenticationExtension -- интерфейс

Предоставляет методы для провайдеров аутентификации, работающих по схеме

* *Пространство имён:* `xref:Platform:Authentication/Authentication_NS.adoc[DocsVision.Platform.Authentication]`
* *Сборка:* `DocsVision.Authentication.dll`

== Синтаксис

[source,csharp]
----
public interface IAuthenticationExtension
----

== Свойства

[cols="60,40",options="header"]
|===
|Имя |Описание

|`InstanceId`
|Идентификатор экземпляра провайдера

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.guid.aspx[System.Guid]`

|`Name`
|Имя расширения

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`Type`
|Тип расширения аутентификации

*Тип*: `xref:Platform:Authentication/AuthenticationExtensionType_EN.adoc[AuthenticationExtensionType]`

|`CommonSettings`
|Общие глобальные настройки аутентификации

*Тип*: `xref:Platform:Authentication/Settings/AuthenticationSettings_CL.adoc[AuthenticationSettings]`

|`ExtensionSettings`
|Специфичные настройки расширения

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`LocalSettings`
|Специфичные локальные настройки

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|===

== Методы

[cols="60,40",options="header"]
|===
|Имя |Описание

|`Initialize(Guid, string, string, string)`
a|Инициализирует интерфейс с заданными параметрами

.Параметры:
* `instanceId` -- идентификатор экземпляра провайдера
* `commonSettings` -- общие глобальные настройки аутентификации
* `extensionSettings` -- специфичные настройки расширения
* `localSettings` -- специфичные локальные настройки

|===
