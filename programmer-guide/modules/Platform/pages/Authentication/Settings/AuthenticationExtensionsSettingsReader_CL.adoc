= AuthenticationExtensionsSettingsReader -- класс

Предоставляет глобальные методы чтения и записи настроек аутентификации, всех экземпляров расширений для всех тенантов

* *Пространство имён:* `xref:Platform:Authentication/Settings/Settings_NS.adoc[DocsVision.Platform.Authentication.Settings]`
* *Сборка:* `DocsVision.Authentication.dll`

== Синтаксис

[source,csharp]
----
public class AuthenticationExtensionsSettingsReader : IAuthenticationExtensionsSettingsReader
----

== Методы

[cols="60,40",options="header"]
|===
|Имя |Описание

|`GetAuthenticationExtensionSettings(Guid)`
a|Получает настройки конкретного расширения аутентификации по его GUID

.Параметры:
* `id` -- идентификатор расширения аутентификации

*Возвращаемое значение*: `xref:Platform:Authentication/Settings/AuthenticationExtensionSettings_CL.adoc[AuthenticationExtensionSettings]` -- настройки расширения аутентификации

|`GetSettings()`
a|Получает глобальные настройки всех расширений аутентификации

*Возвращаемое значение*: `xref:Platform:Authentication/Settings/AuthenticationExtensionSettings_CL.adoc[AuthenticationExtensionSettings]` -- настройки расширения аутентификации

|`GetTenantAuthenticationExtensionSettings(string)`
a|Получает настройки расширения аутентификации для конкретного тенанта

.Параметры:
* `tenant` -- тенант

*Возвращаемое значение*: `IEnumerable<xref:Platform:Authentication/Settings/AuthenticationExtensionSettings_CL.adoc[AuthenticationExtensionSettings]>` -- список настроек расширения аутентификации

|`SetAuthenticationExtensionSettings(AuthenticationExtensionSettings)`
a|Задаёт расширения аутентификации для тенанта

.Параметры:
* `settings` -- настройки расширения аутентификации

|`SetTenantAuthenticationExtensions(TenantAuthenticationSettings)`
a|Задаёт расширение аутентификации для тенанта

.Параметры:
* `settings` -- настройки расширения аутентификации

|===
