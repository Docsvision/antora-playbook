= OpenIDConnectSettings -- класс

Описывает настройки подключения для расширения OpenID

* *Пространство имён:* `xref:Platform:Authentication/OpenIDConnect/OpenIDConnect_NS.adoc[DocsVision.Platform.Authentication.OpenIDConnect]`
* *Сборка:* `DocsVision.Authentication.dll`

== Синтаксис

[source,csharp]
----
public class OpenIDConnectSettings
----

== Свойства

[cols="60,40",options="header"]
|===
|Имя |Описание

|`WellKnownConfigurationUrl`
|URL публичной конфигурации OpenID

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`ClientId`
|Идентификатор клиента приложения, в котором производится привязка пользователей

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`Secret`
|Секрет приложения

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`AccountNameClaim`
|Имя пользователя для запроса при авторизации

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`LoginHintClaim`
|Подсказка к логину из информации для входа пользователя

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`UniqueIdClaim`
|Неизменяемый идентификатор пользователя, запрашиваемый при авторизации

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.string.aspx[System.String]`

|`TraceErrors`
|Ошибки отладки

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.boolean.aspx[System.Boolean]`

|`TracePI`
|Позволяется ли включать персональную информацию в отладке

*Тип*: `http://msdn.microsoft.com/ru-ru/library/system.boolean.aspx[System.Boolean]`

|===
