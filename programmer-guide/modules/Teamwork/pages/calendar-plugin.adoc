= Расширение ЭУ "Календарь" с помощью плагина

Для создания своего источника данных календаря необходимо реализовать интерфейс `ICalendarDataPlugin`.

. `Name` -- название плагина, котороу нужно будет указать в параметрах ЭУ
. `GetCalendarData` -- метод получения данных каледаря
. `UpdateEvent` -- метод изменения данных события
. `DeleteEvent` -- метод удаления события
. `AddEvent` -- метод создания нового события
. `UpdateDayType` -- метод изменения типа дня

Реализованный класс необходимо зарегистрировать в методе `InitializeContainer` серверного расширения следующим образом:

 containerBuilder.RegisterType<MyCustomCalendarDataPlugin>().As<ICalendarDataPlugin>().SingleInstance();
