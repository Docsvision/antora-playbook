= Добавление элемента управления "Дело" в карточку

Установка компонентов модуля _{am}_ открывает возможность работы со справочником номенклатуры дел. Перед работой со справочником необходимо выполнить настройку программы {kvr} и карточек вида _Документ_.

* Для модуля {am} 6.1 используется ЭУ `_Дело_`, см. документацию модуля {am} 6.1: "xref:6.1@archivemgmt:layouts:guide-add-case-control.adoc[]".
* Для модуля {am} {mc-cu-mc} и выше используется ЭУ `_Контрол табличных данных_`, см. документацию модуля {am} 6.2: "xref:layouts:ctrl/table/dataGridControl.adoc[]".
