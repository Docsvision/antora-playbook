= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы администраторов. Справочник открывает возможности создания иерархической структуры разделов для xref:archivemgmt:user:cases.adoc#createCase[создания] дел и списания документов в дело при помощи ЭУ "xref:6.1@archivemgmt:layouts:guide-add-case-control.adoc[Дело]" (только для 6.1) или ЭУ "xref:layouts:ctrl/table/dataGridControl.adoc[]" (для 6.2 и выше), просмотра документов, списанных в дело, см. подробнее "xref:archivemgmt:layouts:ctrl/nomenclatureOfCases/nomenclatureDirectory.adoc[]".
