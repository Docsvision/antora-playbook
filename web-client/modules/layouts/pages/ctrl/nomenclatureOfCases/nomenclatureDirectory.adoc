= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы администраторов. Справочник открывает возможности создания иерархической структуры разделов для xref:6.1@archivemgmt:user:cases.adoc#createCase[создания] дел и xref:6.1@archivemgmt:layouts:guide-add-case-control.adoc[списания] документов в дело, просмотра документов, списанных в дело, см. подробнее "xref:6.1@archivemgmt:layouts:ctrl/nomenclatureOfCases/nomenclatureDirectory.adoc[]".
