= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы администраторов. Справочник открывает возможности создания иерархической структуры разделов для создания дел и списания документов в дело при помощи ЭУ `_Дело_`, просмотра документов, списанных в дело, см. подробнее в документации модуля {am}:

* 5.5.2: "xref:5.5.2@archivemgmt:layouts:ctrl/nomenclatureOfCases/nomenclatureDirectory.adoc[]"
