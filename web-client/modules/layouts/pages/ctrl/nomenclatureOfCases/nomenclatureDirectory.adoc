= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы администраторов. Справочник открывает возможности создания иерархической структуры разделов для xref:archivemgmt:user:cases.adoc#createCase[создания] дел и xref:archivemgmt:layouts:guide-add-case-control.adoc[списания] документов в дело, просмотра документов, списанных в дело, см. подробнее "xref:archivemgmt:layouts:ctrl/nomenclatureOfCases/nomenclatureDirectory.adoc[]".
