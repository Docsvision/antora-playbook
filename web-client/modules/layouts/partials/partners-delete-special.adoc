== Особенность удаления записей из Справочника контрагентов

Запись будет удалена от имени текущего пользователя, если пользователь после добавления записи в Справочник контрагентов откажется от сохранения изменений.

Удаление будет произведено, только если у текущего пользователя есть права на удаление.

Запись будет удалена от имени учётной записи {wc}а, если у пользователя нет прав на удаление записей из Справочника контрагентов.

Если нужно запретить удаление записей для УЗ {wc}а, запретите данную операцию для системной учётной записи в настройках дискреционной безопасности Справочника контрагентов.
