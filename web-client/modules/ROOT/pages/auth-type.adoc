= Поддерживаемые способы аутентификации

{wc} поддерживает аутентификацию Basic и xref:admin:use-kerberos.adoc[Kerberos], аутентификация с помощью xref:user:prepare-authenticate.adoc#extensions[расширений аутентификации]. Другие способы аутентификации не поддерживаются.

WARNING: NTLM-аутентификация не поддерживается в {dv} версии 6.1.
