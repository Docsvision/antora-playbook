= Сведения о составных частях модуля

Модуль {wc} представлен следующими компонентами:

* Служба {wc}а и основные сборки, необходимые для работы модуля.
* Схемы метаданных для хранения в БД.
* Общие сборки {wc}а, необходимые для взаимодействия с другими модулями.
* Комплект утилит {dv} {wc} Toolkit поставляет программу _{kvr}_, предназначенную для настройки разметок (интерфейса пользователя) {wc}а. Также включает утилиту xref:admin:webservices-install.adoc[WebToolBuilder], предназначенную для сборки и настройки _DVWebTool_. _DVWebTool_ позволяет пользователям {wc}а открывать файлы в офисном редакторе и сканировать документы на  компьютерах с ОС Windows.
* DvSupService -- выполняет в ОС Linux функции, аналогичные _DVWebTool_. Утилита не входит в состав "{wc} Toolkit" и устанавливается на клиентские компьютеры Linux отдельно.
