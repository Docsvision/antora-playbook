= Перенос срока исполнения задания

Для заданий "{dm}" в {wc}е версии {wc-change-deadline-req} поддерживается перенос срока исполнения задания. Исполнитель задания может создать запрос на перенос срока.
Инициатор задания увидит запрос в карточке задания и сможет его обработать.

Вся информация о запросе на перенос для задания и работе с ним записывается в секции _Обсуждение_.

Существующая операция "xref:documentmgmt:user:tasks/manage-launched.adoc#change-deadline[Изменение срока исполнения]" работает в прежнем режиме и в дополнение используется при обработке активного запроса.

WARNING: Перенос срока исполнения задания доступен {dm}. Логика работы заданий {ad} остаётся прежней.

[#request]
== Запрос на перенос срока

.Чтобы создать запрос на перенос срока исполнения:
. Нажмите на ленте задания кнопку *Запрос изменения срока*. Откроется боковая панель _Запрос изменения срока_.
+
NOTE: Кнопка может быть недоступна из-за настроек ролевой модели или параметров разметок.
+
.Панель запроса на изменение срока исполнения
image::deadline-request-bar.png[Панель запроса на изменение срока исполнения]
+
. Ознакомьтесь с действующим сроком исполнения задания в поле _Текущий срок исполнения_.
+
Срок может быть отсутствовать, если он не обозначен в задании.
+
. Укажите новый срок исполнения в поле _Запрашиваемая дата переноса_.
+
Обязательное для заполнения поле по умолчанию отображает текущий срок исполнения. Если текущий срок не задан, будет отображаться текст `Запрашиваемая дата переноса`.
+
. Укажите комментарий в поле _Причина переноса_.
. Нажмите кнопку *Запросить*, чтобы создать запрос на перенос срока или обновить существующий запрос.
+
Нажатие кнопки *Отмена* закроет панель без сохранения внесённых изменений.
+
. Исполнитель может отозвать собственный запрос при помощи кнопки *Отозвать* в элементе управления запроса.

[#handling]
== Работа с запросом на перенос

Созданный исполнителем запрос на перенос срока отображается в карточке инициатора. Инициатор может подтвердить или отклонить запрос.

.Отображение запроса на перенос срока исполнения в карточке
image::request-deadline-handling.png[Отображение запроса на перенос срока исполнения в карточке]

Запрос отображается, только когда в задании был запрошен перенос срока и он находится в статусе _Активен_. В остальных случаях запрос скрыт.

Запрос отображается отдельным элементом управления разметки под лентой карточки в виде текста на жёлтом фоне. В элементе управления представлена вся информация о запросе, включая исполнителя, запросившего перенос срока, запрошенный срок, комментарий исполнителя. Если текст комментария не помещается в одну строку, он будет сокращён. При наведении курсора на сокращённую строку будет отображён полный текст комментария. В правой части элемента управления отображаются две кнопки для принятия решения о переносе срока исполнения: *Принять* и *Отклонить*.

Нажатие на кнопку *Принять* принимает запрос и устанавливает новый срок исполнения.

Нажатие кнопки *Отклонить* отменяет запрос и оставляет срок исполнения неизменным.

После принятия или отклонения запроса панель элемента управления с информацией будет скрыта.

Если инициатор не согласен с запрашиваемым сроком, он вправе отклонить запрос на изменение срока исполнения задания и перенести дату самостоятельно при помощи существующей в {dm} команды на ленте карточки -- "xref:documentmgmt:user:tasks/manage-launched.adoc#change-deadline[Изменение срока исполнения]".

[#info]
== Информация о переносе сроков

При создании, обновлении, принятии, отклонении и отзыве запроса переноса срока исполнения информация о запросе автоматически добавляется в блок _Обсуждение_ карточки задания.

.Информация о запросе на перенос сроков исполнения в блоке "Обсуждение"
image::deadline-comments.png[Информация о запросе на перенос сроков исполнения в блоке "Обсуждение"]

Для запросов на перенос срока исполнения кнопки редактирования и удаления отображаются только пользователям, имеющим права на изменение и удаление любого комментария. Если сотруднику доступно только изменение или удаление собственного комментария, кнопки изменения и удаления не отображаются, даже если комментарий создан от имени этого сотрудника.

Комментарий добавляется, даже если у сотрудника отсутствуют права на его добавление. При изменении срока исполнения с помощью операции "xref:documentmgmt:user:tasks/manage-launched.adoc#change-deadline[Изменение срока исполнения]", отдельный комментарий в блоке _Обсуждение_ не добавится.
