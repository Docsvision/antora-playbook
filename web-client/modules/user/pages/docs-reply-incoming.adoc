= Создать исходящий документ в ответ на входящий

.Чтобы создать исходящий документ в ответ на входящий, выполните следующие действия:
. Откройте карточку вида _Входящий_ в xref:5.5.17@webclient:user:cards-open-modes.adoc#read-mode[режиме чтения].
. На xref:5.5.17@webclient:user:cards-terms.adoc#cards-operations[панели операций] нажмите кнопку *Создать исходящий*. Будет открыта новая карточка исходящего документа.
+
****
Часть данных карточки будет заполнена данными из входящего документа.
****
+
. Заполните xref:5.5.17@webclient:user:docs-fields-outgoing.adoc[поля] карточки и сохраните изменения.
+
****
Созданная карточка будет добавлена в список ссылок в разделе _Ссылки_.
****
