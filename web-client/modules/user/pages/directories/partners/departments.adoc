= Работа с подразделениями контрагента

В справочнике контрагентов реализована возможность создания подразделений организаций. Каждая организация может иметь неограниченное количество подразделений. Подразделения являются составной частью организаций и не могут быть созданы вне организации.

[#info]
== Посмотреть информацию о подразделении

Основная информация о выбранной организации или подразделении контрагента доступна в правой области справочника, во вкладке _Информация_. Полную информацию можно посмотреть, выбрав пункт _Информация_ в контекстном меню.

== Изменить подразделение

.Чтобы отредактировать ранее созданный узел подразделения:
. На вкладке *Организации* в левой области справочника выберите узел из иерархического списка.
. Выберите Подразделение.
include::partial$excerpts.adoc[tags=editMethods]
. Измените необходимые <<fields,поля>> и нажмите *Сохранить*.

[#delete]
== Удалить подразделение

.Чтобы удалить ранее созданный узел подразделения:
. На вкладке _Организации_ в левой области справочника выберите узел из иерархического списка.
. Вызовите контекстное меню на выбранном узле.
. Выберите соответствующий пункт из контекстного меню, чтобы удалить узел.
. Появится предупреждение, подтвердите действие кнопкой *ОК*.

[#fields]
== Перечень полей карточки подразделения контрагента

Основная информация о подразделении может быть заполнена при создании нового подразделения или изменена после создания.

.Основная информация о подразделении контрагента
image::create-new-dept-main-index-partner.png[Основная информация о подразделении контрагента]

Информация о подразделении::
Название:::
В поле указывается сокращенное название, которое будет отображаться в справочнике {dv}.
Полное название:::
В поле указывается полное официальное название.
Телефон:::
В поле указывается номер телефона для связи.
Факс:::
В поле указывается номер факса.
E-mail:::
В поле указывается адрес для отправки электронных писем.
Адрес:::
В поле xref:./companies.adoc#address[указывается] фактический адрес.
+
Поле заполняется по аналогии с xref:./companies.adoc#address[полем] `Адрес` в данных организации.

Дополнительная информация::
Коды:::
В секции _Коды_ вкладки _Дополнительно_ нажмите кнопку *Добавить* image:buttons/plus.png[Плюс], чтобы ввести государственные коды и указать их значения.
+
Удалить коды можно при помощи кнопки image:buttons/recycle-bin-black.png[Урна].
