= Справочник контрагентов

Справочник контрагентов позволяет создавать, редактировать и просматривать иерархическую структуру узлов организаций и подразделений, групп контрагентов. Справочник позволяет создавать и объединять сотрудников в группы внешних организаций, с которыми взаимодействует компания.
