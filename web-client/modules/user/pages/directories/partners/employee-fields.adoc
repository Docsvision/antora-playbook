= Поля и вкладки карточки сотрудника контрагента

[#common]
== Поля с общей информацией в карточке сотрудника контрагента

Поля общих данных сотрудника всегда отображаются в верхней области карточки. Содержимое области, расположенной под общими данными, зависит от выбранной вкладки, расположенной в нижней части карточки: _Основная_, _Активность_, _Дополнительно_.

.Общая информация и вкладки карточки сотрудника контрагента в режиме редактирования
image::employee-card-common.png[Общая информация и вкладки карточки сотрудника контрагента в режиме редактирования]

[cols="26%,74%"]
|===
|Фото
|Область фотографии слева от общих данных предназначена для xref:directories/staff/employee.adoc#photo[прикрепления фотографии] к личной карточке сотрудника.

|Фамилия, Имя и Отчество
|Поля для указания ФИО сотрудника. Обязательным для заполнения является только поле `Фамилия`.

|Дата рождения
|Можно выбрать дату рождения сотрудника из xref:appendix/date-time.adoc#calendar[календаря].
|===

[#main]
== Поля вкладки "Основная" в карточке сотрудника контрагента

.Карточка сотрудника контрагента на вкладке "Основная" в режиме редактирования
image::employee-card-edit.png[Карточка сотрудника на вкладке "Основная" в режиме редактирования]

[cols="26%,74%"]
|===
|Пол
|В поле указывается пол сотрудника. Пол можно выбрать из двух значений: *_Мужской_* и *_Женский_*, либо не указывать, оставив в значении *_Нет_*.

|[[email]]E-mail
|Адрес электронной почты сотрудника нужен, например, для возможности отправки заданий по почте, если включена xref:directories/staff/employee.adoc#routing[маршрутизация]. Можно указать несколько адресов без пробелов, разделив их символом `;`. При этом, если включена маршрутизация, задания будут отправляться на все указанные адреса.

|[[duty]]Должность
|Должность сотрудника можно выбрать из списка. Если необходимая должность не представлена в списке, xref:directories/staff/duties.adoc#createDuty[добавьте её].

|Мобильный телефон и Рабочий телефон
|В поле указываются номера телефонов для связи с сотрудником.

|Комната
|В поле указывается номер помещения, в котором работает сотрудник.

|Руководитель
a|Указывается непосредственный руководитель сотрудника.

[#activity]
== Поля вкладки "Активность" в карточке сотрудника

Во вкладке _Активность_ карточки сотрудника доступна следующая информация:

.Вкладка "Активность" в режиме редактирования
image::employee-active-tab-edit.png[Вкладка "Активность" в режиме редактирования]

[cols="26%,74%"]
|===
|[[currentStatus]]Текущий статус
|Статус сотрудника может быть выбран из списка в режиме xref:directories/staff/employee.adoc#edit-employee[редактирования] или xref:directories/staff/employee.adoc#new[создания], а также задан самим сотрудником из xref:interface-user-profile.adoc[профиля сотрудника]. Подробнее о статусах сотрудников cм. <<statuses,ниже>>.

|Период недоступности сотрудника
|В поле под статусом задаётся период недоступности сотрудника. Подробнее о доступности сотрудника в пункте xref:directories/staff/absence-deputy.adoc[].

|Заместители
|В нижней части окна сотрудника отображается область _Заместители_. В данной области отображаются сотрудники, уполномоченные замещать текущего сотрудника (см. xref:directories/staff/absence-deputy.adoc#viewDeputies[недоступность и замещение]).

При просмотре информации о сотруднике период и причина отсутствия, заместители сотрудника отображаются только если задан период недоступности. Если период недоступности не задан, отображается только статус.

|===

[#statuses]
== Статусы сотрудника

Статусы сотрудников позволяют задать текущий статус активности сотрудника без потери данных. Например, если установить для сотрудника статус _Уволен_, сотрудник окажется неактивен. При этом рабочие данные, связанные с сотрудником, не пропадут из карточек.

Любой статус подсвечивается серым цветом, кроме статуса _Активен_. Статус _Активен_ подсвечивается зелёным.

include::6.1@winclient:user:employee-status.adoc[tags=bp-status]

[cols="26%,74%",options="header"]
|===
|Статус
|Описание

|Активен
|Сотрудник активен и может выполнять свои рабочие обязанности.

Статус можно изменить из _Справочника контрагентов_ и из xref:interface-user-profile.adoc[профиля сотрудника] в {wc}е.

|Болен
|Сотрудник отсутствует по состоянию здоровья.

Статус можно изменить из _Справочника сотрудников_ и из xref:interface-user-profile.adoc[профиля сотрудника] в {wc}е.

|В отпуске
|Сотрудник находится в отпуске.

Статус можно изменить из _Справочника контрагентов_ и из xref:interface-user-profile.adoc[профиля сотрудника] в {wc}е.

|В командировке
|Сотрудник находится в командировке.

Статус можно изменить из _Справочника контрагентов_ и из xref:interface-user-profile.adoc[профиля сотрудника] в {wc}е.

|Отсутствует
|Сотрудник отсутствует по каким-либо другим причинам.

Статус можно изменить из _Справочника контрагентов_ и из xref:interface-user-profile.adoc[профиля сотрудника] в {wc}е.

|Уволен
|Сотрудник уволен.

Статус доступен для смены только из _Справочника контрагентов_.

|Переведен
|Сотрудник переведен в другое подразделение.

Статус доступен для смены только из _Справочника контрагентов_.

|Уволен без возможности восстановления
|Запрет любых изменений сведений о сотруднике, включая повторное изменение состояния. Работа с системой для контрагентов в данном состоянии запрещена.

Статус доступен для смены только из _Справочника контрагентов_.
|===
