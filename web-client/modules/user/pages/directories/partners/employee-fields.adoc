= Поля и вкладки карточки сотрудника контрагента

.Общая информация и вкладки карточки сотрудника контрагента в режиме редактирования
image::employee-card-partner.png[Общая информация и вкладки карточки сотрудника контрагента в режиме редактирования]

[cols="26%,74%"]
|===
|Фамилия, Имя и Отчество
|Поля для указания ФИО сотрудника. Обязательным для заполнения является только поле `Фамилия`.

|Мобильный, рабочий, дополнительный телефон
|В поле указываются номера телефонов для связи с сотрудником.

|Дата рождения
|Можно выбрать дату рождения сотрудника из xref:appendix/date-time.adoc#calendar[календаря].

|Обращение
|Форма официального обращения к сотруднику выбирается из _Справочника обращений_.

|Должность
|Должность контрагента из собственного справочника доложностей для
_Справочника контрагентов_.

|[[email]]E-mail
|Адрес электронной почты сотрудника контрагента. Можно указать несколько адресов без пробелов, разделив их символом `;`.

|Адрес
|В поле xref:./companies.adoc#address[указывается] фактический адрес.

Поле заполняется по аналогии с xref:./companies.adoc#address[полем] `Адрес` в данных организации.

|Комментарий
|Поле предназначено для добавления дополнительной информации к карточке сотрудника. Поле поддерживает HTML синтаксис.

|===
