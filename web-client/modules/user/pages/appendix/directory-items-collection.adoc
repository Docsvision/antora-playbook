= Записи справочников

Элемент разметки `_Записи справочников_` предназначен для выбора одного или нескольких значений из одного или нескольких справочников.

.ЭУ "Записи справочников" в разметке с режимом создания
image::collection-select-layout.png[ЭУ "Записи справочников" в разметке с режимом создания]

В зависимости от настроек могут быть ограничены возможности выбора определённых типов записей, а также области выбора (см. подробнее "xref:layouts:ctrl/directories/directoryItemsCollection.adoc[]").

Также может быть разрешён выбор только одной или нескольких записей. Или режим, при котором определённое значение будет по умолчанию выбрано.

[#display-mode]
== Режим отображения

.В зависимости от режима редактирования ЭУ отображается по-разному:
* В режиме _Просмотр_ и _Редактирование по месту_ ЭУ представляет собой текст, содержащий иконки (свойство `*CSS-класс иконки*`) и отображаемые названия (свойство `*Отображаемое поле*`) выбранных элементов справочника. Выбранные элементы отображаются либо в одну строку с разделителем `;`, либо вертикально, с новой строки в зависимости от значения свойства `*Вертикальная ориентация*`.
* В режиме _Редактирование_ ЭУ содержит:
.. Кнопку image:user:buttons/book.png[Книга], нажатие на которую открывает окно поиска и выбора элементов с текстовым полем для ввода искомого текста.
.. Раскрывающийся список найденных элементов справочника с возможностью выбора. Список будет отображен при вводе строки, длина которой больше или равна значению, заданному в свойстве `*Индекс поиска*`.
+
Нажатие на найденный элемент добавляет его в список ниже. Для каждого пункта в списке отображается следующая информация:
+
*** Если выбор осуществляется из нескольких справочников, отображается название справочника и секции, в которой найден данный элемент.
*** Иконка (свойство `*CSS-класс иконки*`) и отображаемое название элемента (свойство `*Отображаемое поле*`). Если в отображаемом названии найдены совпадения, они будут выделены жёлтой подсветкой.
*** Дополнительные сведения об элементе (свойство `*Дополнительные поля*`). Если поле дополнительных сведений также является полем для поиска и в нём найдены совпадения, они будут выделены жёлтой подсветкой.
+
.. Список выбранных элементов справочника.

[#multiple-types]
== Выбор из нескольких типов значений

Если для выбора доступны несколько xref:layouts:ctrl/directories/directoryItemsCollection.adoc#types[типов значений], в режиме редактирования значения ЭУ нажмите кнопку image:buttons/book.png[Книга], чтобы открыть окно выбора элементов.

.Окно поиска и выбора значения элементов при выборе из нескольких типов значений
image::collection-select.png[Окно выбора значения элементов при выборе из нескольких типов значений]

.Окно поиска и выбора элементов содержит:
. Указатель типа элементов. В заголовке окна отображается путь к текущей секции. Чтобы перейти к дочерним элементам, нажмите кнопку image:buttons/arrow-blue-forward.png[Стрелка вправо]. Чтобы перейти к промежуточному уровню, используйте ссылки в пути к текущему открытому элементу справочника. Чтобы вернуться к списку типов значений, нажмите на кнопку image:buttons/book.png[Книга].
. Поле для ввода текстового поискового запроса.
. Доступные типы значений. Чтобы перейти к выбору значения, нажмите на строку с типом значений.
. Список выбранных значений с возможностью удаления элементов.
. Кнопки *Закрыть* и *Выбрать*. Кнопка *Закрыть* закрывает окно без изменения значения ЭУ, аналогичное действие поведение будет при закрытии формы кнопкой `Х` в заголовке, либо при клике по странице вне формы. Кнопка *Выбрать* закрывает окно, значение ЭУ будет установлено как список выбранных в форме элементов.

. Доступные типы значений. Чтобы перейти к выбору значения, нажмите на строку с типом значений.
+
Если настроено свойство `*Дополнительные поля*`, таблица будет содержать столбец с названием элемента (свойство "Отображаемое поле"), а также столбцы для всех полей, указанных в свойстве `*Дополнительные поля*`. +
Если в таблице какого-либо типа элементов отображается выбранный элемент, он будет выделен жирным шрифтом.
+
. Кнопка добавления нового значения в справочник. Отображается, если соответствующая возможность xref:layouts:ctrl/directories/directoryItemsCollection.adoc#edit[включена] в настройках типа значения и текущий сотрудник обладает правом на редактирование справочника и строки, указанной в свойствах "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#node[Узел]" или "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#limitation[Ограничение]".
+
[#list]
.Добавлять разрешается следующие новые значения:
* Подразделения справочника контрагентов
* Сотрудники справочника контрагентов
* Подразделения справочника сотрудников
* Сотрудники справочника сотрудников
* Узлы конструктора справочников
* Элементы конструктора справочников
+
. Список выбранных значений с возможностью удаления элементов.
. Кнопки *Закрыть* и *Выбрать*. Кнопка *Закрыть* закрывает окно без изменения значения ЭУ, аналогичное действие поведение будет при закрытии формы кнопкой `Х` в заголовке, либо при клике по странице вне формы. Кнопка *Выбрать* закрывает окно, значение ЭУ будет установлено как список выбранных в форме элементов.

[#quick-search]
== Поиск по справочнику

Для ЭУ доступны два вида поиска значений: быстрый поиск из поля редактирования и поиск из окна элемента управления. Чтобы воспользоваться быстрым поиском по справочнику, введите искомое значение в поле элемента управления. Записи, соответствующие условиям запроса, будут показаны в списке. Записи, которые были выбраны, в результатах поиска не отображаются.

NOTE: Обратите внимание, поиск активируется при вводе количества символов, равного или превышающего указанное в свойстве "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#search-index[Поисковой индекс]"

.Быстрый поиск по записям справочников
image::collection-search-quick.png[Быстрый поиск по записям справочников]

Поиск осуществляется по полям секции, указанным в параметре "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#disp-field[Отображаемое поле]". Результаты сортируются по возрастанию значения отображаемого поля и по справочнику. Справочники в результатах поиска отображаются в порядке, заданном в свойстве "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#types[Типы значений]".

Количество результатов на "порцию" поиска зависит от свойства "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#per-query[Кол-во загружаемых за раз элементов]". Больше результатов можно получить при нажатии на кнопку *Показать ещё*.

.Поиск в ЭУ "Записи справочников"
image::collection-search-full.png[Поиск в ЭУ "Записи справочников"]

Если также задан параметр "xref:layouts:ctrl/directories/directoryItemsCollection.adoc#field-for-search[Поле для поиска]", поиск будет осуществляться по указанным в нём полям (поле из свойства `*Отображаемое поле*` в поиске участвовать не будет).
