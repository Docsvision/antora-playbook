Начиная, с {wc-first-login-req}, в {wc} могут входить пользователи, добавленные в справочник сотрудников или в группу *{dv-admins-serv}*.

Сотрудники, входящие в группу *{dv-admins-serv}* (например, xref:6.2@mgmtconsole:servers:appserver-access.adoc[добавленные в группу] через {mc}), могут войти в {wc}, даже если их учётная запись отсутствует в справочнике сотрудников.

ifdef::admin[]
Если пользователь отсутствует в справочнике сотрудников, но является членом группы *{dv-admins-serv}*, перед выполнением входа автоматически создается запись о сотруднике в Справочнике сотрудников. Запись о сотруднике будет добавлена в первую по списку организацию, если в справочнике есть хотя бы одна организация. Если в справочнике нет ни одной организации, будет создана организация с именем `DocsVision`, в которую будет добавлен сотрудник. Заполняется только поле _Пользователь_, остальные поля не заполняются
endif::admin[]

Если пользователь отсутствует в Справочнике сотрудников и не входит в группу *{dv-admins-serv}*, он не сможет получить доступ в {wc}. При попытке входа появляется сообщение об ошибке: `Не удалось войти: Сотрудник с именем пользователя не найден в Справочнике сотрудников и не является администратором`.
