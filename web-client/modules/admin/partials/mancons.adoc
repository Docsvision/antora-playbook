[TIP]
====
Начиная с модуля {wc} версии {wc-cu5}, поддерживается два {do-what}:

ifndef::cntrl-pnl[]
ifndef::init-config[]
ifndef::webtoolutil[]
* Из интерфейса {of-mc} без необходимости работы с форматом `.json`: "xref:dev@mgmtconsole:servers:{link}"
endif::webtoolutil[]
ifdef::webtoolutil[]
* При помощи WebToolUtil без необходимости работы с форматом `.json`, см. подробнее в разделе "{link}"
endif::webtoolutil[]
* При помощи настройки в конфигурационном файле модуля, см. подробнее ниже
endif::init-config[]
ifeval::["{init-config}" == "yes"]
* Из интерфейса {of-mc} без необходимости работы с форматом `.json` см. ниже раздел {first}
* При помощи настройки в конфигурационном файле модуля, см. ниже раздел {second}
endif::[]
endif::cntrl-pnl[]
ifeval::["{cntrl-pnl}" == "yes"]
* Из интерфейса {of-mc}, минуя взаимодействие с программой {pu}: "xref:dev@mgmtconsole:servers:{link}"
* При помощи настройки в программе {pu}, см. ниже
endif::[]
====
// Если не понятно, то поясняю: cntrl-pnl нужен для страниц панели управления, но работает только при условии, если он yes, в противном случае второй ifeval не действует. Первый ifeval действует только, если установлен init-config в yes, т.е. на странице установки и первоначальной настройки, там немного другая структура, т.к. оба раздела на странице. Остальное довольно очевидно: если определён такой-то атрибут, то будет такое-то, если нет -- будет другое. Например, webtoolutil чуть сложнее обычного, т.к. изначально утилиты настраивались через конфиг, а сейчас через webtoolutil.
