Для создания нового пула приложений в IIS администратор должен будет указать данные учётной записи, от имени которой пул будет запущен.
+
.Пример заполнения учётных данных пула приложений
image::config-pool.png[Пример заполнения учётных данных пула приложений]
+
Имя пользователя следует указывать в формате домен\пользователь (без использования суффиксов UPN). Требования к учётной записи пула приложений см. в xref:ROOT:requirements-pool.adoc[Требования к учётной записи пула приложений].
