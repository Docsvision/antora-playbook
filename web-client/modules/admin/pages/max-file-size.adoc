= Ограничить размер прикладываемых файлов

В {wc}е по умолчанию действует несколько ограничений, влияющих на возможность прикладывания файлов большого размера:

* Максимальный размер файла, прикладываемого при создании карточки (параметр `MaxUploadFileItemSize`). Значение по умолчанию: 50 Мб.
// * Максимальный размер всех прикладываемых файлов одной карточки. Значение по умолчанию: 128 Мб.
* Максимальный размер тела запроса (параметр `MaxRequestBodySize`), по умолчанию приблизительно равен 28,6 Мб.

Администратор системы может изменить действующее ограничение в {of-mc}.

// tag::webconfig[]
.Чтобы изменить ограничение для максимального размера единичного файла:
. Откройте {mc} на странице menu:Серверы[Имя сервера > {wc}> "xref:dev@mgmtconsole:servers:webclient-files.adoc[Группа настроек "Работа с файлами"]] и измените следующий параметр:
+
* Максимальный размер прикладываемого файла, байт
+
. Сохраните изменения.

.Чтобы изменить ограничение для максимального размера тела запроса:
. Откройте {mc} на странице menu:Серверы[Имя сервера > {wc}> "xref:dev@mgmtconsole:servers:webclient-files.adoc[Группа настроек "Работа с файлами"]] и измените следующий параметр:
+
* Максимальный размер карточки
// end::webconfig[]
+
. Сохраните изменения.
