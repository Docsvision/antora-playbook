= Параметры конфигурационного файла {wc}а

Конфигурация модуля может выполняться при помощи конфигурационного файла {wc}а, расположенного по адресу `{webconfig-lin}` в Linux и `{webconfig-cp}` в Windows, однако следует помнить, что настройки конфигурационного файла не сохраняются при xref:update-module.adoc[обновлении версии {wc}а].

include::partial$excerpts.adoc[tags=ifabsent]

[TIP]
====
Рекомендуемый способ конфигурации {wc}а -- при помощи {of-mc}, дополнительные сведения приведены в разделах соответствующих параметров по ссылкам.

Настройки в конфигурационном файле не сохраняются при xref:update-module.adoc[обновлении версии {wc}а].
====
