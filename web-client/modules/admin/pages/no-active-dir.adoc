= Настройка {wc}а в сети без Active Directory

{wc} поддерживает подключение к серверу {dv} под системной учётной записью из каталога LDAP\LDAPS, xref:install-server.adoc[указанной] в параметрах `SystemUserAccount` и `SystemUserPassword` конфигурационного файла.

Настройка каталогов LDAP\LDAPS описана в разделе "xref:CU25.3@engineer:ROOT:ldaps-without-ad.adoc[]".
