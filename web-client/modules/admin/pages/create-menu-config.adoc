= Настройка меню создания карточек

Администратор {wc}а может изменить настройки меню создания карточек: добавить или удалить типы карточек, изменить последовательность отображения типов.

// tag::webconfig[]
.Чтобы изменить настройки меню создания карточек:
. Откройте {mc} на странице menu:Серверы[Имя сервера > {wc}> "xref:dev@mgmtconsole:servers:webclient-interface.adoc[Группа настроек "Интерфейс"]].
. В группе настроек "Типы карточек, отображаемые в диалоге создания" укажите следующие параметры:
+
* _Идентификатор_ -- системный идентификатор типа карточки;
* _CSS-класс_ -- стиль по умолчанию, используемый для типа карточек;
* _Сохранять в папке_ -- флаг, определяющий необходимость сохранения карточек данного типа в папке;
* _Вариант скрытия_ -- строка для ввода значения.
// end::webconfig[]
+
. Сохраните изменения.
