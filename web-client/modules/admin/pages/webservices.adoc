= Настройки DVWebTool и DVSupService

DVWebTool и DVSupService необходимы для работы пользователя в {wc}е. DVWebTool и DVSupService предоставляют пользователю возможность открывать файлы в офисном редакторе с правами *текущего пользователя*. Если пользователь использует ОС Windows, будет использоваться DVWebTool, если сотрудник работает в Linux, будет использоваться DVSupService.
