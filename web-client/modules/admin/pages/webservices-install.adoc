= Работа с программой WebToolBuilder

Программа _WebToolBuilder_ предназначается для сборки _DVWebTool_, минуя {pu}. Так как в будущем _DVWebTool_ планируется упразднить и перенести функциональность утилиты в _DVSupService_, задача по сборке _DVWebTool_ была делегирована _WebToolBuilder_.

.WebToolBuilder необходимо запускать для сборки DVWebTool в следующих случаях:
. Когда DVWebTool устанавливается впервые на версии системы без программы {pu}
. Когда изменились файлы DVWebTool или вышла новая версия
. Когда изменился адрес или порт вервера {wc}а
. Когда изменились внутренние расширения DVWebTool

Программа _WebToolBuilder_ устанавливается либо из инсталлятора {wc}а (`Docsvision web-client.msi`, компонент _WebToolBuilder_) или из инсталлятора утилиты `WebToolBuilder.msi`. WebToolBuilder запускается в ОС Windows. Программа может быть запущена с минимальным пользовательским интерфейсом или как консольное приложение.

Новая версия WebToolBuilder выпускается при каждом исправлении DVWebTool в накопительных обновлениях. Для распространения WebToolBuilder могут использоваться групповые политики.

[#ui]
== Запуск в режиме окна

.Окно программы "WebToolBuilder"
image::webtoolbuilder.png[Окно программы "WebToolBuilder"]

Путь к приложения по умолчанию: `C:\Program Files (x86)\Docsvision\WebToolBuilder\WebToolBuilderUI.exe`.

.В окне приложения отображается следующий набор элементов:
* Путь к манифесту приложения -- поле для выбора файла манифеста `DocsVision.DVWebTool.application`
* image:layouts:buttons/three-dots.png[Три точки] -- унопка для выбора манифеста приложения из файловой системы
* Адрес {wc}а -- полный адрес сервера {wc}а
* Порт -- порт для подключения к DVWebTool
* Флаг `*Автозапуск*` -- отвечает за автоматический запуск DVWebTool при загрузке системы
* Кнопка *Собрать* или *Пересобрать* неактивна, пока не выбран файл манифеста и не заполнены поля _Адрес {wc}а_ и _Порт_
* Поле _Журнал_, в котором записываются действия при работе с программой

[#noui]
== Запуск в консольном режиме

. Перейдите в каталог с WebToolBuilder (по умолчанию `C:\Program Files (x86)\Docsvision\WebToolBuilder\WebToolBuilder.exe`) и запустите утилиту командой с указанием пути к файлу манифеста:
+
 ./WebToolBuilder http://example.com:5004/Content/Tools/DVWebTool/DocsVision.DVWebTool.application
+
. Чтобы получить справку по работе с утилитой в консольном режиме, введите `-h` при нахождении в папке утилиты:
+
.Доступные опции:
* `-u`, `--url` -- URL развёртывания манифеста приложения на сервере (обязательная опция)
* `-p`, `--port` -- Порт для работы DVWebTool (записывается в конфигурационный файл DVWebTool)
* `-a`, `--autorun` -- Флаг, отвечающий за автоматический запуск DVWebTool при загрузке системы
* `-c`, `--certificate` -- Путь к файлу сертификата для подписания манифеста приложения и манифеста развёртывания
* `--version` -- Узнать версию приложения
* `-?`, `-h`, `--help` -- Показать справку
* `--whatIf` -- Отображает список параметров, которые будут использоваться при пересборке DVWebTool

== Сборка DVWebTool через WebToolBuilder

// tag::webtool[]
Программа _DVWebTool_ необходима для выполнения сканирования документов и открытия файлов в офисном редакторе в ОС {ms} Windows.

WARNING: Программа _DVWebTool_ работает только в ОС {ms} Windows. Для работы требуется установить {net-r}.
// end::webtool[]

.Чтобы установить "DVWebTool":
. [[install-dvweb]]Чтобы установить _DVWebTool_ на сервер Linux, необходимо создать образ утилиты. Для этого запустите _WebToolBuilder_ на Windows.
. В поле _Путь к манифесту приложения_ выберите файл манифеста `DocsVision.DVWebTool.application`. Файл можно получить на вкладке xref:user:interface-user-profile.adoc#install["Установки" профиля пользователя] скачанный из профиля пользователя {wc}а. После выбора файла автоматически будут заполнены другие поля.
+
NOTE: Файл является уникальным для каждого пользователя.
+
* В поле _Адрес {wc}а_ указывается адрес DVWebTool на сервере {wc}а
* В поле _Порт_ указывается порт для подключения к DVWebTool (по умолчанию `5413`)
+
. При необходимости установите флаг `*Автозапуск*`, чтобы _DVWebTool_ запускалась автоматически при загрузке системы.
. Нажмите кнопку *Собрать*, чтобы открыть каталог.
+
.Успешное завершение сборки
image::admin:dvweb-final-window.png[Успешное завершение сборки]
+
После завершения сборки появится окно об успешном завершении операции. При нажатии на кнопку *ОК* будет открыта папка в файловой системе с собранными файлами DVWebTool.
+
. Скопируйте открытую папку _DVWebTool_ на сервер Linux по пути `/lib/docsvision/webclient/Content/Tools` (если папка отсутствует, создайте её самостоятельно).
. Убедитесь, что в конфигурационном файле `/usr/lib/docsvision/webclient/appsettings.json`, в параметре `DVWebToolInstallerUri`: указан адрес каталога: `Content\\Tools\\DVWebTool\\DocsVision.DVWebTool.application`.
. Перезапустите службу *{wcs-new}*.
. _DVWebTool_ будет установлена при первом открытии файла из карточки в ОС Windows. Программу также можно установить вручную из menu:Профиля пользователя[Установки > Установить DVWebTool].
+
После завершения установки программа _DVWebTool_ будет запущена автоматически, а в области уведомлений Windows появится значок программы (image:user:buttons/dv-web-ico.png[Две стрелочки в зелёном круге]).
+
Программа устанавливается только для текущего пользователя. Если на компьютере работает несколько пользователей (несколько профилей Windows), программу нужно установить каждому пользователю.
