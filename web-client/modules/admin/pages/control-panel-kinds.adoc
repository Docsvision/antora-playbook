= Раздел "Виды карточек по умолчанию"

Раздел _Виды карточек по умолчанию_ открывает страницу настройки видов карточек, с которыми по умолчанию будут создаваться новые карточки соответствующих типов.

****
Начиная с модуля {wc} версии {wc-cu5}, поддерживается два варианта настройки видов карточек по умолчанию:

* При помощи настройки в программе {pu}, см. подробнее ниже
* Из интерфейса {of-mc}, минуя работу с Панелью управления: "xref:dev@mgmtconsole:servers:webclient-kinds.adoc[]"
****

== Изменение стандартных видов карточек

****
Начиная с модуля {wc} версии {wc-cu5}, поддерживается два варианта изменения стандартных видов карточек:

* При помощи настройки в программе {pu}, см. подробнее ниже
* Из интерфейса {of-mc}, минуя работу с Панелью управления: "xref:dev@mgmtconsole:servers:webclient-kinds.adoc#edit-kinds[Изменение стандартных видов карточек]"
****

Для изменения стандартного вида для соответствующего типа карточек, нажмите на кнопку *Редактировать*. Для изменения списка нажмите кнопку *…* (три точки) и выберите вид из списка.
