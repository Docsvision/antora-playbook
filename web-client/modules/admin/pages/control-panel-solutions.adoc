[#import-standard]
== Загрузка стандартных решений

.Чтобы загрузить стандартные _решения_:
. В раскрывающемся списке *_Базы данных_* выберете подключенную БД для загрузки стандартных _решений_.
. Нажмите на кнопку *Импортировать стандартные решения*.
+
Если база данных {dv} содержит аналогичные загружаемым _решения_ более ранних версий, существующие _решения_ будут обновлены. Данное обновление не затрагивает собственные _решения_.
+
После завершения загрузки _решений_ в БД, они отобразятся в списке *Решения*.
+
[NOTE]
====
_Решения_ загружаются только в выбранную БД. Если к {wc}у подключено несколько БД, то _решения_ нужно будет поочередно загрузить во все требуемые базы данных.
====

[#import-other]
== Загрузка прочих решений

Помимо загрузки всех стандартных _решений_ администратор может загрузить отдельные _решения_ из файлов.

.Чтобы загрузить решения в БД:
. Выберите в раскрывающемся списке *_Базы данных_* БД, в которую будут загружены _решения_. В данном списке отображаются БД, которые были добавлены на странице через _{cns}_.
. Нажмите на кнопку *Импортировать решение*.
. Выберите файл с данными _решения_:
+
--
* _Базовое решение_. Содержит разметки и условия выбора *типа* карточек Документ. Расположено в каталоге `{wcd-lin}/LayoutSolutions/LayoutSolutionsDocsvision.BackofficeSolution.xml`.
+
[NOTE]
====
[subs="specialchars,attributes,quotes"]
В {wc}е версии {wc-cu-mc} и выше расположение стандартных решений изменено: {solutions}.
====
+
* Решение _{dm}_. Содержит разметки и условия выбора стандартных *видов* карточек Документ приложения _{dm}_. Расположено в каталоге. `{wcd-lin}/LayoutSolutions/LayoutSolutionsDocsvision.DocumentManagementSolution.xml`.
+
[NOTE]
====
[subs="specialchars,attributes,quotes"]
В {wc}е версии {wc-cu-mc} и выше расположение стандартных решений изменено: {solutions}.
====
+
* Файл собственного _решения_.
--
+
При импорте стандартных решений приоритет отдаётся решениям xref:layouts:solutions-export.adoc#package[в виде пакета], в виде файла будут импортированы только те решения, у которых отсутствует вариант импорта в виде пакета.

[#remove]
== Удаление решений

Для удаления _решения_ из БД нужно выбрать его в списке _решений_ и нажать на кнопку *Удалить*.

[#transform]
== Преобразование решений

Если база данных содержит _решения_, формат которых не соответствует установленной версии {wc}а, на странице будет отображаться предупреждение о необходимости конвертации и кнопка для её выполнения. Решения, нуждающиеся в конвертации, будут выделены курсивом.

.БД с Решениями, требующими конвертации
image::config-convert.png[БД с Решениями, требующими конвертации]

Для выполнения преобразования _решений_, нажмите кнопку *Конвертировать*.

WARNING: Новые версии стандартных _решений_ при этом не будут импортированы.
