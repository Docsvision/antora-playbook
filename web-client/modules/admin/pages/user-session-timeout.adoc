= Изменить время ожидания пользовательской сессии

include::partial$mancons.adoc[]

// tag::webconfig[]
Администратор может изменить максимальное время ожидания ответа (таймаут) от сервера {dv}. Время ожидания устанавливается в секундах.

.Чтобы изменить таймаут пользовательской сессии из конфигурационного файла:
. Откройте конфигурационный файл `{webconfig-lin}` в Linux и `{webconfig-cp}` в Windows.
. Перейдите к секции {cnf-sgrps} > System].
. Измените значение параметра `ConnectionTimeout`.
+
--
[source,json]
----
{
  "Docsvision": {
    "WebClient": {
      "SettingGroups": {
        "System": {
          "ConnectionTimeout": 3600000 <.>
        }
      }
    }
  }
}
----
<.> Время ожидания пользовательской сессии равное 1 часу. Значение задаётся в секундах.
--
