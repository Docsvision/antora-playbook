= Изменить время ожидания пользовательской сессии

// tag::webconfig[]
Администратор может изменить максимальное время ожидания ответа (таймаут) от сервера {dv}. Время ожидания устанавливается в миллисекундах.

.Чтобы изменить таймаут пользовательской сессии:
. Откройте {mc} на странице menu:Серверы[Имя сервера > {wc}> "xref:dev@mgmtconsole:servers:webclient-connection.adoc[Группа настроек "Подключение к серверу приложений"]] и измените следующий параметр:
+
* Таймаут подключения, мс
// end::webconfig[]
+
. Сохраните изменения.
