= Ограничить максимальный размер файла для предпросмотра

В {wc}е по умолчанию действует ограничение предпросмотра файлов больше 100 Мб.

Администратор системы может изменить действующее ограничение.

include::partial$mancons.adoc[]

//tag::webconfig[]
.Чтобы изменить ограничение для максимального размера файла для предпросмотра из конфигурационного файла:
. Откройте конифгурационный файл {wc}а: `{webconfig-lin}` в Linux и `{webconfig-cp}` в Windows.
. В категории настроек {cnf-sgrps-wc}] измените параметр `MaxPreviewFileSize`.
+
--
[source,json]
----
{
  "Docsvision": {
    "WebClient": {
      "SettingGroups": {
        "WebClient": {
          "MaxPreviewFileSize": "0" <.>
        }
      }
    }
  }
}
----
<.> Укажите значение в байтах. +
Увеличение значения повысит нагрузку на сервер и время открытия файла на предпросмотр.
--
//end::webconfig[]
+
