= Ограничить максимальный размер файла для предпросмотра

В {wc}е по умолчанию действует ограничение предпросмотра файлов больше 100 Мб.

Администратор системы может изменить действующее ограничение.

//tag::webconfig[]
.Чтобы изменить ограничение для максимального размера файла для предпросмотра:
. Откройте {mc} на странице menu:Серверы[Имя сервера > {wc}> "xref:dev@mgmtconsole:servers:webclient-files.adoc[Группа настроек "Работа с файлами"]] и измените следующий параметр:
+
* Максимальный размер файлов для предпросмотра, байт
+
NOTE: Увеличение значения повысит нагрузку на сервер и время открытия файла на предпросмотр.
//end::webconfig[]
+
. Сохраните изменения.
