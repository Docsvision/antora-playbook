= Создать администратора {wc}а

Администратор {wc}а -- пользователь, которому предоставляются администраторские привилегии при работе с модулем. Когда администратор {wc}а входит в {wc}, под профилем пользователя отображается псевдоним текущего тенанта.

include::partial$mancons.adoc[]

.Отображение текущего тенанта
image::current-tenant.png[Отображение текущего тенанта]

.Администратор {wc}а -- пользователь:
* Зарегистрированный в _Справочнике сотрудников_ системы {dv}.
* Включённый в группу *{dv-admins-dir}* в конфигурационном файле Сервера приложений (модуля {pl}) или {of-mc}. См. подробнее в документации модуля _{pl}_, раздел "xref:6.1@platform:admin:config-platform.adoc[]", и документации {of-mc}, раздел "xref:mgmtconsole:servers:appserver-access.adoc[]".
