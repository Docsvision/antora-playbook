= Включить аутентификацию Kerberos

Прозрачная аутентификация Kerberos позволяет выполнять вход от имени УЗ текущего пользователя (если он зарегистрирован в справочнике сотрудников). Необходимые настройки описаны в руководстве по настройке системы, см. раздел "xref:engineer:ROOT:kerberos-authentication.adoc[]".

NOTE: На машине Windows, введенной в домен, могут возникать проблемы входа при подключении к машине по Remote Desktop Connection с использованием сквозной аутентификации т.к. https://wiki.astralinux.ru/kb/windows-v-ald-190917503.html[ALD Pro не поддерживает] ввод Windows в домен.
