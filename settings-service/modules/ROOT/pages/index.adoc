= Сервис настроек

.В "Сервисе настроек" хранятся:
* Собственные настройки "{of-mc}".
* Настройки сервисов и функций {dv}, управляемых с помощью "{of-mc}".

== Структура и функции модуля

Хранилище данных {of-sett-serv} -- хранилище, в котором хранятся данные данные {of-sett-serv}. По умолчанию это база данных. Содержимое {of-sett-serv} размещается в подключенной к системе БД.

Пользователи не работают с Сервисом настроек напрямую, а взаимодействуют с сервисом через {mc} с помощью веб-браузера. Используется протокол подключения HTTP.

Сформированная пользователем конфигурация для Службы фоновых операций сохраняется в Сервис настроек с исполняемым процессом `XXX.Sevice.exe`. Для записи настроек используется REST API.
