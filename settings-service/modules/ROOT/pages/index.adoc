= Сервис настроек

.В "Сервисе настроек" хранятся:
* Настройки "{of-mc}".
* Настройки сервисов и функций {dv}, управляемых с помощью "{of-mc}".

== Структура и функции модуля

{sett-serv} предоставляет модулям в системе {dv} возможность записывать, хранить и читать свои настройки. Настройки размещаются в собственной БД {of-sett-serv}.

Пользователи не работают с Сервисом настроек напрямую, администратор конфигурирует модули системы через {mc} с помощью веб-браузера. Сформированная пользователем конфигурация для модулей системы сохраняется в {sett-serv}. Для записи настроек используется REST API и протокол подключения HTTP.
