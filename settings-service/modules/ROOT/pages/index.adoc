= Сервис настроек

.В "Сервисе настроек" хранятся:
* Настройки "{of-mc}".
* Настройки сервисов и функций {dv}, управляемых с помощью "{of-mc}".

== Структура и функции модуля

Хранилище данных {of-sett-serv} -- хранилище, в котором хранятся данные данные {of-sett-serv}. По умолчанию это база данных. Содержимое {of-sett-serv} размещается в подключенной к системе БД.

Пользователи не работают с Сервисом настроек напрямую, администратор конфигурирует Службу {ws} через {mc} с помощью веб-браузера. Сформированная пользователем конфигурация для Службы {ws} сохраняется в Сервис настроек. Для записи настроек используется REST API и протокол подключения HTTP.
