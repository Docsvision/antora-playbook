[#windows-server]
== Установка модуля на сервер под управлением Windows

. Запустите пакет установки `Docsvision M4dRegistryIntegration.msi`.
+
.Мастер установки серверной части модуля
image::install-server-hello.png[Мастер установки серверной части модуля]
+
. Примите условия лицензионного соглашения для продолжения установки. Нажмите *Далее*.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Выберите компоненты, которые требуется установить, и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
include::6.1@platform:admin:partial$install-components.adoc[]
+
****
Общие компоненты::
Обеспечивают взаимодействие с другими сервисами {dv}, обязательны для установки на сервер {dv}.

Серверные компоненты:::
Основные серверные компоненты модуля _{mir}_, обязательны для установки на сервер {dv}.

Расширение {wc}а:::
Компоненты, необходимые для работы {wc}а, обязательно к установке на сервер {wc}а.

Расширение службы {ws}:::
Расширение службы {ws} необходимо для взаимодействия с модулем "Служба {ws}". Обязательно к установке на сервер "Службы {ws}".

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****
+
. В следующем окне нажмите *Установить* и дождитесь завершения установки модуля.
. Нажмите на кнопку *Готово*, чтобы закрыть мастер установки.
+
