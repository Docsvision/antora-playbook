= Обновление модуля

* Установка новой версии должна выполняться в нерабочее время.
* Перед установкой создайте резервную копию БД {dv}.
* Перед обновлением БД {pgsql} остановите pgAgent.
* База данных {dv} должна быть переведена на работу с расширенными метаданными.
* При обновлении разных серверов компоненты модуля должны быть одной версии.
