= Работа с журналом сообщений сервиса Workflow

Журнал сообщений сервиса Workflow предназначен для просмотра данных по обработке функций сервисом. Настройка журналирования описана в разделе "xref:bp-management.adoc[]".

[#view]
== Просмотр сообщений журнала

Просматривать журнал сообщений сервиса _{wfs-new}_, выполните команду:

[subs=attributes]
 $ sudo journalctl -f -u {wfs-new}

Команда выведет только самые последние записи в журнале и будет отображать новые записи по мере их появления, подробнее, например, о возможности фильтрации вывода см. описание команды `journalctl`.

[#detailed]
== Просмотр подробной информации о сообщениях журнала

Полный журнал работы сервиса можно найти по адресу, указанному в конфигурационном файле модуля `/usr/lib/docsvision/workflow/appsettings.json`, по умолчанию `/var/log/docsvision/workflow`.
