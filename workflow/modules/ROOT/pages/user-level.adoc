= Уровень подготовки пользователя

Для эксплуатации модуля _{wf}_ определены две пользовательские роли: администратор {dv} и пользователь.

Администратор {dv} устанавливает модуль (серверную и клиентскую части), выполняет первоначальную настройку.

Пользователь выполняет настройку бизнес-процессов с помощью предоставляемых функций и шлюзов, а также разработанных скриптов.

Основным пользовательским рабочим местом является {wc}. Все пользователи модуля должны обладать базовыми навыками работы на персональном компьютере и в интернет браузере.

При внедрении модуля может определяться дополнительная роль: разработчик {dv}. Разработчик создаёт  собственные скрипты (сценарии) БП на языках C# и Visual Basic .Net в интегрированной среде разработки.
