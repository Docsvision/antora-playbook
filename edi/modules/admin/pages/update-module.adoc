[#conditions]
== Условия обновления

* Установка новой версии должна выполняться в нерабочее время.
* Перед установкой создайте резервную копию БД {dv}.
* Если в БД {pgsql} используется pgAgent, остановите планировщик.
* База данных {dv} должна быть переведена на работу с расширенными метаданными.
* При обновлении разных серверов компоненты модуля должны быть одной версии.

WARNING: При выполнении данной операции в БД {dv} будут загружены стандартные настройки {of-em}. Рекомендуем перед обновлением БД экспортировать _Справочник настроек операторов ЮЗДО_ для последующего его импорта после обновления БД.
