[#conditions]
== Условия обновления

* Установка новой версии должна выполняться в нерабочее время.
* Перед установкой создайте резервную копию БД {dv}.
* Перед обновлением БД {pgsql} остановите pgAgent.
* База данных {dv} должна быть переведена на работу с расширенными метаданными.
* При обновлении разных серверов компоненты модуля должны быть одной версии.

WARNING: При выполнении данной операции в БД {dv} будут загружены стандартные настройки {of-em}. Рекомендуем перед обновлением БД экспортировать _Справочник настроек операторов ЮЗДО_ для последующего его импорта после обновления БД.

[#ext-linux]
== Обновление Расширения {of-em} для {wc}а на сервере под управлением Linux

. Обновите компоненты расширения на сервере Linux командой:
+
[tabs]
====
{os1}::
+
[source,subs=attributes]
----
sudo apt-get update
sudo apt-get install --only-upgrade docsvision-ext-edi-webc*
----

{os2}::
+
[source,subs=attributes]
----
sudo dnf update docsvision-ext-edi-webc*
----
====

[#ext-windows]
== Обновление Расширения {of-em} для {wc}а на сервере под управлением Windows

. Обновите необходимые компоненты модуля на сервере Windows из инсталлятора `{dv} EDI extension for Web-client.msi`.
