[#windows-connector]
== Установка компонентов Коннектора к Диадок на сервер под управлением Windows

Серверные компоненты _Коннектора к Диадок_ устанавливаются на сервер под управлением Windows с установленными серверными компонентами _{of-em}_.

. Запустите пакет установки `{dv} EDI Integration server.msi`.
+
.Мастер установки серверной части модуля
image::admin:install-server-hello.png[Мастер установки серверной части модуля]
+
. Примите условия лицензионного соглашения для продолжения установки. Нажмите *Далее*.
+
.Условия лицензионного соглашения
image::admin:install-server-license.png[Условия лицензионного соглашения]
+
. Выберите компоненты "Коннектор к Диадок" и "Серверные компоненты" коннектора и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::admin:install-server-components.png[Выбор устанавливаемых компонентов]
+
****
Общие компоненты::
Обеспечивают взаимодействие с другими сервисами {dv}, обязательны для установки на сервер {dv}, сервер {wc}а и узлы модуля {wf}.

Серверные компоненты:::
Основные серверные компоненты _{of-em}_, обязательны для установки на сервер {dv}.

Коннектор к Диадок::
Обеспечивают взаимодействие с коннектором к Диадок, обязательны для установки на сервер {dv}, если планируется работать с коннектором.

Серверные компоненты:::
Основные серверные компоненты коннектора к Диадок для работы в {wc}е, обязательны для установки на сервер {dv}.

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****

[#uninstall]
== Удаление Коннектора

. Удалите настройки оператора Диадок из _Справочника настроек операторов ЮЗДО_.
.. Откройте карточку _Справочник настроек операторов ЮЗДО_ в утилите _{dv} Explorer_ (входит в _{rk}_). Инструкция по работе с утилитой _{dv} Explorer_ приведена в документации _{rk}_, разделе "xref:6.1@resource-kit:dvexplorer:util.adoc[]".
.. Удалите из секции _Операторы_ строку оператора "Диадок".
. Удалите компоненты коннектора:
+
.. В ОС Windows Удалите компоненты коннектора через изменение инсталлятора:
+
* Клиентский компонент модуля: "Коннектор к Диадок. Клиент".
* Серверный компонент модуля: "Коннектор к Диадок. Сервер".
+
.. В ОС Linux удалить компоненты можно командой:
+
