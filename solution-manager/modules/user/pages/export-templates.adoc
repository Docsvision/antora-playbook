= Настройка параметров экспорта шаблонов

{sm} позволяет переносить шаблоны (например, маршруты согласования), находящиеся в папках.

.Чтобы экспортировать шаблоны:
. Поместите шаблоны, которые необходимо экспортировать, в папку.
. Выполните шаги по экспорту папок, описанные в разделе "xref:export-folders.adoc[]".
