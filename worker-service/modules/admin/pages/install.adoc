[#config]
== Настройка Службы {ws}

Служба {ws} имеет два конфигурационных файла, расположенных по адресу `/usr/lib/docsvision/workerservice/` в Linux и `C:\Program Files\Docsvision\WorkerService\` в Windows. Конфигурационный файл `appsettings.json` предназначается для настройки защищённого подключения для Службы {ws}.

Файл `Configuration.json` содержит основные настройки для работы системы {dv}: `SettingsServiceConnectionString`, `ApiKey`, `RestApiAddress`, `LogFile`.

// tag::config[]

--
В конфигурационном файле `appsettings.json` располагаются настройки защищённого соединения.

.Фрагмент конфигурационного файла "appsettings.json":
[source,json]
----
{
  "Kestrel": { <.>
    "Endpoints": {
      "Http": {
        "Url": "http://*:5900"
      }
    }
  }
}
----
<.> Настройка защищённого (HTTPS) соединения для Службы {ws} для защиты конфиденциальных данных, см. подробнее "xref:dv6@engineer:ROOT:https-connection.adoc[]". Настройка также позволяет задать порт и адрес подключения к Службе {ws}.

.Фрагмент конфигурационного файла "Configuration.json":
[source,json]
----
{
  "SettingsServiceConnectionString": "ConnectAddress=http://settings.domain.com:5200/api", <.>
  "ApiKey": "anything", <.>
  "RestApiAddress": "http://worker.domain.com:5900/api", <.>
  "LogTraceLevel": "1" <.>
}
----
<.> Адрес подключения к Сервису настроек.
<.> Ключ доступа к Сервису настроек -- "пароль", который также должен быть указан в конфигурационном файле сервиса.
<.> Адрес подключения к Службе {ws}.
<.> Уровень журналирования Службы {ws}, см. подробнее "xref:6.1@workerservice:admin:work-log.adoc[]".
--

// end::config[]
