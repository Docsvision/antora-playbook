= Блок "Модули расширения"

Раздел "Модули расширения" содержит настройки базовых и дополнительных модулей {dv}, для которых предусмотрена возможность настройки.

* Модуль {pl} добавляет настройки "Сервиса полнотекстового поиска". Подробное описание приведено в документации {of-mc}:
// "xref:dev@mgmtconsole:servers:fulltext-search.adoc[]".
* Если модуль _{wf}_ установлен, его настройки также будут добавлены. Подробное описание приведено в документации {of-mc}: "xref:dev@mgmtconsole:user:connections-mail-server.adoc[]".
