[#linserver]
== Установка на сервер под управлением Linux

Начиная с версии {pl-cu-mc}, установка серверных компонентов в ОС Windows не потребуется, если не планируется работать в {wincl}е.

[#linux-pl]
=== Установка модуля {pl} на сервер под управлением Linux

При установке модулей {dv} в ОС Linux необходимо установить модуль описанными далее командами.

. Установите пакеты модуля {pl} следующей командой, предварительно обновив индекс пакетов:
+
:wt: platform
include::6.1@platform:admin:partial$install.adoc[tags=commands]
+
Вместе с модулем _{pl}_ команда установит серверные компоненты базовых модулей.
+
. Активируйте лицензию при помощи xref:activation.adoc[утилиты активации]:
+
[tabs]
====
{os1}::
+
[source]
----
sudo apt-get install docsvision-activation
cd /usr/lib/docsvision/tools/activation
sudo ./activation online ВАШ-КЛЮЧ
----

{os2}::
+
[source]
----
sudo dnf install docsvision-activation
cd /usr/lib/docsvision/tools/activation
sudo ./activation online ВАШ-КЛЮЧ
----
====
+
. Выполните конфигурацию модуля по инструкции в разделе "xref:config-platform.adoc[]".
. Запустите службу Сервера {dv}.

[#windows-pl]
=== Установка модуля {pl} на сервер под управлением Windows

Включить журналирование процесса установки можно с помощью флага `*/l*v*`:

 msiexec /i "Docsvision Platform server.msi" /l*v install.log

. Запустите пакет установки `{dv} Platform server.msi`.
. Примите условия лицензионного соглашения.
+
.Условия лицензионного соглашения
image::6.1@platform:admin:install-server-license.png[Условия лицензионного соглашения]
+
. Выберите компоненты, которые требуется установить, и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
include::6.1@platform:admin:partial$install-components.adoc[]
+
****
// tag::components[]
Платформа::
Предоставляет функции сервера {dv}, обязательна для установки на сервер {dv}.

Служба Windows:::
Компоненты системы, предоставляющие службу Сервера {dv}, обязательна для установки на сервер {dv}.

Расширение консоли управления:::
Расширение добавляет связанные с модулем ресурсы локализации, обработчики, специализированные редакторы для настройки сервера приложений и БД из {of-mc}, обязательно для установки на сервер {of-mc}.

{fs}::
Выполняет отложенные операции удаления бинарных данных файлов из внешних хранилищ и перемещает данные между хранилищами, обязателен для установки на сервер {dv}.

Служба Windows:::
Компоненты {of-fs}, предоставляющие службу Файлового сервиса, обязательна для установки на сервер {dv}.

Расширение консоли управления:::
Расширение добавляет связанные с модулем ресурсы локализации, обработчики, специализированные редакторы (при наличии) для настройки сервера приложений и БД из {of-mc}, обязательно для установки на сервер {of-mc}.

Сервис полнотекстового поиска::
Передает в {mssql} Server или во внешнюю систему полнотекстового поиска {es} данные, требующие построения полнотекстовых индексов, обязателен для установки на сервер {dv}.

Служба Windows:::
Компоненты {of-fs}, предоставляющие службу полнотекстового поиска, обязательна для установки на сервер {dv}.
// end::components[]

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****

include::6.1@platform:admin:partial$install.adoc[tags=commands]

[source,json]
----
{
  "DocsVision": {
    "Platform": {
      "Server": {
        "Databases": {
          "alias": "Database-connection-string" <.>
        }
      }
    }
  }
}
----
<.> Строка подключения к БД, подробнее см. в разделе "xref:config-platform.adoc#conn-string[Конфигурация модуля {pl}]".

+
:wt: fulltextservice
include::6.1@platform:admin:partial$install.adoc[tags=commands]

. {blank}
