Когда сервер {dv} работает под управлением ОС семейства Linux, отдельно устанавливать модуль не требуется, модуль устанавливается автоматически при установке модуля {pl} следующей командой:

 $ sudo apt-get install docsvision-platform

Установка клиентской части из инсталлятора в ОС Windows потребуется только при использовании {wincl}а. Подробно процесс описан <<client,ниже>>.
