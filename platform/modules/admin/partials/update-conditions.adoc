[#conditions]
== Условия обновления

* При обновлении разных серверов компоненты модуля должны быть одной версии.
* Версии *всех* серверных и клиентских компонентов должны быть одинаковыми.
* Обновление должно выполняться в нерабочее время.
* Перед обновлением создайте резервную копию БД {dv}.
* Если в БД {pgsql} используется pgAgent, остановите планировщик дол начала обновления.
* Перед обновлением убедитесь в наличии {net-r}, подробнее см. "xref:ROOT:requirements-software.adoc[]".
* База данных {dv} должна быть переведена на работу с расширенными метаданными.
