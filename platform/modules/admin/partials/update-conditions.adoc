[#conditions]
== Условия обновления

* При обновлении разных серверов компоненты модуля должны быть одной версии.
ifndef::manacons,solmgr[]
* Версии *всех* серверных и клиентских компонентов должны быть одинаковыми.
endif::manacons,solmgr[]
* Обновление должно выполняться в нерабочее время.
ifdef::sservice[]
* Перед обновлением создайте резервную копию БД {of-sett-serv}.
endif::sservice[]
ifndef::manacons,solmgr[]
* Перед обновлением создайте резервную копию БД {dv}.
endif::manacons,solmgr[]
* Если в БД {pgsql} используется pgAgent, остановите планировщик до начала обновления.
ifndef::manacons,solmgr[]
ifeval::["{update}" == "platform"]
* Перед обновлением убедитесь в наличии {net-r}, подробнее см. "xref:ROOT:requirements-software.adoc[]".
endif::[]
ifndef::solmgr,sservice[]
* Обновите версию модуля на всех узлах кластера {dv}.
endif::solmgr,sservice[]
endif::manacons,solmgr[]
