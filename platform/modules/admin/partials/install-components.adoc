[NOTE]
====
Выбирайте необходимые компоненты в зависимостми от настраиваемого сервера. На основном сервере {dv} обязательно должны быть установлены "Серверные компоненты" модуля. Для работы модулей, устанавливаемых отдельно (например, {mc}, Служба {ws}, {wc} и т.д.), достаточно устанавливать только расширения (при наличии) и общие компоненты. См. "Требования к системе {dv}" в разделе "xref:ROOT:requirements.adoc[]", чтобы определить связь с другими модулями.

Выбранные компоненты сохраняются при обновлении модуля, т.е. выбирать компоненты повторно при обновлении не потребуется. Если все модули установлены вместе, достаточно выбрать компоненты только при первой установке.
====
