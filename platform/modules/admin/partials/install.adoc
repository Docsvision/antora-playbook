// tag::install[]
. Установите серверные компоненты {of} следующей командой, предварительно обновив индекс пакетов:
// tag::commands[]
+
[tabs]
====
{os1}::
+
[source,bash,subs=attributes]
----
sudo apt-get update
sudo apt-get install docsvision-{wt}
----

{os2}::
+
[source,bash,subs=attributes]
----
sudo dnf makecache
sudo dnf install docsvision-{wt}
----
====
// end::commands[]
// end::install[]
+
ifndef::no-config[]
+
. Приоритетным способом настройки системы является {mc}, но настройки в конфигурационном файле `{config}.json` имеют приоритет перед Консолью управления, см. подробнее "xref:6.2@mgmtconsole:servers:index.adoc[]" в документации {of-mc}. Это сделано с целью оставить возможность постепенного перехода от настройки модулей через конфигурационные файлы к конфигурации через {mc}.
endif::no-config[]
