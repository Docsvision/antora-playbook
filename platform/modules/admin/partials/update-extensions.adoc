[#ext-linux]
== Обновление {what-ext} на сервере под управлением Linux

.Чтобы установить новую версию:
. Обновите компоненты {what-ext} на сервере Linux командой:
+
[tabs]
====

{os1}::
+
[source,subs=attributes]
----
sudo apt-get update
sudo apt-get install --only-upgrade 'docsvision-ext-{update}*'
----

{os2}::
+
[source,subs=attributes]
----
sudo dnf makecache
sudo dnf update 'docsvision-ext-{update}*'
----

{os3}::
+
[source,subs=attributes]
----
sudo apt-get update
sudo apt-get install --only-upgrade=true 'docsvision-ext-{update}*'
----

====

[#ext-windows]
== Обновление {what-ext} на сервере под управлением Windows

. На сервере {of-mc} запустите инсталлятор `{installer}`.
. На шаге выбора компонентов выберите компонент "Расширение консоли управления" и нажмите *Далее*.
. Нажмите на кнопку *Установить* и дождитесь завершения установки модуля.
. Нажмите на кнопку *Готово*, чтобы закрыть мастер установки.
