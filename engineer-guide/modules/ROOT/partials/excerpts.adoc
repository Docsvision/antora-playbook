.Условия работы коннектора:
****
* Для работы коннектора авторизации ALD Pro не требуется дополнительных опций лицензии.
* Авторизация с помощью ALD Pro поддерживается в {dv} при установке модуля {mo} {cu253-mo-req}.
// * Для работы LDAPS сертификат, используемый на контроллере домена, должен быть доверенным. Корневой сертификат недоверенного сертификата потребуется установить в хранилище "Доверенные корневые сертификаты" на машине с сервисом, использующим LDAPS.
* Если база данных была создана, но не использовалась, перед использованием коннектора необходимо завести как минимум одного сотрудника в справочнике сотрудников и авторизоваться под ним в {wc}е.
// * Для аутентификации при использовании коннектора к LDAPS необходимо указывать учётные данные пользователя в стандартном формате Active Directory: `domain\user`.
* При использовании конфигурации с несколькими контроллерами, объединенными через балансировщик нагрузки, необходимо использовать сертификат с указанием домена в формате `*.domain.com`. Альтернативный вариант -- в конфигурационном файле сервиса указать адрес балансировщика в параметре `LdapServerAddresses`.
****
