= {dv} Server Console ({cns})


// tag::old-console[]
[TIP]
====
* Начиная с {pl-cu-mc}, основным инструментом настройки системы является {mc}, {cns} по-прежнему доступна с ограниченной функциональностью и в режиме обратной совместимости, однако теперь является частью пакета утилит {rk}.
* До версии {pl-cu-mc}, {cns} устанавливается вместе с модулем {pl}.
====
// end::old-console[]
{dv} Server Console ({cns}) предназначается для выполнения следующих задач:

// * xref:manage-licenses.adoc#personalLicense[Управление] персональными лицензиями.
* xref:db-settings.adoc[Просмотр] списка баз данных {dv} и базы по умолчанию.
* xref:section-security-report.adoc[Получение] отчёта по безопасности.
* xref:section-folder-rights.adoc[Настройка] дискреционных прав на папки.
* xref:folder-views.adoc[Выбор] представлений для папок.
* xref:full-text-service.adoc[Настройка] сервиса полнотекстового индексирования.
