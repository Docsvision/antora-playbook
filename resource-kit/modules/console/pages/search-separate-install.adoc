= Установить сервис полнотекстового индексирования отдельно

Сервис полнотекстового индексирования при необходимости может быть установлен отдельно от сервера {dv} на любой компьютер организации, перед установкой ознакомьтесь с требованиями "xref:new-admin-console@install-linux:ROOT:requirements-full-text-indexing.adoc[]" для Linux и "xref:new-admin-console@installguide:ROOT:requirements-full-text-indexing.adoc[]" для Windows.

Отдельная установка сервиса полнотекстового индексирования позволяет снять часть связанной с индексированием данных нагрузки с сервера {dv}.

.Чтобы отдельно установить сервис полнотекстового индексирования:
. Установите серверную часть модуля {pl} на отдельный компьютер.
+
WARNING: В списке устанавливаемых компонентов модуля должны быть выбраны все компоненты.
+
// .Набор компонентов модуля {pl}
// image::admin:install-server-components.png[Набор компонентов модуля {pl}]
+
При завершении установки снимите флаг `*Запустить "Мастер настройки {dv}" после установки*`.
+
. Настройте учётную запись сервиса полнотекстового поиска на данном компьютере "xref:new-admin-console@install-linux:ROOT:requirements-full-text-indexing.adoc[]" для Linux и "xref:new-admin-console@installguide:ROOT:requirements-accounts.adoc#fulltext[Требования для отдельной установки сервиса полнотекстового индексирования]" для Windows.
. На компьютере с сервером {dv} откройте _{cns}_.
+
WARNING: Учётная запись, от имени которой запущена _{cns}_, должна иметь права на запись и чтение в ветку реестра `{hklm-dv}\` на компьютере, куда устанавливается сервис полнотекстового поиска.
