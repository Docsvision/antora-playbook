= Изменить параметры подразделения из группы

.Чтобы изменить параметры включённого в группу подразделения:
. Нажмите кнопку *Редактировать организацию/подразделение* image:buttons/edit-partner-dept.png[Изменить подразделение контрагента].
. В открывшемся окне измените необходимые параметры и нажмите кнопку *ОК*.
