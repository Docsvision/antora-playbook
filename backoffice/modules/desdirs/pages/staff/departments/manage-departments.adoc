= Подразделения

Подразделения создаются внутри xref:staff/companies/manage-companies.adoc[организаций] компании.

Подразделению можно настроить специальный xref:staff/departments/new-department.adoc#select-kind[вид карточки], который будет использоваться для хранения информации о данном подразделении и входящих в него сотрудниках.

Для просмотра информации о подразделении в справочнике можно настроить xref:staff/displayed-fields.adoc[способ отображения полей].
