= Список файлов задания

== Назначение

Элемент отображает список файлов, полученных во время согласования или подписания, предоставляет возможность предварительного просмотра и редактирования.

Чтобы активировать элемент управления, необходимо его назвать определённым образом (см. название в разметке карточки, где он используется по умолчанию).
