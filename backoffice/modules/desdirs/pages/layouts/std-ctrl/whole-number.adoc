= Целое число

== Назначение

Элемент предназначен для добавления в разметку карточки поля ввода, принимающего только целые числа. Число можно ввести вручную или выбрать значение с кнопок, расположенных в правой части поля.

Каждые 3 символа числа, состоящего из 4 и более символов разделяются знаком, который в настройках Microsoft Windows определён как разделитель групп разрядов.

[NOTE]
====
Параметр *Разделитель групп разрядов* настраивается для выбранного языка в _Панели управления_ Windows в подразделе _Язык и региональные стандарты_. Разделитель настраитвается отдельно для каждой используемой локализации.
