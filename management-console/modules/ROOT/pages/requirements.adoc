[#separate]
== Требования для установки на отдельную машину

Модуль Служба {ws} может устанавливаться на отдельную от сервера {dv} машину, см. "xref:admin:install.adoc[]". При этом к данной машине выдвигаются дополнительные требования.

.На отдельном сервере должны быть установлены :
* Общие компоненты модуля _{sett-serv}_ {cu261-ws-req}.
* Общие компоненты модуля _Служба {ws}_ {cu261-sett-serv-req}.
* Общие компоненты модуля {ad} {cu261-ad-req}.
* Общие компоненты модуля {bo} {cu261-bo-req}.
* Общие компоненты модуля {dm} {cu261-dm-req}.
* Общие компоненты модуля {pl} {cu261-pl-req}.
* Общие компоненты модуля {wf} {cu261-wf-req}.
* Расширение консоли управления для Службы {ws} {cu261-ws-req}.
* Расширение консоли управления для модулей {pl} и {fs} {cu261-pl-req}.
* Расширение консоли управления для {wc}а {cu261-wc-req}.
* Расширение консоли управления для модуля {wf} {cu261-wf-req}.
