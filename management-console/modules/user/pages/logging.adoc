.Пользовательский раздел документации {of-mc}
****
Для {mc} поддерживается два типа журналов:

* "xref:logs.adoc[Журналы работы приложения]" -- сюда относится журнал {of-mc} и {of-sett-serv}, предназначенные для отслеживания состояния служб, диагностики проблем и анализа причин сбоев. Журнал сохраняется в виде файла и хранится в файловой системе сервера {dv}.
* "xref:admin-log.adoc[Журнал действий администратора]" -- содержит события взаимодействия с самой консолью.
