[#page]
== Страница "Открытые сессии"

Страница содержит информацию по всем открытым сессиям для выбранного соединения. Данные на странице будут обновлены при обновлении страницы или фильтрации при помощи кнопок в заголовке. По умолчанию сортировка данных в таблице на странице выполнена по времени входа пользователя. Чтобы отсортировать данные таблицы по столбцу, нажмите на заголовок столбца.  Попасть на страницу можно только из виджета _Открытые сессии_.

Учитываются все лицензии независимо от их типа, пользовательские подключения и подключения сервисов {dv} (например, подключения СУБП).

Таблица "Открыте сессии"::
В верхней строке таблицы представлены кнопки фильтрации: *Онлайн* и *Офлайн*. При нажатии на одну из кнопок в таблице будут отображены только сессии с соответствующим статусом. Данные в таблице по умолчанию отсортированы по столбцу _Время входа_, нажмите на заголовок любого столбца, чтобы включить сортировку по нему.
+
Правее расположена кнопка *Закрыть выбранные* для удаления выбранных строк сессий.
+
.Таблица представлена следующими колонками:
* Флаг image:buttons/checkbox.png[Чекбокс] для выбора сессии. Чтобы закрыть сессию (сессии), выберите строку (строки) при помощи флагов в левой части и нажмите кнопку image:buttons/black-urn.png[Урна].
* Статус -- индикатор текущего состояния сессии. Зелёный -- сессия онлайн, красный -- сессия офлайн.
* Пользователь -- учетная запись пользователя, занимающего сессию, соответствует UserID. Если учетная запись пользователя не найдена, отображается сам ID.
* Компьютер -- имя компьютера, с которого выполнен вход пользователя.
* Время входа -- дата и время создания сессии.
* Время бездействия -- срок неактивности сессии (время обновляется при обновлении страницы или фильтрации при помощи кнопок в заголовке).
