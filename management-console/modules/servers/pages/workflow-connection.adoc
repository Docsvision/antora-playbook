= Группа настроек "Подключение"

Данный раздел документации {of-mc} описывает группу настроек подключения модуля {wf} к серверу приложений.

include::partial$excerpts.adoc[tags=mc-extension]

Подключение к серверу приложений настраивается в {of-mc} на странице menu:Серверы[Имя-сервера > {wf} > Подключение к серверу приложений]. Интерфейс страницы настроек модуля {wf} представлен в виде списка. Поля и компоненты настроек представлены универсальными компонентами редактирования.

[#appserver]
:parameter: ServiceUrl
Сервер приложений::
Раскрывающийся список, позволяющий выбирать зарегистрированный сервер приложений, к которому подключается сервис "{wf}". По умолчанию Сервер приложений в списке не выбран, в качестве заполнителя отображается название настройки: "Сервер приложений"footnote:[
include::partial$excerpts.adoc[tags=analog-param]
].
Обязательно укажите Сервер приложений в списке и примените настройки, чтобы параметры "<<handling,Доля процессов>>" и "<<mail-conn,Почтовое соединение>>" стали активными.

:proga: {cns}", раздел "{wf}
[#handling]
Доля процессов::
С помощью компонента редактирования можно настроить пропорции распределения бизнес-процессов для каждой БДfootnote:[
include::partial$excerpts.adoc[tags=analog-program]
].
Чтобы список БД обновился, выберите другой <<appserver,Сервер приложений>> и примените настройки.
+
Для каждой БД в поле вводится число, определяющее относительную нагрузку на сервис Workflow от `0` до `1000`. Например, при доле `0` сервис {wfs-new} не обрабатывает БП, при долях `3` и `4` нагрузка делится как `43%` на `57%` Для БД, назначенной по умолчанию, добавляется тэг "БД по умолчанию".

:module: {wf}
:parameter: WorkflowServer
[#mail-conn]
Почтовое соединение::
Блоки с раскрывающимся списком для выбора почтового соединенияfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] конкретной БД (БД, назначеная по умолчанию, обозначается тэгом "БД по умолчанию"). В блоке настроек отображаются имена почтовых соединений, xref:user:connections-mail-server.adoc[настроенных для Службы {ws}].
+
Если значение в списке не выбрано, используется почтовое соединение по умолчанию для данного экземпляра модуля {wf}. Если в сервисе настроек почтовые соединения недоступны, вместо списка отображается текст: `Нет доступных почтовых соединений`.
+
Чтобы список БД обновился, выберите другой <<appserver,Сервер приложений>> и применените настройки.

:parameter: WorkflowServer
[#default-mail]
Почта по умолчанию::
В списке отображаются названия почтовых соединенийfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] из xref:user:connections-mail-server.adoc[сохранённых в Сервисе настроек]. Выбранное в списке соединение назначается почтовым соединением по умолчанию для данного экземпляра модуля {wf}. Если соединение по умолчанию выбрано, оно будет использоваться. Если в сервисе настроек почтовые соединения недоступны, вместо списка отображается текст: `Нет доступных почтовых соединений`.

:parameter: APIKEY
API-ключ для подключения к серверу::
Используется для аутентификации в API данного сервиса {wf} Сервера приложенийfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Можно оставить значение по умолчанию или изменить, главное условие, чтобы значения в конфигурации модулей {pl} и {wf} были одинаковые. Обязательная настройка.

:parameter: SystemUserAccount
Имя системного пользователя::
Имя системной учётной записи {dv}footnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Обязательная настройка.

:parameter: SystemUserPassword
Пароль системного пользователя::
Парольfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] системной УЗ для взаимодействия с Сервером приложений, рекомендуется хранить в зашифрованном виде, см. подробнее в документации по установке системы, раздел "xref:install-linux::appendix/account-protection.adoc[]". Обязательная настройка.

[#cert-stamp]
:parameter: DataProtectCertificateThumbprint
Штамп сертификата шифрования паролей::
Отпечаток закрытого ключа шифрования SHA1footnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Указывается без двоеточия, например, `D8602179888DC8402B393F11DCA16A3376DDF879`, см. подробнее в документации по установке системы, раздел "xref:install-linux:ROOT:appendix/account-protection.adoc[]". +
Если шифровать пароль системной учётной записи не планируется, параметр можно не указывать.

:parameter: MemorySize
Лимит памяти, Мбайт::
Объем оперативной памяти, выделенной для сервиса Управления процессамиfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Минимальное значение `4096` Мб.
