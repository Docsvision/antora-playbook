= Страница "Домен" для создания доменного каталога

// tag::no-title[]
.Страница создания нового доменного каталога в {of-mc}
image::6.2@mgmtconsole:servers:appserver-catalogs-full.png[Страница создания нового доменного каталога в {of-mc}]

CAUTION: Настройки на этой странице повторяют параметр "Catalogs" в конфигурационных файлах модуля {pl} и {wc} и являются обязательными к заполнению (если это не было выполнено ранее).

Страница создания нового доменного каталога открывается по нажатию кнопки *Новый каталог* под таблицей _Настройка доменных каталогов_ в группе настроек "Управление доступом" для Сервера приложений и "Подключение" для {wc}а. Страница содержит полный список полей для создания доменного каталога.

.Следующие настройки необходимо заполнить:
Доменный каталог::
* _Полное имя домена_ -- имя домена в формате `example.com`.
* _NetBios-имя домена_ -- имя домена в формате `EXAMPLE`.
* _Переадресация_ -- перенаправление запросов от выбранного домена к каталогам указанного домена.
+
Переадресация должна указывать на существующий каталог в настройках доменных каталогов. Целевой каталог должен отличаться от того, с которого выполняется переадресация.

Подключение к LDAP каталогу::
* _Адреса серверов LDAP_ -- поле для указания адресов LDAP серверов данного домена. Чтобы добавить адрес, введите его в поле и нажмите кнопку *Добавить*.
* _Таймаут_ -- время ожидания ответа LDAP сервера в миллисекундах.
* _Порт_ -- порт подключения к LDAP серверу.
* _LDAPS_ -- настройка определяет, будет ли использоваться протокол LDAPS для безопасного обмена данными. Установите флаг, чтобы разрешить LDAPS, снимите флаг чтобы запретить. По умолчанию значение не задано.
* _Тип аутентификации в LDAP_ -- использовать базовую или расширенную аутентификацию.
* _Логин_ -- логин пользователя для подключения к LDAP-каталогам текущего домена в формате `\user@example.com`.
* _Пароль_ -- пароль пользователя для подключения к LDAP-каталогам текущего домена.
