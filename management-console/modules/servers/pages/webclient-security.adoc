= Группа настроек "Безопасность"

Настройки безопасности и защиты от попыток автоматического перебора пароля пользователя при входе в систему.

[#captcha]
== Капча

Количество неудачных попыток ввода пароля::
Максимальное количество неудачных попыток входа, после которого требуется ввод капчи. Значение должно быть не менее 1.

Время сброса счетчика неудачных попыток, сек::
Время, через которое сбрасывается счётчик неудачных попыток входа при отсутствии новых попыток. Значение должно быть не менее `60` секунд.
