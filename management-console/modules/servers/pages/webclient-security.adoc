== Капча

:module: {wc}
:parameter: MaxFailedLoginAttempts
Количество неудачных попыток ввода пароля::
Максимальное количество неудачных попыток входа, после которого требуется ввод капчи. Значение должно быть не менее 1footnote:[
include::partial$excerpts.adoc[tags=analog-param]
].

:module: {wc}
:parameter: FailedLoginAttemptsTTL
Время сброса счетчика неудачных попыток, сек::
Времяfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
], через которое сбрасывается счётчик неудачных попыток входа при отсутствии новых попыток. Значение должно быть не менее `60` секунд.

Неудачные попытки входа и срабатывания капчи попадают в журнал {wc}а. Попытки входа будут записаны в журнал при уровне журналирования как `Error` и серьёзнее, срабатывания капчи будут записаны в журнал при уровне `Warn` и серьёзнее.
