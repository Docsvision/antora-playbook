Активная лицензия отображается в верхней части страницы настроек сервера. Начиная с {mc-lic-act-req}, чтобы активировать лицензию или изменить текущий лицензионный ключ, нажмите кнопку *Активировать ключ*/*Изменить ключ*, см. <<activate,подробнее ниже>>.

Параметры лицензии перечислены в списке "Параметры используемой лицензии".

.Параметры лицензии
image::appserver-license.png[Параметры лицензии]

Ниже располагается область управления лицензиями, в которой можно назначить или удалить лицензии для определённых пользователей.

[#personal-license]
== Назначение персональной лицензии

Количество пользовательских подключений к серверу {dv} ограничено лицензией. После исчерпания пула конкурентных лицензий (за которые конкурируют пользователи), новые пользователи не смогут войти в {dv}.

Чтобы предоставить определённому пользователю возможность подключаться к {dv} независимо от наличия свободных конкурентных лицензий, нужно назначить ему персональную лицензиюfootnote:[Назначение персональных лицензий ранее выполнялось с помощью программы {cns}].

[WARNING]
====
Чтобы иметь возможность назначать персональные лицензии, в лицензии {dv} должна быть дополнительная опция _{dv} Personal (VIP) Licenses_. Общее число пользователей, которым может быть назначена персональная лицензия, указано в примечании к опции _{dv} Personal (VIP) Licenses_.
====

.Чтобы назначить персональную лицензию:
. Откройте menu:{mc}:[Серверы > Имя-сервера > Сервер приложений > Управление лицензиями].
. Нажмите на кнопку *Добавить*.
. Выберите учётную запись пользователя, которому назначается лицензия.
+
В список _Персональные лицензии_ будет добавлена персональная лицензия для выбранной учётной записи.

.Чтобы освободить назначенную персональную лицензию:
. Найдите строку учётной записи, персональную лицензию которой необходимо освободить.
. Нажмите на кнопку image:buttons/urn.png[Урна].
+
Персональная лицензия будет освобождена, учётная запись будет удалена из списка.
+
. {blank}
+
[subs="specialchars,attributes,quotes"]
После изменения списка персональных лицензий нужно перезапустить службу Сервера {dv}, а также клиентские приложения {wincl}, {wc}.
+
[WARNING]
====
Если пользователь, имеющий персональную лицензию, работает под своей учётной записью на двух или более компьютерах, то при втором и последующих соединениях он получит их из пула конкурентных лицензий.
====

[#activate]
== Активация лицензии из {of-mc}

Основным способом активации системы, в {mc} {mc-lic-act-req}, является указание ключа из web-интерфейса. Поддерживается онлайн- и офлайн-активация.

.Чтобы активировать лицензию или изменить лицензионный ключ:
. Откройте {mc} на menu:Настройки сервера[Сервер приложений], перейдите к блоку настроек _Лицензии_.
. Нажмите кнопку:
+
* Если требуется активировать лицензию, нажмите кнопку *Активировать ключ*.
* Если требуется изменить текущую лицензию, нажмите кнопку *Изменить ключ*.
+
. В окне _Активация лицензии_ выберите способ активации лицензии при помощи переключателей и заполните соответствующие поля:
+
* <<online,Онлайн-активация>>.
* <<offline,Создать запрос офлайн-активации>> (офлайн-активация).
+
.Окно "Активация лицензии"
image::GBL-4070@mgmtconsole:servers:online-activation.png[Окно "Активация лицензии"]
+

[#online]
=== Онлайн-активация лицензии

При выборе опции *Онлайн-активация* будет выполнена активация системы через сеть интернет. В окне активации лицензии проверьте и заполните следующие поля:

* _Адрес сервиса активации_ -- официальный URL сервиса активации лицензии {dv} подставляется автоматически.
* _Серийный номер продукта_ -- полученный от {dv} серийный номер лицензии системы.
+
Лицензионный ключ состоит из шести блоков, в каждом блоке по четыре буквы латинского алфавита или цифры. Значение можно ввести вручную или вставить из буфера обмена.

Нажмите кнопку *Выполнить*. При нажатии кнопки проверяются введённые данные. В случае возникновения ошибки, текст ошибки будет выведен в окне активации.

Если ключ корректен, все поля заполнены действительными данными и сервис активации доступен, лицензия будет активирована.

[#offline]
=== Активация лицензии офлайн

При выборе опции *Создать запрос офлайн-активации* будет создан запрос на офлайн-активацию. В окне активации лицензии заполните поле:

* _Серийный номер продукта_ -- лицензионный ключ, полученный от {dv}.

.Создание запроса офлайн-активации
image::GBL-4070@mgmtconsole:servers:offline-activation.png[Создание запроса офлайн-активации]

Нажмите кнопку *Выполнить*. При нажатии кнопки проверяются введённые данные, в случае возникновения ошибки, текст ошибки будет выведен в окне активации.

После успешной проверки введённых данных формируется файл запроса активации с именем вида: `request-activation_ГГММДД_ЧЧММСС.xml`. В зависимости от настроек браузера файл будет сохранён в папку загрузок или пользователю будет предложено выбрать место сохранения. Сразу после скачивания файла окно активации закрывается.

Воспользуйтесь сервисом офлайн-активации по адресу `https://activate.docsvision.com/index`.

include::GBL-4070@mgmtconsole:servers:partial$excerpts.adoc[tags=saved-and-restart]

Файл запроса активации также можно передать в службу лицензирования {dv} для получения <<response-file,файла ответа>>.

[#response-file]
==== Загрузка ответа на запрос офлайн-активации

При выборе опции *Загрузить ответ офлайн-активации* будет показано поле для выбора файла ответа офлайн-активации.

* Выберите из файловой системы файл ответа на запрос офлайн-активации нажав левой кнопкой мыши в поле _Файл ответа активации_.

.Загрузка ответа офлайн-активации
image::GBL-4070@mgmtconsole:servers:offline-activation-response.png[Загрузка ответа офлайн-активации]

Выбрать можно только один файл с расширением `.xml`.

После успешной проверки формата выбранный файл передаётся Серверу приложений. Дальнейшая проверка структуры, содержимого и соответствия файла запросу офлайн-активации выполняется существующим механизмом лицензирования {dv}.
