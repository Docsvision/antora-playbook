= Группа настроек "Работа с файлами"

Группа настроек "Работа с файлами" содержит параметры, регулирующие размер прикладываемых файлов, размер карточки, настройки предпросмотра и другие.

+

:module: {wc}
:parameter: AcceptableFileExtensionsForEditing
Разрешённые для редактирования файлы::
По умолчанию {wc} предлагает возможность открывать в стороннем ПО файлы следующих форматов: `.doc`, `.docx`, `.docm`, `.xls`, `.xlsx`, `.xlsm`, `.ppt`, `.pptx`, `.odt` и `.ods`. Данная функциональность доступна только, если установлено соответствующее ПО, позволяющее открывать файлы на редактирование, а также если пользователь установил и запустил _DVWebTool_ или _DVSupService_.
+
При необходимости администратор может расширить список поддерживаемых форматовfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
], которые можно будет открывать на редактирование при условии, если необходимое ПО установлено на компьютере пользователя. В настройке указываются поддерживаемые форматы через символ `|` в виде регулярного выражения, например `(\b)(doc|...|xodp)$`.
+
NOTE: С добавленными форматами функциональность открытия на редактирование может работать некорректно.
+
include::partial$excerpts.adoc[tags=slash]

:module: {wc}
:parameter: MaxUploadFileItemSize
Максимальный размер прикладываемого файла, байт::
В {wc}е по умолчанию действует ограничение, влияющее на возможность прикладывания файлов большого размера. По умолчанию максимальный размер файла, прикладываемого при создании карточки, равняется 52428800 байт (50 Мб).
+
Администратор системы может изменить действующее ограничениеfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
], установив размера единичного файла в байтах, не превышающий `2147483647`.

:module: {wc}
:parameter: MaxRequestBodySize
Максимальный размер карточки, байт::
Ограничение для максимального размера тела http-запроса. По умолчанию значение приблизительно равняется `28600000` байт (28,6 Мб). При необходимости ограничить сетевой запрос администратор может указать новое значениеfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
], не превышающее `4294967295` байт (4294.97 Мб). `0` -- отсутствие ограничения.

:module: {wc}
:parameter: MaxPreviewFileSize
Максимальный размер файлов для предпросмотра, байт::
В {wc}е по умолчанию действует ограничение предпросмотра файлов больше `100` Мб. Увеличение значения повысит нагрузку на сервер и время открытия файла на предпросмотр. Администратор системы может изменить действующее ограничениеfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Значение указывается в байтах.

:module: {wc}
:parameter: FilePreviewMode
Компонент для предпросмотра::
Параметрfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] управляет возможностью предварительного просмотра:
+
* *Предпросмотр отключен* -- предпросмотр файлов в {wc}е будет недоступен.
* *Предпросмотр с помощью Р7* -- для предпросмотра будет использоваться компонент "Р7-Офис".

[#r7-office]
== Настройка Р7-Офис

"Р7-Офис. Сервер документов"/OnlyOffice расширяет стандартную функциональность, позволяя отображать документ напрямую и копировать данные непосредственно из файла.

:module: {wc}
:parameter: ServerR7ConnectionAddress
Адрес сервера документов Р7-Офис/OnlyOffice::
URLfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] сервера документов Р7-Офис/OnlyOffice. Если URL сервера документов Р7 не указан, остальные настройки будет проигнорированы.

:module: {wc}
:parameter: ServerR7UploadDirectory
Каталог загрузки консолидируемых файлов::
Каталогfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] на сервере Р7-Офис, в который временно будут загружаться консолидируемые файлы.

:module: {wc}
:parameter: ServerR7SecretToken
Секретное слово::
Работа с Р7-Офис сервер документов для консолидации и предварительного просмотра поддерживает авторизацию с помощью токена, что является более безопасным вариантом стандартного режима работы. Чтобы настроить авторизацию с помощью токена, укажите секретное слово для использования Р7-Офис. Допускается указывать используя только цифры и буквы латинского алфавита.

Настройка Р7-Офис при помощи {of-mc} подробно описана на странице "xref:webclient-r7.adoc[]".
