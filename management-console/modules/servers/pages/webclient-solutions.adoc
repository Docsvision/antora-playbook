== Инструменты импорта решений

Каждая строка таблицы содержит сведения о решении, загруженном в БД.

.Страница настроек "Решения"
image::webclient-solutions.png[Страница настроек "Решения"]

.Страница настроек "Решения"
[cols="34,66", frame=none, grid=none]
|===

|Колонка "Идентификатор решения"
|Системный идентификатор решения.

|Колонка "Название"
|Отображаемое имя конкретного решения, загруженного в выбранную БД.

|Колонка "Версия"
|Версия загруженного в выбранную БД решения.

|Кнопка image:buttons/urn.png[Урна]
|Удаляет выбранное решение из базы данных. При нажатии кнопки удаления появляется модальное окно подтверждения с сообщением: `Подтвердите удаление` и кнопками *Ок*/*Отмена*.

|Кнопка "Импортировать решение"
|Импортирует в БД решение из файла XML. При нажатии на кнопку открывается окно файловой системы для выбора xml-файла или zip-архива решения и последующего импорта. Решения импортируются в конкретную базу. После импорта решения появляются в таблице с указанными данными: идентификатор, название, версия.

|Кнопка "Импортировать стандартные решения"
|Импортирует в БД все версии решений из menu:Каталога {wc}а[LayoutSolutions].

|===

После импорта в таблице появляется новая строка с данными решения. Импортированные решения отображаются в таблице, соответствующей определённой БД. Операции импорта или удаления решений запускаются сразу и не требуют применения настроек на странице, однако для завершения импорта потребуется время.

== Загрузка стандартных решений

include::partial$excerpts.adoc[tags=solutions]

.Чтобы загрузить стандартные решения:
. Выберете подключенную БД для загрузки стандартных решений.
. {blank}
+
[subs="specialchars,attributes,quotes"]
Нажмите на кнопку *Импортировать стандартные решения*. Если файлов стандартных решений в папке {solutions} не оказалось, при попытке импорта появится окно с ошибкой: `Произошла непредвиденная ошибка. Файлы стандартных решений по пути ... не найдены`.
+
Если база данных {dv} содержит решения более ранних версий, аналогичные загружаемым, существующие решения будут обновлены.
+
[NOTE]
====
Если к {wc}у подключено несколько БД, решения необходимо поочередно загрузить во все требуемые базы данных.
====
+
Кнопка импорта остаётся неактивной до завершения загрузки. Загруженные в БД решения отобразятся в таблице, редактировать информацию о решении нельзя.

[#import-other]
== Загрузка прочих решений

include::partial$excerpts.adoc[tags=solutions]

Помимо загрузки всех стандартных решений администратор может загрузить отдельные решения из файлов.

.Чтобы загрузить решения в БД:
. Выберите БД, в которую будут загружены решения.
. Нажмите на кнопку *Импортировать решения*.
. Выберите файл с данными решения:
+
Импортируемое решение может быть файлом или пакетом. Чтобы импортировать файл, выберите его из файловой системы, чтобы импортировать пакет, выберите из файловой системы предварительно упакованный архив в формате `.zip`.
+
При повторном импорте одного и того же решения его данные будут перезаписаны.
+
Одновременно может загружаться только одно решение. Кнопка импорта остаётся неактивной до завершения загрузки, загруженные решения появятся в таблице после обновления страницы, редактировать информацию о решении нельзя.

[#remove]
== Удаление решений

Для удаления решения из БД нужно выбрать его в списке решений и нажать на кнопку image:buttons/urn.png[Урна]. При нажатии на кнопку возникает окно для подтверждения операции с сообщением `Подтвердите удаление` и кнопками *Ок* и *Отмена*.
