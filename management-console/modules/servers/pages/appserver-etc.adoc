[#setting]
== Пример указания настроек на странице

.Дополнительные настройки Сервера приложений
image::appserver-etc.png[Дополнительные настройки Сервера приложений]

Пример указания дополнительных настроек на странице приведён ниже. Любая настройка имеет свой путь, например, menu:{dv}[Platform > Server > LogFile]. В поле _Ключ_ указывается полный путь настройки через двойное подчёркивание: `&#95;&#95;`. В поле _Значение_ указывается значение настройки, например, путь к файлу журнала сервера.

.Пример указания пути к файлу журнала сервера:
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;LogFile` -- _Ключ_
* `/var/log/docsvision/appserver/dvappserver.log` -- _Значение_

.Настройка уровня журналирования
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;TraceLevel&#95;&#95;LogLevel` -- _Ключ_
* _Значение_:
** `0` -- журналирование не ведётся
** `1` -- Error
** `2` -- Warning
** `3` -- Info
** `4` -- Verbose
** Если значение не задано, по умолчанию используется `1`

[#some-settings]
== Некоторые дополнительные настройки

Настройки из списка ниже не были перенесены в интерфейс, а также по умолчанию были удалены из конфигурационного файла. Доступны только два способа задать настройки: указать их на странице "Дополнительные настройки" или самостоятельно прописать их в конфигурационном файле Сервера приложений (модуля {pl}).

* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;BaseFileLocationPath` -- альтернативный путь до схем карточек.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;DBScript` -- флаг использования альтернативного пути до схем карточек.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;CacheTreshold` -- числовой порог выполнений поискового запроса по `.xml` (динамический поиск) до его преобразования в сохранённый.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;CustomOperationsTimeout` -- при включенном режиме отслеживания медленной сети параметр задает порог длительности сложных операций. Если время операции превышает этот лимит, значит, она выполняется дольше предполагаемого. К сложным операциям относятся поиски, представления, изменение настроек безопасности, копирование карточек, папок и похожие.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;DBLcid` -- язык создания базы.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;FileCacheMaxFilesCount` -- максимальное количество файлов в кэше быстрого доступа сервера.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;FileCacheSize` -- размер кэша файлов быстрого доступа сервера. Значение указывается в процентах размера системного диска: от 0 до 100.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;NetworkControlEnabled` -- включает режим отслеживания медленной сети.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;SimpleOperationsTimeout` -- при включенном режиме отслеживания медленной сети задает порог длительности простых операций. Если время операции превышает этот лимит, значит, она выполняется дольше предполагаемого.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;SqlCommandTimeout` -- таймаут в секундах выполнения любой команды к БД.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;UpdateSessionCacheTimeout` -- интервал в секундах очистки кэша сессий от офлайн или закрытых сессий.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;UserInfoCacheMode` -- флаг использования кэша `UserInfo`.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;ViewKeysetLimit` -- максимальное количество строк в кейсетном представлении.
* `{dv}&#95;&#95;Platform&#95;&#95;Server&#95;&#95;ResultLimit` -- ограничить результаты поискового запроса
