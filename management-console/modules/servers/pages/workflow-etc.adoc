[#setting]
== Пример указания настроек на странице

.Дополнительные настройки модуля {wf}
image::webclient-etc.png[Дополнительные настройки модуля {wf}]

Пример указания дополнительных настроек на странице приведён ниже. Любая настройка имеет свой путь, например, menu:{dv}[Workflow > WorkflowServer > BaseName]. В поле _Ключ_ указывается полный путь настройки через двойное подчёркивание: `&#95;&#95;`. В поле _Значение_ указывается значение настройки, например, путь к файлу журнала.

.Пример настройки пути к файлу журнала:
* `{dv}&#95;&#95;Workflow&#95;&#95;WorkflowServer&#95;&#95;BaseName` -- _Ключ_
* `DBname` -- _Значение_

.Пример настройки сертификата для шифрования и подписания:
* `{dv}&#95;&#95;Workflow&#95;&#95;WorkflowServer&#95;&#95;thmb` -- _Ключ_
* `путь-к-сертификату` -- _Значение_
