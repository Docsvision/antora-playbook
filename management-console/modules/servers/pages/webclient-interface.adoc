= Группа настроек "Интерфейс"

При запуске {wc}а будет открыто основное окно с главной страницей. Настройки в данной группе регулируют внешний вид и поведение элементов интерфейса данной страницы.

[#appearance]
== Внешний вид

:parameter: DefaultButtonPosition
Порядок следования кнопок::
Переключает взаимное расположение кнопок *ОК* и *Отмена* в диалоговых окнах и разметках {wc}аfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Расположение кнопок может определяться автоматически в зависимости от операционной системы (пункт *Определять автоматически*) или быть задано вручную одним из переключателей.
+
* *Автоматически* -- значение по умолчанию -- порядок отображения кнопок определяется типом ОС пользователя: *Отмена*/*OK* для ОС MacOS, *ОК*/*Отмена* для ОС Windows, Linux, Android и др.
* *ОК, Отмена* -- *ОК*/*Отмена*
* *Отмена, OK* -- *Отмена*/*ОК*

:parameter: UXMainMenuBehavior
Закрепление основного меню::
По умолчанию основное меню {wc}а с деревом папок закрепляется/открепляется с помощью кнопок image:webclient:admin:buttons/pin-menu.png[Закрепить меню]/image:webclient:admin:buttons/unpin-menu.png[Открепить меню]. Администратор может переключить режим закрепления основного меню переключателем *Закреплять кнопкой "Скрепка"* или *Закреплять кнопкой "Гамбургер"*. Основное меню будет закрепляться/открепляться при нажатии кнопки image:webclient:admin:buttons/open-menu.png[Открыть меню]. При этом кнопки открепления/закрепления основного меню будут скрыты.

:parameter: HideSidebarOnPageClick
Скрытие боковой панели::
На правой боковой панели отображаются параметры отправки документа на согласование, на ознакомление и пр. По умолчанию панель скрывается при нажатии на ней кнопок выполнения: *ОК*, *Отмена* и пр. Когда флагfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] `*Cкрывать при щелчке вне боковой панели*` активирован, режим скрытия боковой панели по щелчку в любой области страницы {wc}а активирован. По умолчанию флаг неактивен.

:parameter: CardTypes
Типы карточек, отображаемые в диалоге создания::
В случае необходимости, администратор системы может настроить диалог создания карточек из {wc}аfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Функциональность даёт возможность отключить, подключить или настроить порядок отображения типов в меню создания, открываемом:
+
--
* При нажатии кнопки *+ Создать* на панели управления.
* При создании карточки с добавлением ссылки из карточек _Документ_ и _Задание_.
--
+
include::partial$excerpts.adoc[tags=mc-extension]
+
.Чтобы настроить меню создания типов карточек, нажмите на строку в таблице "Типы карточек" или нажмите кнопку "Добавить тип":
. Откроется окно настроек конкретного типа с тремя полями для ввода значения:
+
* _Идентификатор_ -- обязательное поле, системный идентификатор типа карточки;
* _CSS-класс_ -- обязательное поле, стиль по умолчанию, используемый для типа карточек;
* _Сохранять в папке_ -- флаг, определяющий необходимость сохранения карточек данного типа в папке;
* _Флаги скрытия_ используются для управления видимостью типа карточки при ее создании. Параметр принимает числовое значение, которое является суммой флагов (цифр). Каждая цифра соответствует определенному варианту скрытия:
+
--
** `0` -- не скрывать.
** `1` -- скрывать тип из списка типов при создании карточки при нажатии кнопки *+ Создать* на панели управления.
** `2` -- скрывать тип из списка типов при создании карточки с добавлением ссылки из карточек _Документ_ и _Задание_, а также при создании карточки в качестве отчёта к _Заданию_.
** `4` -- скрывать тип из списка типов при создании связанного задания карточки _Документ_.
** `8` -- скрывать тип из списка типов при создании подчиненного задания карточки _Задание_.
** `Null` -- значение не задано (значение по умолчанию, типы карточек не скрываются при создании).
--
+
****
Чтобы отключить любую возможность создания карточки _Группа заданий_ из {wc}а, укажите значение *_15_* (= 1+2+4+8). Чтобы скрыть тип карточки _Документ_ из списка типов при создании новой карточки, укажите значение `1`.

WARNING: Настройки скрытия не действуют, когда меню создания карточки вызывается из настраиваемой разметки.
****
+
. Нажмите кнопку *Применить*, чтобы применить выполненные изменения или кнопку *Отмена*, чтобы отменить изменения.
. В каждой строке таблицы отображается кнопка удаления. При нажатии на кнопку удаления появляется модальное окно подтверждения с текстом: `Подтвердите удаление` и кнопками *ОК*/*Отмена*.

Кнопка "Добавить тип"::
Позволяет добавить новый тип карточек в меню создания. При нажатии на кнопку появляется окно с кнопками *Отмена*/*Применить*.
+
При добавлении нового типа поля _Идентификатор_ (системный идентификатор типа карточки) и _CSS-класс_ в окне являются обязательными. Если одно из полей не заполнено, при сохранении появляется красная индикация и надпись _Обязательное поле_.
+
После сохранения в основной табличке появляется новая строка с данными типа.

****
Чтобы изменение цвета строки типа карточки в меню создания работало корректно, к {wc}у должен быть подключен файл стилей с CSS-классом `.Значение-атрибута-CssClass-color`:

[source,css]
----
.document-color {
    background-color: #639;
}
----
****

[#grid]
== Грид

:module: {wc}
:parameter: DisableUnreadCountersGroup
Отключить счётчик непрочитанных карточек::
Проверка непрочитанных карточек может быть отключена для группы пользователейfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Укажите в поле идентификатор группы, для которой необходимо отключить счётчик.

:module: {wc}
:parameter: RefreshTimeout
Время обновления счётчика непрочитанных карточек, сек::
Период обновления данных папок в секундах. Если указанныйfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] интервал равен нулю, автоматическое обновление счётчика не происходит.
+
Значение указывается в секундах, например, `300`.

:module: {wc}
:parameter: ApplyAggregatesButton
Применение фильтров агрегации::
Флаг `*Обновление по кнопке Применить*` определяет, будет ли список карточек обновляться автоматически или перестраиваться по нажатию кнопки *Применить*footnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. +
Доступные агрегаты обновляются согласно настройке _Интервал обновления агрегатов, мс_.
+
Обратите внимание, что для работы функции агрегации необходима опция лицензии _{dv} Модуль Интеллектуальный поиск_.

:module: {wc}
:parameter: ApplyAggregatesTimeout
Интервал обновления агрегатов, мс::
Администратор может настроитьfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] задержку обновления списка карточек и доступных агрегатов при использовании {es}. Данная настройка задаёт интервал по истечении которого миллисекунд будет автоматически обновлён список карточек и доступные агрегаты.
+
Обратите внимание, что для работы функции агрегации необходима опция лицензии _{dv} Модуль Интеллектуальный поиск_.
//
// Количество вариантов агрегата::
// По умолчанию количество выводимых вариантов в агрегате равно 100. максимально возможная настройка `65 536` вариантов.

[#other]
== Прочие

:module: {wc}
:parameter: DeletePermanently
Способ удаления карточек::
По умолчанию карточки из {wc}а удаляются в корзину, папки удаляются временно, но в корзину не попадают. Администратор может включить режим удаления без возможности восстановления при помощи флага ``*Удалять файлы навсегда*``footnote:[
include::partial$excerpts.adoc[tags=analog-param]
].
+
[NOTE]
====
Восстановить удалённые карточки и папки можно только в {wincl}е.
====

:module: {wc}
:parameter: FeedbackUrl
Адрес формы обратной связи::
Определяетfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
] адрес формы обратной связи для пункта "Пройти опрос". Если значение не задано, меню "Пройти опрос" не отображается в пользовательском меню.
