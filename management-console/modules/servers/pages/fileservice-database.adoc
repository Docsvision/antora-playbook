Кнопки действия:::
* Кнопка *Отключить* -- удаляет БД из списка используемых Файловым сервисом.
* Кнопка *Подключить* -- нажатие на кнопку открывает окно выбора новой БД из списка сохранённых в Сервисе настроек. Базы, которые уже подключены к текущему файловому сервису, не отображаются в списке.
+
Окно подключения БД содержит список баз данных с указанием _Псевдонима_, _Сервера приложений_, для которого настроена БД и флагами выбора. Нажмите *Применить*, чтобы подтвердить выбор БД или *Отмена*, чтобы отменить подключение.

.Окно подключения БД для использования в файловом сервисе
image::fileservice-database-connect.png[Окно подключения БД для использования в файловом сервисе]

Если несколько БД (например, для работы в кластере) имеют одинаковую строку подключения, они будут сгруппированы в одной строке:

* Псевдонимы БД могут совпадать, при подключении такой группы в основной таблице отображается общий псевдоним.
* Если псевдонимы БД отличаются, вся строка отображается серым цветом, как неактивная, включая флаг выбора. Такую группу БД выбрать нельзя.
