Кнопки действия:::
* Кнопка *Отключить* -- удаляет БД из списка доступных для пользователей.
* Кнопка *Подключить* -- нажатие на кнопку открывает окно выбора новой БД из списка сохранённых в Сервисе настроек. Базы, которые уже подключены к текущему файловому сервису, не отображаются в списке.
+
Окно подключения БД содержит список баз данных с указанием _Псевдонима_, _Сервера приложений_, для которого настроена БД и флагами выбора. Нажмите *Применить*, чтобы подтвердить выбор БД ли *Отмена*, чтобы отменить подключение.

.Окно подключения БД для использования в файловом сервисе
image::fileservice-database-connect.png[Окно подключения БД для использования в файловом сервисе]

Если несколько БД (например, для работы в кластере) имеют одинаковую строку подключения, они будут сгруппированы в одной строке.

* Если псевдонимы БД совпадают, в окне подключения:
+
--
** В первом столбце отображается общий псевдоним.
** Названия Серверов приложений, на которых зарегистрированы эти базы, отображаются списком в столбик (делать по аналогии со списком адресов подключения в редакторе LdapCatalogs).
** Отображается общее название СУБД для всей группы.
** Отображается общий флаг выбора для всей группы.
--
+
При подключении такой группы в основой таблице отображается общий псевдоним.

* Если псевдонимы БД отличаются:
+
--
** В первом столбце все псевдонимы перечисляются списком через запятую.
** Названия Серверов приложений также отображаются списком один под другим.
** Отображается общее название СУБД для всей группы.
** Вся строка отображается серым цветом, как неактивная, включая флаг выбора. Такую группу БД выбрать нельзя.
** При наведении мыши на строку отображается всплывающая подсказка: `Невозможно подключить базы данных с одинаковой строкой подключения и разными псевдонимами`.
--
