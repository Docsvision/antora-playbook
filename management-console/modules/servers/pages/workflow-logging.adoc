= Группа настроек "Журналирование"

Журнал сообщений сервиса Workflow предназначен для просмотра данных по обработке функций сервисом.

.Группа настроек "Журналирование" СУБП
image::workflow-logging.png[Группа настроек "Журналирование" СУБП]

:module: {wf}
:parameter: menu:WorkflowServer[LogFile]
Файл журнала::
Путь к файлу журнала, в котором фиксируются операции, выполняемые сервисом {wf}footnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. При корректной работе сервиса ведение журнала не обязательно, однако в случае его нестабильной работы журнал может помочь выяснить неполадки и устранить их. Для ведения журнала у учётной записи сервиса Workflow должны быть права на папку, в которой Создаётся журнал.
+
[NOTE]
====
Журнал является средством диагностики при возникновении нештатных ситуаций и предназначен для передачи в службу технической поддержки. Анализ содержимого журнала пользователем или администратором не предполагается. Кроме этого журнала служба технической поддержки может запросить другие данные, которые могут оказаться полезными при анализе нештатных ситуаций.
====

:module: {wf}
:parameter: menu:WorkflowServer[TraceLevel]
Уровень журналирования::
Глубина фиксации процессов в журнале сервиса {wf}footnote:[
include::partial$excerpts.adoc[tags=analog-param]
]. Если предполагается вести журнал, поле _Уровень журналирования_ следует указать глубину фиксации процессов:
+
--
* Отключено
* Ошибки
* Предупреждения
* Информация
* Подробное журналирование
--
+
Каждый последующий уровень журналирования включает в себя сообщения предыдущих уровней. Таким образом, включение режима `*Подробное журналирование*` будет означать так же фиксацию сообщений об ошибках, предупреждениях и информационных сообщениях.
+
[NOTE]
====
Если выбран уровень журналирования с высокой детализацией, за небольшой промежуток времени размер журнала может существенно увеличиться. Таким образом, устанавливать уровень журналирования `*Подробное журналирование*` рекомендуется только при возникновении проблем в работе сервиса или по просьбе технической поддержки {dv}.
====

:module: {wf}
:parameter: menu:WorkflowServer[LogFileDateTemplate]
Форматирование даты::
В поле задаётся задается шаблон (маска) для вывода даты файла журнала в его имени. По умолчанию используется маска `yyMMdd`, она может быть изменена на другую, соответствующую стандарту ISO 8601.. Для определения формата используйте стандартные спецификаторы (например, `D`, `d`, `F`, `g`, `s`, `u` и другие) или их комбинацииfootnote:[
include::partial$excerpts.adoc[tags=analog-param]
].
+
Если формат даты задан, то в `0:00` вывод сообщений перенаправляется в новый файл журнала, имя которого образуется как `ИмяДоПервойТочкиОтформатированнаяДата.ИмяПослеПервойТочки`. Если рассматриваемое поле очищено, журнал сервиса продолжает вестись в прежнем файле.
