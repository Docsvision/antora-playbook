= Настройки {wincl}а и РМА

Категория "Настройки {wincl}а и РМА" описана в "xref:GBL-3644@platform:console:config-client.adoc[]", включая:

* Настройки установки клиентской части решений:
** Адрес расположения документации (только для {wincl})
** Путь к папке, в которой будет создаваться журнал
** Уровень отображения пользовательского интерфейса инсталляций
** Область установки компонентов
* Настройки интерфейса {wincl}а по умолчанию:
** Показывать панели
** Периодичность обновления данных представления
** Не скрывать панель инструментов Internet Explorer
** Язык интерфейса
** Производительность

Категория "Настройки кэширования и производительности" описана в "xref:GBL-3644@platform:console:section-server.adoc[]", включая:

* Включить счетчики производительности
* Режим кэширования
* Очистить клиентский кэш

Категория "Управление доступом" описана в "xref:GBL-3644@platform:console:manage-access.adoc[]", включая:

* Использовать протокол
* Адрес сервера {dv}
* Адрес сайта при подключении через внешнюю сеть или по HTTP
* Запретить встроенную аутентификацию
