== Прерывание, закрытие и продолжение конфигурирования БД

После запуска мастера выполнение операции с БД будет продолжено в фоновом режиме и может быть закрыт кнопкой image:buttons/x-db-master.png[Крестик]. Если мастер был закрыт до шага подтверждения обновления или создания БД, будет выведено сообщение вида: `Подтвердите сохранение шага для продолжения конфигурирования базы данных` и кнопками *Ок* / *Отмена*. Кнопка *Отмена* отменяет незавершённые шаги, а кнопка *ОК* -- сохраняет.

После подтверждения процесса {process} будет запущено, что обозначается появлением полосы загрузки и кнопкой *Прервать*. Нажатие кнопки вызовет диалоговое окно с предупреждением `При прерывании операции создания база данных останется в промежуточном состоянии. Завершить конфигурацию будет невозможно. Продолжить?`. Выбор кнопки *Отмена* закроет диалоговое окно, процесс {process} не будет прерван. Кнопка *ОК* подтверждает намерение перрвать {process}.
