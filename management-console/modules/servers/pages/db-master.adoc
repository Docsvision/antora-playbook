= Мастер баз данных

Мастер БД {dv} -- инструмент _{of-mc}_, с помощью которого можно выполнить следующие операции:

* xref:db-create.adoc[Создать новую БД {dv}].
* xref:db-connect.adoc[Подключить существующую БД {dv}].
* xref:db-update.adoc[Обновить базу данных {dv}].

.Таблица БД {dv}
image::db-master.png[Таблица БД {dv}]

Мастер БД предназначен для запуска создания или обновления баз данных. После запуска мастера выполнение операции с БД будет продолжено в фоновом режиме. По завершении процесса появится всплывающее сообщение о завершении создания/обновления БД. Нажатие на сообщение откроет страницу мастера на нужном шаге.

.При открытии мастера для продолжения конфигурации БД отображается актуальный статус процесса БД:
. Если БД ещё обновляется, отображакется полоса прогресса.
. Если создание БД завершилось ошибкой, будет отображена ошибка.
. Если обновление БД завершилось успешно, пользователь будет оповещён об этом, и сможет перейти к следующему шагу с загрузкой решений.

Мастер Бд может быть закрыт до завершения процесса создания/обновления БД кнопкой image:buttons/x-db-master.png[Крестик]. Если мастер был закрыт до подтверждения обновления БД (шаг 2), будет выведено сообщение вида: `Подтвердите сохранение шага для продолжения конфигурирования базы данных` и кнопками *Ок* / *Отмена*. После нажатия *Отмена*, незавершённый шаг будет отменён (отправляется запрос на удаление текущего шага из БД сервиса настроек). После нажатия *ОК* текущий несохранённый шаг будет сохранён.
