= Мастер баз данных

Мастер БД {dv} -- инструмент _{of-mc}_, с помощью которого можно выполнить следующие операции:

* xref:db-create.adoc[Создать новую БД {dv}].
* xref:db-connect.adoc[Подключить существующую БД {dv}].
* xref:db-update.adoc[Обновить базу данных {dv}].

Мастер БД -- это таблица, каждая строка которой представляет отдельную БД, мастер предназначается для создания, обновления и подключени баз данных, настройки свойств, просмотра текущего состояния, отключения и других действий.
