[#params]
== Настройки группы хранилищ

.Чтобы настроить параметры группы хранилищ:
. В поле _Название группы_ введите уникальное имя для новой группы хранилищ.
. В списке _Режим выбора_ выберите правило, по которому сервер приложений {dv} будет выбирать из группы целевое хранилище для размещения бинарных данных:
+
* *_Самое заполненное хранилище_* -- выбирать наиболее заполненное хранилище (для поочередного заполнения хранилищ группы).
* *_Самое свободное хранилище_* -- выбирать наименее заполненное хранилище (для равномерного распределения данных по хранилищам).
* *_Случайный порядок_* -- выбирать хранилище случайным образом.
+
. Если данная группа хранилищ должна по умолчанию использоваться для определённых типов файлов, установите флаги в области _Использовать по умолчанию для следующего типа файлов_:
+
--
* _Основные_ -- бинарные данные файлов, не являющихся архивными или временными.
* _Архивные_ -- бинарные данные файлов карточек, помещённых в архив.
* _Временные_ -- бинарные данные файлов, которые ещё не загружены, но находятся в процессе загрузки в {dv}.
* _Офлайн_ -- бинарные данные файлов, вытесняемых в офлайн.
--
+
[NOTE]
====
Для одной группы можно установить несколько флагов типов файлов, однако каждый нельзя установить один и тот же тип файлов для нескольких групп. Если флаг уже установлен у одной из групп, он автоматически сбрасывается при включении этого флага у другой группы.
====

[#edit]
== Изменение настроек группы хранилищ

.Чтобы изменить настройки группы:
. Выберите группу в списке _Группы хранилищ_, нажмите на её название.
. Измените и сохраните настройки.
+
Тип группы хранилищ не может быть изменён.

[#delete]
== Удаление группы хранилищ

.Чтобы удалить группу хранилищ:
. Найдите группу хранилищ в списке и нажмите на кнопку image:buttons/x.png[Крест] в правой части строки.
+
При удалении группы появляется окно с сообщением: `Вы уверены, что хотите удалить группу хранилищ?` и кнопками *Да* / *Нет*. После подтверждения группа удаляется из списка. Хранилища, добавленные в группу не затрагиваются.
+
[WARNING]
====
Перед удалением группы хранилищ убедитесь, что она не используется по умолчанию для хранения типов файлов и не выбрана в правилах.
====
