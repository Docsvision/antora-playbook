= Группа настроек "Виды карточек"

Элементы в группе настроек предназначены для настройки видов карточек, с которыми по умолчанию будут создаваться новые карточки соответствующих типов.

] представлена блоком с именем БД и таблицей с двумя колонками: _Тип карточки_, _Вид по умолчанию_. В таблице отображаются типы и виды пользовательских карточек по умолчанию, настроенные для БД. Если к системе подключено больше одной БД, отображается несколько блоков с таблицами для каждой БД. В заголовке таблицы отображается название базы данных и признак `БД по умолчанию` (если она является базой по умолчанию).

В колонках _Тип карточки_, _Вид по умолчанию_ отображается список типов карточек {wc} и их видов по умолчанию, которые будут использованы при создании новых карточек.

Под таблицей, в секции _Дополнительно_, отображаются два дополнительных поля: _Вид карточки для ссылки файл_ и _Корневой вид для заданий КС_.

Элементы в колонке _Вид по умолчанию_ и секции _Дополнительно_ могут быть выбраны нажатием. При выборе открывается окно с деревом видов, соответствующих конкретному типу и кнопками *Выбрать* и *Отмена*. Вид, который уже назначен подсвечивается цветом.

.Дерево видов карточек
image::webclient-kinds-tree.png[Дерево видов карточек]

Узлы дерева могут быть свёрнуты и раскрыты, если у них имеются дочерние виды. Удалить или отредактировать тип нельзя.
