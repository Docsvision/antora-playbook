= Настроить правила помещения в хранилище

Администратор должен настроить правила, в соответствии с которыми файлы будут распределяться между группами хранилищ.

.Настроенное для хранилища правило не будет действовать, если:
* Указанная в правиле группа не содержит активных хранилищ, см. "xref:db-storage-add-to-group.adoc[]".
* Группа хранилищ не назначена по умолчанию для какого-либо типа файлов, см. "xref:db-storage-default-group.adoc[]".
* Для файла существует более приоритетное правило выше по списку.

[#params]
== Настройки правила помещения в хранилища

.Чтобы настроить параметры правил помещения в хранилища:
. В поле _Название_ введите уникальное имя правила. Название правила должно быть уникальным. Если название совпадает с другим, при сохранении появляется ошибка: `Правило с таким названием уже существует`.
. В раскрывающемся списке _Группа_ выберите группу хранилищ, которая будет выбираться согласно данному правилу:
+
* *_Common_* -- общая группа хранилищ.
* *_Temp on FileSystem group_* -- хранилище в файловой системе.
+
. В раскрывающемся списке _Тип_ выберите тип условия в правиле:
+
* *_Все файлы_* -- условию будет соответствовать любой файл без ограничений.
* *_По расширению файла_* -- условию будет соответствовать файл с определённым расширением. Можно указать несколько расширений.
* *_Размер файла больше, чем_* -- условию будет соответствовать файл с размером, превышающим заданное значение.
* *_Размер файла меньше, чем_* -- условию будет соответствовать файл с размером, не превышающим заданное значение.
* *_Файл справочника_* -- условию будет соответствовать файл справочника {dv}. Например, файл разметки, файл представления, иконка и другие.
* *_Системный файл_* -- условию будет соответствовать файл с установленным признаком "Системный".
+
Данный тип используется только для системного правила "System files" и отображается только при редактировании этого правила. При создании/редактировании любого другого правила тип скрыт.
+
* *_Собственное правило_* -- алгоритм условия должен быть реализован в выбранном компоненте (файл `.dll`).
+
. Укажите дополнительные настройки правила:
+
--
.Для типа "По расширению файла":
* _Расширение_ файлов, выбираемых по данному условию. Расширения перечисляются через символ `;`.

.Для типа "Размер файла больше, чем":
* _Размер, kB_ -- минимальный размер файлов (в Кб), которые соответствуют условию.

.Для типа "Размер файла меньше, чем":
* _Размер, kB_ -- максимальный размер файлов (в Кб), которые соответствуют условию.

.Для типа "Собственное хранилище":
* Имя сборки -- при выборе варианта *_Собственное хранилище_* появляется поле указания имени сборки в файловой системе. Нужно указать только имя сборки, полный путь указывать не требуется. Если тип был изменён, строка исчезает.
--

[#priority]
== Изменение приоритета использования правила

Правила применяются последовательно сверху вниз. Перетащите правило наверх, чтобы повысить его приоритет. Если условия выполняются одновременно в нескольких правилах, будет выбрана группа хранилищ из правила с более высоким приоритетом.

[#edit-rule]
== Изменение настроек правила

.Чтобы изменить настройки правила:
. Выберите правило в столбце _Правила помещения в хранилища_ и нажмите на его название.
. В появившемся окне отредактируйте и сохраните изменения. Изменить тип правила нельзя.

[#delete-rule]
== Удаление правила

.Чтобы удалить правило:
. Найдите правило в списке _Правила помещения в хранилища_ и нажмите на кнопку image:buttons/x.png[Крест] в правой части строки. При нажатии кнопки удаления появляется окно с сообщением: `Вы уверены, что хотите удалить правило?` и кнопками *Да* / *Нет*.
. После подтверждения правило удаляется.
