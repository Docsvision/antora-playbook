= Назначить базу данных по умолчанию

include::dev@mgmtconsole:servers:partial$excerpts.adoc[tags=maindb]

.Чтобы назначить имеющуюся базу данных основной:
. Откройте страницу menu:Серверы[Имя-сервера > Сервер приложений > Базы данных].
+
.БД по умолчанию в таблице БД
image::dev@mgmtconsole:servers:db-default.png[БД по умолчанию в таблице БД]
+
. Для нужной базы данных в столбце _По умолчанию_ нажмите кнопку *Назначить*.
. Кнопка *Назначить* изменяется на иконку image:dev@mgmtconsole:servers:buttons/db-default.png[Галочка], кнопка *Отключить* становится недоступной, активируются кнопки *Применить* и *Отмена*, а также кнопка обновления таблицы.
. Нажмите *Применить*, чтобы сохранить настройки. База данных будет назначена основной, веб-сервер {dv} будет работать с ней по умолчанию. При выборе *Отмена* изменения будут отменены.
+
Перезапустите службу Сервера {dv}.
