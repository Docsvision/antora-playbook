= Расширенная аутентификация

{dv} {wc} поддерживает авторизацию с помощью поддерживает авторизацию с помощью сторонних расширений OpenID. Необходимые ресурсы для работы расширений авторизации в {wc}е поставляются с модулем {pl} и настраиваются в конфигурационном файле модуля или в {of-mc}.

****
* Данный раздел посвящён регистрации расширений авторизации в Linux с помощью {of-mc} версии {page-version}.
* Создание собственных расширений {dv} описывается в разделе "xref:programmer:solutions:extensions/extensions.adoc[]" руководства по разработке.
* Настройка расширений в конфигурационном файле Сервера приложений (модуля {pl}) описана в разделе "xref:engineer::authorization-extensions.adoc[]".
****

.Чтобы добавить расширение, необходимо:
// tag::setup[]
. Откройте {mc} на странице "xref:6.2@mgmtconsole:servers:appserver-auth-extensions.adoc[]" нажмите кнопку *Добавить расширение*.
+
При переходе на страницу настроек расширения аутентификации выводится сообщение с кнопками *Ок* и *Отмена*. При нажатии *Ок* несохранённые изменения на странице будут применены, при нажатии *Отмена* -- отменены.
+
. На странице настроек расширения представлены следующие поля:
+
* Идентификатор расширения -- строка с идентификатором расширения в виде Guid. Идентификатор определяется при разработке расширения. Параметр `Id` в конфигурационном файле расширения.
* Название расширения -- задаёт отображаемое имя сервиса аутентификации.
ifndef::ald[]
Отображается в xref:6.1@webclient:user:directories/staff/employee-fields.adoc#security[справочнике сотрудников].
endif::ald[]
+
.Регистрация нового расширения аутентификации
image::6.2@mgmtconsole:servers:new-auth-extension.png[Регистрация нового расширения аутентификации]
// end::setup[]
+
* Настройки -- строка настроек расширения в неотформатированном виде. Подробнее см. ниже, например <<esia,ЕСИА>>.
+
include::partial$excerpts.adoc[tags=use-cryption]
+
* Тип -- строка с именем типа, реализующего расширение. Параметр `TypeName` в конфигурационном файле расширения.

[#tenants]
== Настройка расширений для тенантов

Таблица, предназначенная для включения/отключения расширений, доступных в базах данных. Таблица имеет только одну колонку "Доступные расширения" и флаг включения/отключения расширения напротив каждой строки.

.Активация зарегистрированных расширений аутентификации
image::auth-extensions-activation.png[Активация зарегистрированных расширений аутентификации]

В таблице отображается список расширений, которые были зарегистрированы в системе и <<setup,настроены>>. Над таблицей отображается название базы данных. Для базы, которая назначена по умолчанию, добавляется тэг "БД по умолчанию".
