= Особенности SQL- и Windows-аутентификации в БД

При создании новой БД {dv} и подключении существующей БД администратор может выбрать тип проверки подлинности: SQL-аутентификация или аутентификация Windows.

.Настройки подключения базы данных в Консоли настройки {dv}
image::6.1@platform:admin:db-create-parameters.png[Настройки подключения базы данных в Консоли настройки {dv}]

.При выборе SQL-аутентификации:
* Создание и подключение БД будет выполнено от имени учётной записи из поля `Логин` с паролем из поля `Пароль`.
* Сервисы {dv} (кроме СУБП) будут подключаться к БД с использованием учётной записи с указанными данными.

.При выборе аутентификации Windows:
* Создание и подключение БД будет выполнено от учётной записи пользователя, запустившего _{cns}_.
* Сервисы {dv} (кроме СУБП) будут подключаться к БД с использованием учётных записей, от имени которых данные сервисы запущены.
* {blank}
+
[subs="specialchars,attributes,quotes"]
Сервисам сервера {dv} -- пулу приложений _DefaultAppPool_ и службе {sss-new} -- будет автоматически назначена учётная запись из поля `Логин` с паролем из поля `Пароль`.

Если планируется подключать xref:db-storage.adoc[внешнее хранилище] _FileStream хранилище в базе данных {dv}_, БД {dv} должна быть подключена с использованием аутентификации Windows.
