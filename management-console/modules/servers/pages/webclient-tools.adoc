= Группа настроек "Инструменты"

Группа настроек "Инструменты" содержит параметры _DVWebTool_ и _DVSupService_.

.Группа настроек "Инструменты"
image::webclient-tools.png[Группа настроек "Инструменты"]

Порт подключения::
Общая настройка для DVWebTool и DVSupService, задаёт порт для подключения. Минимальное значение: `1`, максимальное значение: `65535`, значение по умолчанию: `5413`.
+
.Порт должен совпадать со значениями, указанными:
* В конфигурационном файле DVSupService, см. подробнее раздел "xref:new-admin-console@webclient:admin:scan-settings.adoc#sane[Настройка сканирования]" в документации по администрированию {wc}а.
* При сборке DVWebTool, см. подробнее раздел "xref:new-admin-console@webclient:admin:webservices-install.adoc[]" в документации по администрированию {wc}а.

Время жизни токена доступа, сек::
Срок действия токена. По умолчанию время жизни составляет `300` секунд (5 минут).

Допустимая погрешность часов при проверке времени жизни, сек::
Допустимая погрешность часов при проверке времени жизни токена. Значение прибавляется к сроку действия токена. По умолчанию значение составляет `300` секунд (5 минут).

[#dvt]
Автоматическое закрытие DVWebTool::
Настройка регулирует поведение утилиты DVWebTool после выполнения действия. Поведение по умолчанию: не закрывать.
