= Назначить группу хранилищ по умолчанию

Группы хранилищ по умолчанию должны быть назначены для всех типов файлов: основного, архивного, временного и офлайн.

Группа хранилищ по умолчанию для определённого типа файлов должна иметь как минимум одно хранилище. В это хранилище должно быть разрешено сохранять файлы данного типа.

. Нажмите на строку группы хранилищ, которая должна использоваться по умолчанию для типов файлов.
+
.Настройки группы хранилищ
image::db-external-storage-group-settings.png[Настройки группы хранилищ]
+
. В появившемся окне установите флаги напротив типов файлов, для которых по умолчанию должна использоваться данная группа. Группа хранилищ будет по умолчанию использована для хранения соответствующих типов файлов.
+
Каждый тип файлов может быть назначен только одной группе по умолчанию. Если тип файлов был выбран ранее для другой группы, при сохранении настроек новой группы значение перезаписывается на новое. Если группа была выбрана ранее, в ней флаг будет снят.
+
. Убедитесь, что группа хранилищ, имеющая хранилища для основных файлов, назначена группой по умолчанию для вытесняемых в офлайн файлов и, при необходимости, назначьте группу
