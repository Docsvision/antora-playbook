== Пример. Хранилище файлов в {location}

Далее приведён пример настройки хранилища файлов {dv} в {location}.

include::partial$excerpts.adoc[tags=openStorageSettings]
+
. Подключите к {dv} хранилище в {location}, см. подробнее в разделе "xref:db-storage-setup.adoc[]".
+
. В поле _Название_ введите `{s-name}` или любое другое название.
. В списке _Тип_ выберите значение *_{type}_*.
. В поле _Путь к файловой системе_ укажите каталога в файловой системе для сохранения бинарных данных файлов. Указывается путь к каталогу на сервере, где установлен Сервер приложений. Пример для Linux: `/var/tmp/`.
+
include::partial$excerpts.adoc[tags=twobasesonepath]
+
. В списке _Состояние_ выберите значение *_Онлайн_*.
. Укажите значение в поле _Макс. размер_, по умолчанию не указан. При установке и снятии курсора в поле автомтически подставится `0`.
+
Когда объём хранилища закончится, попытка добавления файла в него завершится ошибкой.
+
// .Чтобы избежать ошибок, ограничьте размер хранилища:
// ** В поле _Макс. размер_ укажите примерный объем свободного места, который доступен для FileStream.
// ** В списке _Состояние_ выберите значение *_Определять автоматически_*.
// +
. Флаги настройки разделов установите по собственному усмотрению. Флаг `*Временный раздел*` рекомендуется снять.
+

.Пример настройки хранилища в {location}
image::{s-img}.png[Пример настройки хранилища {location}]
+
. Создайте группу хранилищ см. подробнее в разделе "xref:db-storage-setup-group.adoc[]".
+
.Параметры группы настройте следующим образом:
* В поле _Название_ введите `{sg-name}` или любое другое название.
* В списке _Режим выбора_ выберите *_Самое свободное хранилище_*.
* Флаги в области _Использовать по умолчанию для следующего типа файлов_ установите по собственному усмотрению.
+
.Пример настройки группы хранилищ
image::{sg-img}.png[Пример настройки группы хранилищ]
+
NOTE: Новую группу можно не создавать, если включить хранилище в существующую группу.
+
. Включите хранилище `{s-name}` в группу `{sg-name}` перетаскиванием из столбца хранилищ в столбец групп хранилищ и настройте правила помещения файлов в группу хранилищ, см. подробнее в разделах "xref:db-storage-add-to-group.adoc[]" и "xref:db-storage-setup-rule.adoc[]".
+
.Пример настройки правила для группы хранилищ "{sg-name}"
image::{r-img}.png[Пример настройки правила для группы хранилищ "{sg-name}"]
+
--
.Параметры правила настройте следующим образом:
* В поле _Название_ введите `{r-name}` или любое другое название.
* В списке _Группа_ выберите значение *_{sg-name}_*.
* В списке _Тип_ выберите значение *_Все файлы_* или конкретизируйте параметры файлов (см. рисунок ниже), которые будут размещаться в хранилище.
+
.Пример настройки правила для группы хранилищ "{sg-name}"
image::{r-img}-more.png[Пример настройки правила для группы хранилищ "{sg-name}"]
--
+
. Повысьте приоритет использования правила `{r-name}` перетаскиванием его наверх списка.
