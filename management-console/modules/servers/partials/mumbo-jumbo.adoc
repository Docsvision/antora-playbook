// tag::create[]
После подтверждения процесса {process} будет запущено, что обозначается появлением полосы загрузки и кнопкой *Прервать*. Нажатие кнопки вызовет диалоговое окно с предупреждением `При прерывании операции создания база данных останется в промежуточном состоянии. Завершить конфигурацию будет невозможно. Продолжить?`. Выбор кнопки *Отмена* закроет диалоговое окно, процесс {process} не будет прерван. Кнопка *ОК* подтверждает намерение перрвать {process}.
// end::create[]
