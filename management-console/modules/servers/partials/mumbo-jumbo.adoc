// tag::create[]
Запущенный процесс {process} может быть прерван кнопкой *Прервать*. Нажатие кнопки вызовет диалоговое окно с предупреждением `При прерывании операции создания база данных останется в промежуточном состоянии. Завершить конфигурацию будет невозможно. Продолжить?`. Кнопка *Отмена* закроет диалоговое окно, процесс {process} не будет прерван. Кнопка *ОК* подтверждает намерение перрвать {process}.
// end::create[]

// tag::update[]
Запущенный процесс {process} может быть прерван кнопкой *Прервать*. Нажатие кнопки вызовет диалоговое окно с предупреждением `При прерывании операции обновления база данных останется в промежуточном состоянии. Для восстановления работоспособности потребуется восстановить её из резервной копии. Продолжить?`. Кнопка *Отмена* закроет диалоговое окно, процесс {process} не будет прерван. Кнопка *ОК* подтверждает намерение перрвать {process}.
// end::update[]
