= Предоставление доступа к {of-mc}

При работе с Консолью управления выделяется роль _Администратор {of-mc}_. Администратору предоставляется полный доступ ко всем функциям модуля.

Предоставить пользователям доступ к консоли или внесению изменений в настройки _{of-sett-serv}_ можно вручную, изменив конфигурационный файл:

// tag::config[]
[source,json]
----
{
  "Groups": {
    "Docsvision Management Console Administrators": [
      "account@domain.com" <.>
    ]
  }
}
----
<.> Добавьте пользователей, которые должны иметь доступ к {of-mc}.
// end::config[]

ifndef::windows[]
// tag::keytab[]
Сервер {dv}, установленный на Linux, требует дополнительной настройки для использования технологии единого входа (когда пользователь уже аутентифицирован в другом модуле системы). Подробнее настройка описана в Руководстве по настройке системы, см. "xref:new-admin-console@engineer:ROOT:kerberos-authentication.adoc[]".
// end::keytab[]
endif::windows[]
