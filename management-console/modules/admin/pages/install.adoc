Также должны быть выполнены соответствующие настройки в конфигурационном файле модуля, подробнее см. ниже.

[#extensions]
== Установка расширений модулей для {of-mc}

// tag::extensions[]

include::dev@mgmtconsole:user:partial$excerpts.adoc[tags=ext-ver]

Расширения обязательны для установки в версии {of-mc} 6.2 и выше. Для возможности настройки модулей через {mc} необходимо установить их расширения, добавляющие в систему:

* Настройки служб в Консоли, просмотр сообщений -- расширение Службы {ws} для {of-mc}.
* Получение списка локализаций и видов карточек, возможность загрузки новых значений в базу данных, импорт решений -- расширение {wc}а для {of-mc}.
* Связанные с модулем ресурсы локализации, обработчики, специализированные редакторы для настройки сервера приложений и БД из {of-mc} -- расширение сервера приложений для {of-mc}.
* Связанные с модулем ресурсы локализации, обработчики и специализированные редакторы для настройки из {of-mc} (при наличии) -- расширение модуля {wf} для {of-mc}.
* Связанные с модулем ресурсы локализации, обработчики и специализированные редакторы для настройки из {of-mc} (при наличии) -- расширение {of-fs} для {of-mc}.

// tag::register-services[]
[#register-services]
== Регистрация модулей системы

Для возможности настройки модулей системы через интерфейс {of-mc} необходимо, чтобы параметры, перечисленные ниже, были в конфигурационном файле настраиваемого модуля: {pl}, {fs}, {wc}, {wf}.

--
* menu:DocsVision[ServiceId] -- уникальный идентификатор данного экземпляра модуля. Параметр задаётся автоматически при установке модуля.
* menu:DocsVision[SettingsService > ConnectionString] -- адрес подключения к хранилищу настроек. Параметр необходимо указать вручную.
* menu:DocsVision[SettingsService > ApiKey] -- ключ приложения для подключения к хранилищу настроек. Параметр необходимо указать вручную.
--

[subs="specialchars,attributes,quotes"]
Откройте поочерёдно конфигурационные файлы в каталогах модулей {pl}, {fs}, {wc}, {wf} и укажите недостающие параметры в требуемых секциях. Конфигурационные файлы располагаются в каталогах по адресу {config}.

WARNING: После редактирования конфигурационных файлов обязательно перезапустите системные службы!
// end::register-services[]

// tag::cert[]
[#cert]
== Особенности настройки сертификата

Настройка актуальна только для {mssql} Server, для {pgsql} дополнительных настроек не требуется. По умолчанию провайдер считает соединение с БД защищённым.

Если соединение не защищено (т.е. не настроен сертификат на уровне БД, используется самозаверенный или недействительный сертификат), необходимо в строке соединения указывать `TrustServerCertificate = true`, это сообщит провайдеру, что серверу можно доверять.

При необходимости использовать
ifeval::["{sservice}" == "yes"]
xref:dev@mgmtconsole:admin:https-access.adoc[защищённое соединение],
endif::[]
ifndef::sservice[]
xref:./https-access.adoc[защищённое соединение],
endif::[]
настройте {mssql} сервер в соответствии с инструкцией в руководстве по настройке системы, см. подробнее "xref:new-admin-console@engineer:ROOT:create-cert.adoc[]" в руководстве по настройке системы.
// end::cert[]
