[#extensions]
== Установка расширений модулей для {of-mc}

// tag::extensions[]

include::6.2@mgmtconsole:user:partial$excerpts.adoc[tags=ext-ver]

Расширения обязательны для установки в версии {of-mc} {mc-cu-mc}. Для возможности настройки модулей через {mc} необходимо установить их расширения, добавляющие в систему:

* Настройки служб в Консоли, просмотр сообщений -- расширение Службы {ws} для {of-mc}.
* Получение списка локализаций и видов карточек, возможность загрузки новых значений в базу данных, импорт решений -- расширение {wc}а для {of-mc}.
* Связанные с модулем ресурсы локализации, обработчики, специализированные редакторы для настройки сервера приложений и БД из {of-mc} -- расширение сервера приложений для {of-mc}.
* Связанные с модулем ресурсы локализации, обработчики и специализированные редакторы для настройки из {of-mc} (при наличии) -- расширение модуля {wf} для {of-mc}.
* Связанные с модулем ресурсы локализации, обработчики и специализированные редакторы для настройки из {of-mc} (при наличии) -- расширение {of-fs} для {of-mc}.

// end::extensions[]

[#extensions-linux]
=== Установка расширений модулей для {of-mc} на сервер под управлением Linux

// tag::extensions-linux[]
// tag::mc62[]

[CAUTION]
====
В некоторых дистрибутивах и в случаях, когда _{mc}_ установлена на одной машине с Сервером приложений {dv}, расширения добавляются в систему при первичной установке или обновлении _Консоли_.

В {os3} и при установке Консоли на отдельный сервер расширения всегда требуется устанавливать вручную.
====

.Чтобы установить расширения модулей для {of-mc} на сервер под управлением Linux:
. Выполните следующие команды:
+
[tabs]
====
{os1}::
+
[source,bash]
----
sudo apt-get update
sudo apt-get install docsvision-ext-fileservice-mc docsvision-ext-platform-mc docsvision-ext-webc-mc docsvision-ext-workflow-mc docsvision-ext-ws-mc
----

{os2}::
+
[source,bash]
----
sudo dnf makecache
sudo dnf install docsvision-ext-fileservice-mc docsvision-ext-platform-mc docsvision-ext-webc-mc docsvision-ext-workflow-mc docsvision-ext-ws-mc
----
====
// end::mc62[]
+
. Перезапустите службы {dv} для следующих модулей: {fs}, {pl}, {wc}, {wf}, Служба {ws}.

// end::extensions-linux[]

[#register-services]
== Регистрация модулей системы

--
Чтобы настраивать модули системы через интерфейс {of-mc}, необходимо в конфигурационных файлах настраиваемых модулей были указаны параметры, перечисленные ниже.

--
menu:DocsVision[ServiceId]::
Уникальный идентификатор данного экземпляра модуля. Параметр задаётся автоматически при установке модуля.

menu:DocsVision[SettingsService > ConnectionString]::
Адрес подключения к хранилищу настроек. Параметр необходимо указать вручную.

menu:DocsVision[SettingsService > ApiKey]::
Ключ приложения для подключения к хранилищу настроек. Параметр необходимо указать вручную.
--

. {blank}
+
[subs="specialchars,attributes,quotes"]
Откройте поочерёдно конфигурационные файлы в каталогах модулей {pl}, {fs}, {wc}, {wf} и укажите недостающие параметры в требуемых секциях. Конфигурационные файлы располагаются в каталогах по адресу {config}.
+
ifdef::upgrade[]
[WARNING]
====
*Внесение иных изменений в конфигурационные файлы допустимо только после полного завершения всех действий по обновлению системы*,
include::dv6@upgrade:61-mc62:linux/post-config-server.adoc[tags=change-when]
====
endif::upgrade[]
+
. После редактирования конфигурационных файлов обязательно перезапустите соответствующие системные
ifndef::windows[]
службы:

 $ sudo systemctl restart dvappserver dvwebclient dvworkflow dvfileservice

endif::[]
ifdef::windows[]
службы.
endif::[]

Убедиться в успешной регистрации сервисов можно следующим образом: запустить {mc} и открыть страницу menu:Серверы[], выбрать сервер из списка слева. Если для выбранного сервера в правой колонке доступны разделы настроек "Сервер приложений", "Веб-клиент", "Управление процессами" и "Файловый сервис", регистрация выполнена успешно. В противном случае проверьте конфигурацию модулей и перезапустите службы ещё раз.
