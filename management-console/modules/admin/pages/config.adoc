= Первичная настройка {of-mc}

_Администратор {of-mc}_ -- пользователь, добавленный в группу _{dv-web-admin-cns-admins-serv}_ в конфигурационном файле {of-mc}. Администратор имеет полный доступ к изменению настроек Консоли, конфигурации _{of-sett-serv}_, а также ко всем функциям модуля.

WARNING: После сохранения изменений конфигурационного файла обязательно перезапустите службу {of-mc}!

[#access]
== Доступ к {of-mc}

// tag::initial-configuration[]

[subs="specialchars,attributes,quotes"]
Прежде, чем настраивать {mc}, необходимо предоставить пользователям доступ к ней. Предоставьте доступ, отредактировав конфигурационный файл {of-mc} по адресу {config-mc}:

[source,json]
----
{
  "SettingsService": {
    "ConnectionString": "ConnectAddress=http://settings.domain.com:5200/api", <.>
    "ApiKey": "SettingsServiceApiKey" <.>
  },
  "System": {
    "ManagementConsoleAddress": "http://console.domain.com:5100" <.>
  },
  "Catalogs": [], <.>
  "Groups": {
    "Docsvision Management Console Administrators": [
      "account@domain.com" <.>
    ]
  }
}
----
<.> `ConnectionString` -- Адрес {of-sett-serv}.
<.> `ApiKey` -- Ключ доступа к Сервису настроек -- "пароль", который также должен быть указан в конфигурационном файле сервиса и конфигурационном файле {of-sett-serv}.
<.> `ManagementConsoleAddress` -- Адрес {of-mc}.
<.> `Catalogs` -- см. подробнее "<<domain,Настройка работы в домене>>".
<.> `{dv-web-admin-cns-admins-serv}` -- Пользователи, имеющие доступ к Консоли управления. Добавление пользователя в группу *{dv-web-admin-cns-admins-serv}* в конфигурационном файле {of-mc} предоставляет доступ в {mc}.

[subs="specialchars,attributes,quotes"]
Редактирование конфигурационного файла модуля {pl} по адресу {config-pl} даёт пользователям возможность просматривать карточки сообщений в {of-mc}, но не предоставляет доступ в {mc}.

Параметр `Kestrel` в конфигурационном файле {of-mc} позволяет
// tag::kestrel[]
задать URL для доступа к {of-mc}, а также настроить защищённое соединение. Поскольку Консоль версии {mc-cu-mc} является основным инструментом администрирования системы и содержит конфиденциальные данные, для работы рекомендуется использовать защищённое соединение см. подробнее "xref:dv6@engineer:ROOT:https-connection.adoc[]".
// end::kestrel[]

.Фрагмент конфигурационного файла `appsettings.json`:
[source,json]
----
{
  "Kestrel": {
    "Endpoints": {
      "Http": {
        "Url": "http://*:5100" <.>
      }
    }
  }
}
----
<.> URL для доступа к {of-mc}.

[#domain]
== Настройка работы {of-mc} в домене

// tag::config-catalogs[]
[subs="specialchars,attributes,quotes"]
Выполните настройку для работы {of-mc} в одном или нескольких доменах, обеспечив возможность аутентификации. Заполните настройки доменных каталогов в массиве `"Catalogs": []` конфигурационного файла Консоли.

WARNING: Настройки вступают в работу, если в массиве присутствует хотя бы одно описание каталога. Если ни одного каталога не указано, аутентификация в {of-mc} будет недоступна!

[source,json]
----
{
 "Catalogs": [
  {
   "FullDomainName": "example1.com", <.>
    "NetBiosDomainName": "example1", <.>
    "LdapOptions": { <.>
      "LdapServerAddresses": [ "example1.com" ], <.>
      "AuthType": "Basic", <.>
      "Port": 389, <.>
      "Credential": { <.>
        "UserName": "user@example1.com",
        "Password": "Password"
      }
    }
 }, <.>
  {
    "FullDomainName": "example2.com", <.>
    "ChallengeTo": "example1.com" <.>
  }
  ]
}
----
<.> `FullDomainName` -- полное имя домена указывается в формате `user@example.com` учётной записи после `@`.
<.> `NetBiosDomainName` -- `NetBios`-имя домена указывается в формате `domain\\user` перед `\\`.
<.> `LdapOptions` -- настройки подключения к LDAP каталогу домена.
<.> `LdapServerAddresses` -- адреса серверов LDAP данного домена. Если адрес соответствует полному имени домену, параметр можно удалить.
<.> `AuthType` -- тип аутентификации в LDAP.
<.> `Port` -- порт подключения к LDAP каталогам, перечисленным в `LdapServerAddresses`.
<.> `Credential` -- логин и пароль пользователя для подключения к LDAP-каталогам текущего домена. Пароль для подключения можно зашифровать, см. подробнее раздел "xref:dv6@engineer:ROOT:appendix/account-protection.adoc[]" в руководстве по настройке системы.
<.> Следующие настройки являются опциональными.
<.> `FullDomainName` -- полное имя домена указывается в формате `user@example.com` учётной записи после `@`.
<.> `ChallengeTo` -- настройка позволяет переадресовывать запросы от выбранного домена к каталогам указанного домена, см. <<challengeto,далее>>.

[#configuration]
== Настройка соединений в {of-mc}

После установки {mc} требуется выполнить настройку Консоли и _Службы {ws}_.

. Введите в адресной строке браузера адрес {of-mc}, чтобы открыть главную страницуfootnote:[См. подробнее в документации {of-mc}, раздел "xref:6.2@mgmtconsole:user:user-interface.adoc[]"] {of-mc}.
. Перейдите на страницу настроек image:6.2@mgmtconsole:user:buttons/settings.png[Настройки] и xref:./connections-docsvision.adoc[добавьте соединение] к {dv} на вкладке _Соединения_.
. Перейдите на вкладку _Служба {ws}_ и xref:./dvworkerservice.adoc[настройте] процесс Службы {ws}.
. В виджетах на главной страницеfootnote:[См. подробнее в документации {of-mc}, раздел "xref:6.2@mgmtconsole:user:user-interface.adoc[]"] выберите соединение и период статистики.
