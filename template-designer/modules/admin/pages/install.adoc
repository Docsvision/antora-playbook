[#windows]
== Установка на сервер под управлением Windows

. Запустите пакет установки `{dv} TemplateDictionary server` и проследуйте инструкциям мастера установки.
+
. В приветственном окне мастера установки нажмите *Далее*.
+
.Мастер установки модуля "{td}"
image::install-server-hello.png[Мастер установки модуля "{td}"]
+
. Примите условия лицензионного соглашения для продолжения установки и нажмите *Установить*.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Выберите компоненты, которые требуется установить, и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
include::6.1@platform:admin:partial$install-components.adoc[]
+
****
Серверные компоненты:::
Основные серверные компоненты модуля {td}, обязательны для установки на сервер {dv}.

Служба Windows:::
Основные компоненты модуля {td}, предоставляющие базовую функциональность, обязательно для установки на сервер модуля {td}.

Расширение {wc}а::
Обеспечивает взаимодействие с {wc}ом, обязательно для установки на сервер сервер {wc}а.

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****
+
. Нажмите кнопку *Готово*, чтобы закрыть мастер установки.

[#client]
== Установка клиентской части

.Чтобы установить клиентскую часть модуля "{td}":
. Запустите установочный файл `{dv} TemplateDictionary client`, который установит клиентскую часть модуля.
+
.Запуск инсталлятора
image::install-client-hello.png[Запуск инсталлятора]
+
. Примите условия лицензионного соглашения для продолжения установки и нажмите *Далее*.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Нажмите на кнопку *Установить* и дождитесь завершения установки клиентской части.
+
.Подтверждение установки клиентской части
image::install-client-confirm.png[Установка клиентской части]
+
Дождитесь завершения установки.
+
. При необходимости распространите клиентскую часть на машины с {wincl}ом.
