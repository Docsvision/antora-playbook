= Конфигурация {wc}а из {of-mc}

[#minimum]
== Необходимые настройки конфигурационного файла

Ниже перечислены минимально необходимые настройки конфигурационного файла {wc}а. Файл необходимо заполнять в любом случае при свежей установке системы, при обновлении системы с предыдущих версий можно принять решение оставить существующий конфигурационный файл.

. {blank}
+
Убедитесь, что в конфигурационном файле {wc}а по адресу `{webconfig}` указаны описанные ниже настройки. Файл может быть изменён в любом текстовом редакторе (потребуются права суперпользователя/администратора). Настройки в конфигурационном файле:
+
.Фрагмент конфигурационного файла {wc}а:
[source,json]
----
{
  "Docsvision": {
    "ServiceId": "00000000-0000-0000-0000-000000000000", <.>
    "SettingsService": {
      "ConnectionString": "http://localhost:5200/api", <.>
      "ApiKey": "anything" <.>
    }
  }
}
----
<.> `ServiceId` -- уникальный идентификатор данного экземпляра модуля, генерируется и записывается автоматически.
<.> `ConnectionString` -- полный адрес {of-sett-serv}.
<.> `ApiKey` -- API-ключ для подключения к {to-sett-serv}, можно оставить значение по умолчанию или изменить, главное условие, чтобы значения в конфигурации модулей {sett-serv} и {wc} были одинаковые.

[#console]
== Указание настроек в {of-mc}

. Дальнейшие настройки {wc}а выполняются в {of-mc}. Откройте {mc} на странице menu:Серверы[Имя сервера > {wc} > "xref:dev@mgmtconsole:servers:webclient-connection.adoc[Группа настроек "Подключения"]] и настройте следующие параметры:
+
* Сервер приложений -- выберите из раскрывающегося списка, зарегистрированный сервер приложений, к которому будет подключаться служба сервера {wc}а.
* База данных -- БД для работы с {wc}ом. Если поле не заполнено, используется база по умолчанию.
* Имя и Пароль пользователя -- параметры для авторизации системной учётной записи {wc}а.
+
.Группа настроек "Подключение"
image::dev@mgmtconsole:servers:webclient-connection.png[Группа настроек "Подключение"]
+
. Нажмите кнопку *Применить* в правом верхнем углу окна Консоли, чтобы применить настройки {wc}а и перезапустите службу Сервера {wc}а.
. На странице menu:Серверы[Имя сервера > {wc}] откройте группу настроек "Подключение" и убедитесь, что настройки доменных каталогов заполнены корректно. Настройка каталогов для {wc}а повторяет настройку для Сервера приложений, ранее описанную в разделе "xref:./config-domains.adoc[]".
+
* Также укажите параметр "Домен по умолчанию" -- полное имя домена для входа по умолчанию в формате FQDN.
+
. В поле "Домен по умолчанию" укажите полное имя домена для входа по умолчанию в формате FQDN.
. Выполните настройку видов карточек в разделе menu:Серверы[Имя сервера > {wc} > "xref:dev@mgmtconsole:servers:webclient-kinds.adoc[Группа настроек "Виды карточек"]], с которыми по умолчанию будут создаваться новые карточки соответствующих видов.
+
.Группа настроек "Виды карточек"
image::dev@mgmtconsole:servers:webclient-kinds.png[Группа настроек "Виды карточек"]
+
При первом открытии страницы настроек элемент редактирования будет показывать несохранённые изменения, которые будут сохранены после выбора Сервера прилоежний и применения настроек.
+
. В разделе menu:Серверы[Имя сервера > {wc} > "xref:dev@mgmtconsole:servers:webclient-locales.adoc[Группа настроек "Локализации"]] выполните настройку локализаций {wc}а. Флаг в таблице слева от имени локализации включает или выключает её использование в {wc}е и программе {kvr}.
+
.Группа настроек "Локализации"
image::dev@mgmtconsole:servers:webclient-locales.png[Группа настроек "Локализации"]
+
. На странице menu:Серверы[Имя сервера > {wc}] откройте группу настроек "xref:dev@mgmtconsole:servers:webclient-solutions.adoc[Решения]" и выполните импорт решений с разметками карточек, например, импортируйте стандартные решения.
+
.Страница настроек "Решения"
image::dev@mgmtconsole:servers:webclient-solutions.png[Страница настроек "Решения"]
+
. Нажмите кнопку *Применить* в правом верхнем углу окна Консоли, чтобы применить настройки {wc}а и перезапустите службу Сервера {wc}а.
. В {wc}е "Р7-Офис" используется для предпросмотра документов и режима консолидации. При необходимости использования данных режимов, проследуйте инструкции на странице "xref:./webclient-r7.adoc[]".
. DVWebTool устанавливается в ОС Windows, DVSupService -- в Linux. DVWebTool и DVSupService позволяют пользователям {wc}а открывать файлы на редактирование и/или просмотр в офисных редакторах, см. xref:./webservices-install.adoc[руководство по установке].
. При необходимости xref:./webservices-launch.adoc[настройте] параметры запуска DVWebTool и DVSupService.
. После заполнения обязательных настроек рекомендуется xref:dev@mgmtconsole:servers:webclient.adoc[перенести в {mc}] все необязательные параметры, указанные в xref:new-admin-console@webclient:admin:webconfig.adoc[конфигурационном файле {wc}а].
