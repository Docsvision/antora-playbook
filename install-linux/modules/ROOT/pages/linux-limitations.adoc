= Особенности в работе продукта под Linux

.Обратите внимание на следующие пункты:
* Машина c ОС Windows *не* потребуется при настройке системы через основной инструмент -- "xref:6.2@mgmtconsole:ROOT:index.adoc[{mc}]".
* {cns} с ограниченным набором функций поставляется в составе пакета утилит {rk}, подробнее см. "xref:6.1@resource-kit:console:util.adoc[]".
* Для работы с конструктором разметок {wc}а и {wincl}ом всё ещё необходима машина Windows.
* Запуск сканирования документов из браузера поддерживается при использовании сканеров с поддержкой SANE.
// * ABBYY FineReader Engine и функции распознавания документов из карточек модуля (в том числе потоковый ввод документов и распознавание штрих-кодов) не будут работать, если сервер {dv} установлен на Linux.
* Для консолидации и предварительного просмотра файлов на стороне сервера потребуется установка _Р7-Офис. Сервер документов_ или _OnlyOffice_, подробнее см. подробнее "xref:webclient:admin:preview-r7.adoc[]".
* Не поддерживается синхронизация атрибутов карточки и файла.
