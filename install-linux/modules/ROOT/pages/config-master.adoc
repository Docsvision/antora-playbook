= Мастер настройки БД {dv}

Пользователь, выполняющий настройку {dv}, должен являться локальным администратором (быть указанным в файле sudoers).

Если для подключения к СУБД планируется использовать Windows-аутентификацию, у учетной записи, от имени которой запущена {mc}, должны быть следующие права:

[#db-settings]
== Настройка системной БД

.Выполните следующие шаги, чтобы подготовить систему {dv} к работе:
// tag::master[]
. Откройте {mc}.
. Убедитесь, что:
+
* Сервисы {dv} зарегистрированы в {sett-serv}, см. инструкцию по установке соответствующего модуля, например "xref:GBL-3644@platform:admin:config-platform.adoc[Установка модуля {pl}]".
* Пользователь, от имени которого выполняется настройка БД, добавлен в группу безопасности *{dv-web-admin-cns-admins-serv}* xref:dev@mgmtconsole:admin:provide-access.adoc[в конфигурационном файле] {of-mc}.
* Пользователь, настраивающий БД включён в группу *{dv-admins-serv}* на xref:dev@mgmtconsole:servers:appserver-access.adoc#groups[странице настроек] Сервера приложений.
+
. Выполните настройку БД с помощью мастера баз данных:
// end::master[]
// tag::dbase[]
+
.Раздел "Базы данных" Консоли настройки {dv}
image::platform:admin:settings-database.png[Раздел "Базы данных" Консоли настройки {dv}]
+
* Подключите существующую базу данных {dv}, см. инструкцию по подключению существующей БД: "xref:dev@mgmtconsole:servers:db-connect.adoc[]".
+
* Создайте новую базу данных, см. *полную* инструкцию по созданию новой БД: "xref:dev@mgmtconsole:servers:db-create.adoc[]". Ниже приводится *обобщённая* инструкция по созданию БД.

+
// end::dbase[]

image::install-linux::config-sql-server.png[Создание новой БД {dv}]
+
[NOTE]
====
* Для БД {pgsql} адрес сервера следует указывать без домена (например, `postgre` вместо `postgre.company.com`), или указывать IP адрес.
* Порт указывается только для {pgsql} (по умолчанию -- `5432`).
* Особенности работы через SQL- и Windows-аутентификацию см. в документации модуля {pl}, раздел "xref:dev@mgmtconsole:servers:db-authentication.adoc[]".
====
+
. На странице _База данных_ укажите имя создаваемой БД.
+
.Создание новой БД {dv}
image::install-linux::config-sql-create.png[Создание новой БД {dv}]
+
* Не используйте кириллицу, пробелы и спецсимволы в имени БД.
* Для БД {mssql} Server в поле _Язык_ выберите локаль БД, установленную в параметре `Server Collation ()` экземпляра {mssql} Server. Рекомендуемое значение: Русский (Cyrillic_General_CI_AS).
* При выборе СУБД {mssql} Server также можно настроить сателлитные БД. Больше информации о сателлитных БД в разделе "xref:dev@mgmtconsole:servers:db-satellite.adoc[]" документации {of-mc}.
+
WARNING: После создания БД изменять конфигурацию сателлитных БД не рекомендуется. Это может привести к потере данных.
