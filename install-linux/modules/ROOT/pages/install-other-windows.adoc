= Установка серверных компонентов на Windows

[TIP]
====
.*Начиная с версии модулей, входящей в НО 26.1*:
* Когда сервер {dv} под управлением Linux настраивается через {mc}, установка серверных компонентов модулей из инсталляторов `.msi` на машину с ОС Windows *не потребуется*.
* {cns} перенесена в пакет утилит {rk} и используется преимущественно для настройки полнотекстового поиска. Установка пакета утилит описана в разделе "xref:./rk-wctk.adoc[]"
* Подробнее особенности работы в Linux см. в руководстве по установке системы на сервер под управлением Linux, раздел "xref:install-linux::linux-limitations.adoc[]".
====
