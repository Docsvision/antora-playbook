[#locale]
== Проблемы локализации

В некоторых дистрибутивах ОС Linux (например, в {l-6}), если сервер был развёрнут с английской локалью, часть сообщений согласующего могут выводиться с английской локализацией, даже если установлены языковые пакеты. В таком случае после установки  требуется задать системную локаль следующей командой:

 localectl set-locale LANG=ru_RU.UTF-8.
