== Настройки Сервера приложений в {of-mc}

.Заполните параметры доступа к Серверу приложений:
. В разделе "xref:dev@mgmtconsole:servers:appserver-catalogs.adoc[Настройка доменных каталогов]" укажите следующие настройки, см. подробнее "xref:./config-domains.adoc[]":
+
* Заполните таблицу "Настройка доменных каталогов", см. подробнее "xref:./config-domains.adoc[]".
+
.Настройка доменных каталогов в {of-mc}
image::dev@mgmtconsole:servers:appserver-catalogs.png[Настройка доменных каталогов в {of-mc}]
+
* Имя компьютера в текущем домене Active Directory -- используется при получении списка доступных членов домена при настройке дискреционной безопасности.
* Логин системной учётной записи.
+
include::new-admin-console@install-linux:ROOT:partial$excerpts.adoc[tags=system-accounts]
+
* Пароль системной учетной записи.
* Файл журнала и Уровень журналирования -- путь к файлу, в котором регистрируются выполняемые сервером операции.
* API-ключ для подключения к Workflow -- используется для подключения серверного расширения {wf}. API-ключ для подключения серверного расширения {wf}. Главное условие, чтобы значения в конфигурации модулей {pl} и {wf} были одинаковые.
* Штамп сертификата шифрования паролей -- отпечаток закрытого ключа шифрования SHA1. +
Указывается без двоеточия, например, `D8602179888DC8402B393F11DCA16A3376DDF879`, см. подробнее в документации по установке системы, раздел "xref:install-linux::appendix/account-protection.adoc[]". +
Если шифровать пароль системной учётной записи не планируется, параметр можно не указывать.
+
. Нажмите кнопку *Применить* в правом верхнем углу окна Консоли, чтобы применить настройки доменных каталогов и перезапустите службу *{sss-new}*.
. Укажите Логин и Пароль системной учётной записи в соответствующих полях.
. Настройте системные группы пользователей, добавив в каждую группу слева необходимых пользователей из списка справа.
+
.Настройка групп пользователей в {of-mc}
image::dev@mgmtconsole:servers:appserver-groups.png[Настройка групп пользователей в {of-mc}]
+
.Список основных групп пользователей представлен ниже:
--
include::dev@mgmtconsole:servers:appserver-access.adoc[tags=basic-groups]
--
+
NOTE: Первоначальная настройка группы *{dv-web-admin-cns-admins-serv}* выполняется в конфигурационном файле {of-mc}, см. подробнее "xref:./dvconsole.adoc[]".
+
. Нажмите кнопку *Применить* в правом верхнем углу окна Консоли, чтобы применить настройки сервера приложений и перезапустите службу *{sss-new}*.
