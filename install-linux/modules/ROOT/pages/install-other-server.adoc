[#linux-pl]
== Установка модуля {pl} на Linux

После завершения xref:./pre-config-server.adoc[предварительной настройки сервера] установите серверные компоненты модуля, используя команды ниже.

. Установите пакеты модуля {pl} следующей командой, предварительно обновив индекс пакетов:
+
:wt: platform
include::6.1@platform:admin:partial$install.adoc[tags=commands]
+
Вместе с модулем _{pl}_ команда установит серверные компоненты базовых модулей.
+
. Выполните конфигурацию модуля по инструкции в разделе "xref:./config-platform.adoc[]".

[#webc]
== Установка {wc}а

. Установите пакеты модуля:
+
[tabs]
====
{os1}::
+
 $ sudo apt-get install docsvision-webclient

{os2}::
+
 $ sudo dnf install docsvision-webclient
====

[#workflow]
== Установка СУБП

. Установите модуль _{wf}_ следующей командой:
+
[tabs]
====
{os1}::
+
 $ sudo apt-get install docsvision-workflow

{os2}::
+
 $ sudo dnf install docsvision-workflow
====
