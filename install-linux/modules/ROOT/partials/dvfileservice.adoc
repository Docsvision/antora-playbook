[#minimum]
== Необходимые настройки конфигурационного файла

// tag::console[]
[subs="specialchars,attributes,quotes"]
Ниже перечислены минимально необходимые настройки конфигурационного файла {of-fs} по адресу {config}. Файл необходимо заполнять в любом случае при свежей установке системы, при обновлении системы с предыдущих версий можно принять решение оставить существующий конфигурационный файл.

[source,json]
----
{
  "DocsVision": {
    "ServiceId": "00000000-0000-0000-0000-000000000000", <.>
    "SettingsService": {
      "ConnectionString": "http://localhost:5200/api", <.>
      "ApiKey": "anything" <.>
    }
  }
}
----
<.> `ServiceId` -- уникальный идентификатор данного экземпляра модуля, генерируется и записывается автоматически.
<.> `ConnectionString` -- адрес {of-sett-serv}.
<.> `ApiKey` -- API-ключ {of-sett-serv}.

После сохранения изменений в конфигурационном файле перезапустите службу {of-fs}.

== Указание БД из {of-mc}

// tag::console[]
. В {of-mc} перейдите на страницу menu:Серверы[Имя сервера > {fs} > xref:6.2@mgmtconsole:servers:fileservice-database.adoc[Группа настроек "Базы данных"]], чтобы подключить БД к Файловому сервису.
+
.Группа настроек "Базы данных" для файлового сервиса
image::6.2@mgmtconsole:servers:fileservice-database.png[Группа настроек "Базы данных" для файлового сервиса]
+
. Нажмите кнопку *Подключить* под таблицей, чтобы открыть окно подключения БД из доступных к файловому сервису.
+
.Окно подключения БД для использования в файловом сервисе
image::6.2@mgmtconsole:servers:fileservice-database-connect.png[Окно подключения БД для использования в файловом сервисе]
+
. Выберите БД при помощи флага и нажмите кнопку *Применить*.
. Нажмите кнопку *Применить* в правом верхнем углу окна Консоли, чтобы применить настройки модуля и перезапустите службу {of-fs}.
// end::console[]
