= Требования учётной записи файлового сервиса

Перечисленные права должны быть предоставлены учётной записи службы Файлового сервиса.

.Требования на уровне внешнего хранилища:
. Полный доступ на все подключенные внешние хранилища, доступ к которым осуществляется под учётной записью службы.
. Полный доступ к папке `FileStream`, если подключено хранилище FileStream во внешней базе данных {mssql} Server или FileStream хранилище в базе данных {dv}.
