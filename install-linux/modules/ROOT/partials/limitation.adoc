[TIP]
====
* Когда сервер {dv} под управлением Linux настраивается через {mc}, установка серверных компонентов модулей из инсталляторов `.msi` на машину с ОС Windows *не потребуется*.
* {cns} перенесена в пакет утилит {rk} и используется преимущественно для настройки полнотекстового поиска.
* Подробнее про имеющиеся ограничения можно прочитать в руководстве по установке системы, раздел "xref:install-linux::linux-limitations.adoc[]".
====
