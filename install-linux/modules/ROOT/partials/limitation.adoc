[TIP]
====
* При настройке {dv} и создании БД из {of-mc} установка серверных компонентов модулей из инсталляторов `.msi` на машину с ОС Windows не требуется.
* При работе с Консолью настройки {dv} и настройкой БД через неё в ОС семейства Linux потребуется установка серверных компонентов модулей из инсталляторов `.msi` на машину с ОС Windows.
* Подробнее про имеющиеся ограничения можно прочитать в руководстве по установке системы, раздел "xref:install-linux::linux-limitations.adoc[]".
====
