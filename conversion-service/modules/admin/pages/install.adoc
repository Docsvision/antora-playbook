= Установка сервиса конвертации

Пользователь, выполняющий установку {of-cs}, должен обладать правами локального администратора и администратора {dv}.

[NOTE]
====
Администратор {dv} -- пользователь, включенный в группу безопасности *{dv-admins-serv}* в конфигурационном файле Сервера приложений (модуля {pl}).
====

WARNING: Перед установкой ознакомьтесь с разделом "xref:ROOT:requirements.adoc[]".

[#windows-server]
== Установка модуля на сервер под управлением Windows

. Запустите пакет установки `{dv} File conversion service.msi`.
. В приветственном окне мастера установки нажмите *Далее*.
+
.Мастер установки модуля "{am}"
image::install-server-hello.png[Мастер установки модуля "{am}"]
+
. Выберите компоненты, которые требуется установить, и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+
include::6.1@platform:admin:partial$install-components.adoc[]
+
****
Общие компоненты::
Обеспечивают взаимодействие с другими сервисами {dv}, обязательны для установки на сервер {dv} и сервер {wc}а.

Кнопка Сброс::
Сбрасывает выбор компонентов на стандартные.

Кнопка Использование диска::
Позволяет посмотреть свободное место на системных дисках.
****
+
. Примите условия лицензионного соглашения для продолжения установки и нажмите *Установить*.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Нажмите кнопку *Готово*, чтобы закрыть мастер установки.
