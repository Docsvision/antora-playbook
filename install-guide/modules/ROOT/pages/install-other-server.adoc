= Установка серверной части других модулей

Данный раздел описывает основной алгоритм установки модулей.

.Базовый сценарий установки серверной части модулей:
. Запустите пакет установки серверной части модуля.
. На странице приветствия нажмите *Далее* и примите условия лицензионного соглашения, чтобы продолжить установку.
. Модуль может включать дополнительные компонентыfootnote:[Описание дополнительных компонентов приведено в соответствующем руководстве по установке каждого модуля.]. В таком случае на следующем шаге будет предложено выбрать устанавливаемые компоненты.
+
.Выбор устанавливаемых компонентов для модуля "Платформа"
image::new-admin-console@installguide:ROOT:install-components.png[Выбор устанавливаемых компонентов для модуля "Платформа"]
+
. Нажмите кнопку *Установить* и дождитесь завершения установки модуля.
. На следующем шаге нажмите кнопку *Готово*, чтобы закрыть мастер установки.
. Повторите пункты выше для каждого модуля.
. Если модуль устанавливается последним, запустите {mc} и выполните настройку системы следуя инструкции, данной в пунктах "xref:./config-master.adoc[]" и "xref:./post-config-server.adoc[]".
