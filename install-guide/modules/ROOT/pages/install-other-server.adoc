= {what} базовых модулей и регистрация сервисов на сервере под управлением Windows

Данный раздел описывает основной алгоритм установки модулей системы {dv}.

.Базовый сценарий установки серверной части модулей:
. Запустите пакеты установки серверной части:
+
* `{dv} web-client.msi`
* `{dv} Workflow server.msi`
* `{dv} DocumentManagement server.msi`
* `{dv} TakeOffice server.msi`
* `{dv} BackOffice server.msi`
* `{dv} ApprovalDesigner server.msi`
* `{dv} WindowsClient server.msi`
+
. На странице приветствия нажмите *Далее* и примите условия лицензионного соглашения, чтобы продолжить установку.
. Модуль может включать дополнительные компоненты. В таком случае на следующем шаге будет предложено выбрать устанавливаемые компоненты.
+
.Выбор устанавливаемых компонентов для модуля "{wf}"
image::6.1@workflow:admin:install-server-components.png[Выбор устанавливаемых компонентов для модуля "{wf}"]
+
include::6.1@platform:admin:partial$install-components.adoc[]
+
Описание дополнительных компонентов приведено в соответствующем руководстве по установке каждого модуля, например в разделе "xref:workflow:admin:install.adoc[]" для модуля {wf}.
+
. Нажмите кнопку *Установить* и дождитесь завершения установки модуля.
. На следующем шаге нажмите кнопку *Готово*, чтобы закрыть мастер установки.
. Повторите пункты выше для каждого модуля.
. Если модуль устанавливается последним, запустите {mc} и выполните настройку системы следуя инструкции, данной в пунктах "xref:./config-master.adoc[]" и "xref:./post-config-server.adoc[]".
