= Установка пакета утилит {rk} и {wc} Toolkit

Если планируется использовать {cns}, Полнотекстовый поиск, {kvr} и DVWebTool необходимо установить пакет утилит {rk} и {wc} Toolkit на клиентскую машину с {wincl}ом.

{cns} входит в инсталлятор `ResourceKit.msi`.

Пакет утилит {rk} содержит системные утилиты для специалистов системы, включая программу {cns}. "xref:6.1@resource-kit:console:db-settings.adoc[Базы данных]" (в сокращённом виде), "xref:6.1@resource-kit:console:section-transformations-generator.adoc[Генератор преобразований]", "xref:6.1@resource-kit:console:security-report.adoc[Отчёт по безопасности]", "xref:6.1@resource-kit:console:folder-rights.adoc[Права папок]", "xref:6.1@resource-kit:console:folder-views.adoc[Представления папок]", "xref:6.1@resource-kit:console:full-text-service.adoc[Сервис полнотекстового поиска]"
