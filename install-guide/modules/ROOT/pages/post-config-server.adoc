== Отключите клиентское кэширование

Рекомендуется отключить кэширование карточек и файлов на компьютере с сервером {dv}, для избежания переполнения клиентского кэша из-за работы СУБП, следствием чего может стать замедление обработки БП. Настройка выполняется в секции "Site" конфигурационного файла {wincl}а по адресу `/usr/lib/docsvision/platform/config/windows-client-part.json`.
