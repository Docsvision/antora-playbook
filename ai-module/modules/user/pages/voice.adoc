= Создание задания голосовым вводом

Функция предназначена для автоматического создания задания вида _На исполнение_ и заполнения его полей на основе продиктованного пользователем текста. Для использования функции требуется соединение по протоколу HTTPS.

Чтобы воспользоваться функцией необходимо нажать на кнопку *Начать голосовой ввод* image:admin:buttons/mic.png[Микрофон] на Главной странице {wc}а.

WARNING: Для возможности записи звука потребуется предоставить браузеру доступ к микрофону, во всплывающем окне.

Далее необходимо продиктовать текст поручения, фамилию и имя исполнителя, срок (допустимы значения "сегодня", "завтра" и прочее) и при необходимости фамилию и имя контролера.
Для завершения записи необходимо нажать на кнопку *Создать задание* image:buttons/check.png[Галочка], для отмены записи необходимо нажать на кнопку *Отменить* image:buttons/no-check.png[Крестик].

После завершения записи запустится процесс создания задания, по завершению которого откроется карточка задания в режиме просмотра с заполненными полями _Исполнители_, _Контролер_, _Срок исполнения_, _Примечание_. Данные в задании при необходимости можно скорректировать и отправить или отменить отправку.
