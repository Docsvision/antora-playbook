= Сгенерировать текст

Функция предназначена для автоматического создания текста на основе заданных параметров, введённых пользователем данных и/или информации из карточки и прикреплённых файлов. Может использоваться для подготовки сопроводительных материалов, писем, аннотаций и резолюций.

Чтобы воспользоваться функцией необходимо нажать на кнопку *Генерация текста* в карточке. Откроется окно с параметрами генерации текста.

.Параметры генерации
image::generation-parameters.png[Параметры генерации]

.Параметры генерации:
* Тип текста -- определяет назначение и формат создаваемого текста:
* Содержание -- краткое описание или аннотация к текущему документу.
* Письмо -- текст официального или делового письма.
* Деловая переписка -- текст для внутренней или внешней деловой переписки.
* Резолюция -- решение или указание по результатам рассмотрения документа.
* Тональность текста -- задаёт стиль и эмоциональную окраску:
* Официальная -- строгий, формальный стиль.
* Деловая -- нейтральный, профессиональный стиль.
* Разговорная -- неформальный стиль, приближённый к устной речи.
* Получатель (опционально) -- определяет целевую аудиторию текста:
* Сотрудник -- текст, адресованный коллеге или подчинённому.
* Руководитель -- текст для непосредственного руководителя.
* Контрагент -- текст для внешнего партнёра (поставщика, подрядчика и др.).
* Количество предложений (опционально) -- позволяет ограничить объём текста.
* Детали для письма -- текстовое поле для ввода ключевых деталей, которые необходимы для генерации текста.
* Добавить значения полей карточки (опционально) -- включает в генерацию информацию из текущей карточки документа.
* Извлекать текст из приложенных файлов (опционально) -- позволяет использовать содержание вложенных файлов при формировании текста.

После заполнения параметров нажмите кнопку *Отправить запрос*. Результат появится в области _Сгенерированный текст_, далее его можно скопировать вручную или по кнопке image:buttons/copy.png[Копировать].
