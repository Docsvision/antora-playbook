= Извлечение атрибутов во входящих

Функция предназначена для распознавания текста их файла входящего документа и автоматического заполнения полей карточки вида _Входящие документы_.

.Чтобы воспользоваться функцией
. Нажмите на кнопку *Извлечь атрибуты* в карточке Входящего документа.
. По завершению обработки запроса в карточке заполнятся поля _Тема_, _Номер отправителя_, _Дата отправки_, _Организация-отправитель_, _Примечание_, если эта информации будет найдена в самом файле.

NOTE: Поиск организации-отправителя осуществляется по справочнику контрагентов по свойствам _ИНН_ или _Название_.
