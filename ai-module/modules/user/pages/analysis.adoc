= Анализ документа

Функция позволяет проанализировать содержимое прикреплённого документа с помощью искусственного интеллекта по определенным профилям анализа:

*	Юридический -- выявление юридических рисков, несоответствий законодательству и проблемных формулировок.
*	Финансовый -- анализ финансовых показателей, условий и расчетов.
*	Информационной безопасности -- выявление рисков утечки информации и нарушений требований ИБ.
*	Пользовательский -- гибкая настройка под конкретные задачи пользователя.

.Чтобы использовать функцию:
. Откройте карточку документа и перейдите в секцию с прикреплёнными файлами.
. В раскрывающемся списке действий в выбранном файле выберите пункт *_Анализ_*.
. Во всплывающем меню _Анализ документа_ выберите необходимый профиль анализа или введите свой профиль.
+
.Выбор профиля для анализа
image::select-profile.png[Выбор профиля для анализа]
+
. После обработки файла искусственным интеллектом, откроется форма с результатом анализа.
+
.Пример работы функции "Анализ документа"
image::analysis-result.png[Пример работы функции "Анализ документа"]

.В правой части окна доступны кнопки взаимодействия с текстом:
// tag::commands[]
. *Скопировать* -- копирование сгенерированного текста.
.	*Сохранить и добавить в карточку как docx* -- сохранение сгенерированного текста в формате `.docx` и автоматическое добавление файла в карточку.
. *Скачать* -- скачивание анализа в формате `.docx`.
. *Сгенерировать повторно* -- запуск формирования анализа заново.
. *Озвучить* -- озвучить сгенерированный текст.
// tag::feedback[]
. *Лайк*/*Дизлайк* -- кнопки для отправки xref:feedback.adoc[обратной связи] о качестве сгенерированного текста.
// end::feedback[]
// end::commands[]
