= Обратная связь

Функция позволяет оценить качество работы ИИ-функций и отправить разработчикам замечания для улучшения работы.

.Использование функции:
* В правой части окна с результатом с результатом работы ИИ нажмите кнопку *Лайк* (если результат устраивает) или *Дизлайк* (если есть замечания).
* При нажатии на *Дизлайк* открывается форма обратной связи:
+
.Форма обратной связи
image::feedback.png[Форма обратной связи]
+
** В форме необходимо выбрать один из предложенных параметров: *Неправильно*, *Неполно*, *Стиль или тон*, *Другое*.
** Если выбран параметр *Другое*, будет предложено заполнить поле _Подробности_.
** При нажатии на кнопку *Отправить*, ваш отзыв будет отправлен разработчикам.
* При нажатии на *Лайк* -- положительный отзыв будет отправлен разработчикам.
* При повторном нажатии на *Лайк* или *Дизлайк* оценка и отправленный отзыв будут удалены.
