= Улучшить текст

Функция предназначена для автоматического исправления орфографических и пунктуационных ошибок в тексте с использованием возможностей искусственного интеллекта. Доступна в текстовых полях, где отображается соответствующая кнопка image:buttons/magic.png[Магия].

.Использование функции:
* Введите или вставьте текст в текстовое поле.
* Нажмите кнопку image:buttons/magic.png[Магия] рядом с полем.
* Откроется всплывающее окно _Сравнение текста_, содержащее две текстовые области, значения вкоторых можно редактировать:
** Левая область -- исходный текст.
** Правая область -- улучшенный текст.
* Под текстовыми областями доступны кнопки управления:
** *Принять исходный* -- заполняет текстовое поле исходным текстом.
** *Принять исправленный* -- заполняет текстовое поле улучшенным текстом.
** *Сгенерировать повторно* -- по кнопке image:buttons/circle-arrows.png[Магия] повторно выполняет обработку текста (при необходимости).
* После выбора одного из вариантов, текст будет автоматически подставлен в текстовое поле, из которого была вызвана функция.
