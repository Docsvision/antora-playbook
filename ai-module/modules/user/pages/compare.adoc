= Сравнение файлов

Функция позволяет сравнить содержимое прикреплённых документов с помощью искусственного интеллекта.

.Чтобы использовать функцию:
. Откройте карточку документа и перейдите в секцию с прикреплёнными файлами.
. В раскрывающемся списке действий в выбранном файле выберите пункт _Сравнить_.
. Откроется всплывающее окно с выбором файла для сравнения.
+
.Окно выбора файла для сравнения
image::compare-files.png[Окно выбора файла для сравнения]
+
. Выберите файл и нажмите *Сравнить*.
. После обработки анализа ИИ откроется форма с содержимым сравнения.
+
.Пример работы функции "Сравнить"
image::comparison.png[Пример работы функции "Сравнить"]

В правой части окна отображён цветной "Индикатор", обозначающий статус различий в файлах:

* Зелёный -- в сравниваемых документах нет различий, либо они не относятся к значимым.
* Красный -- в сравниваемых документах есть существенные различия в содержании или оформлении.

.Также в правой части окна доступны кнопки взаимодействия с текстом:
* Скопировать -- image:buttons/copy.png[] копирование сгенерированного текста.
* Скачать -- image:buttons/download.png[] скачивание сравнения в формате `.docx`.
* Сгенерировать повторно -- image:buttons/regen.png[] запуск формирования сравнения заново.
* Озвучить -- image:buttons/aloud.png[] озвучить сгенерированный пересказ.

WARNING: Функция будет доступна только если в карточке приложено более одного файла.
