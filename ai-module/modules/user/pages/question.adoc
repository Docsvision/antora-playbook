= Вопрос по файлу

Функция позволяет получить ответ на конкретный вопрос по содержимому прикреплённого документа с помощью искусственного интеллекта. Может использоваться для быстрого извлечения информации без необходимости вручную изучать весь текст файла.

.Чтобы воспользоваться функцией:
* Откройте карточку документа и перейдите в секцию с прикреплёнными файлами.
* В выпадающем списке действий в выбранном файле нажмите пункт «Задать вопрос».
* Откроется всплывающее окно с полем для ввода вопроса.
* Введите интересующий вопрос, относящийся к содержанию выбранного документа, и подтвердите отправку.
* После обработки вопроса AI, ответ отобразится в той же форме.

Если в документе отсутствует информация, достаточная для ответа, выводится сообщение:
