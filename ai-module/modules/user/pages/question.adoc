= Вопрос по файлу

Функция позволяет получить ответ на конкретный вопрос по содержимому прикреплённого документа с помощью искусственного интеллекта. Может использоваться для быстрого поиска информации по файлу без необходимости вручную изучать весь текст файла.

.Пример работы функции "Вопрос по файлу"
image::question.png[Пример работы функции "Вопрос по файлу"]

.Чтобы воспользоваться функцией:
. Откройте карточку документа и перейдите в секцию с прикреплёнными файлами.
. В раскрывающемся списке действий в выбранном файле нажмите пункт _Задать вопрос_.
. Откроется всплывающее окно с чатом для ввода вопросов.
. Введите интересующий вопрос, относящийся к содержанию выбранного файла, и подтвердите отправку.
. После обработки вопроса ИИ, ответы будут отображаться в той же форме.
. Контекст ответов ИИ сохраняется в рамках одного диалога.

Если в документе отсутствует информация, достаточная для ответа, выводится сообщение:
