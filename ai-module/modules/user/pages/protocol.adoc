= Создание протокола

Функция предназначена для автоматического создания файла протокола на основе медиафайла, добавленного пользователем в основные файлы карточки. Для обработки поддерживаются файлы форматов: `.mp3`, `.aac`, `.flac`, `.wav`, `.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.webm`, `.flv`, `.f4v`.

.Для генерации файла протокола доступны дополнительные параметры:
* Тайминг -- при установленном значении флага в протоколе будут отображены метки времени.
* Сложная форма -- при установленном значении флага сформированная печатная форма будет иметь определённую структуру, содержащую: _Повестку совещания_, _Принятые решения_, _Выданные поручения_ и _Ответственные исполнители_.

.Дополнительные параметры
image::add-parameters.png[Дополнительные параметры]

Чтобы воспользоваться функцией необходимо добавить аудио/видео файл и нажать на кнопку *Создать протокол* в карточке документа. Откроется окно с сообщением о начале создания протокола (для обработки больших файлов потребуется больше времени).

.Информационное сообщение
image::info-protocol.png[Информационное сообщение]

После завершения обработки в секцию _Основные файлы_ текущей карточки приложится печатная форма протокола в формате `.docx`, в секцию _Дополнительные файлы_ будут приложены файлы транскрипции (файлов транскрипции может быть несколько, в зависимости от объема медиафайла).
