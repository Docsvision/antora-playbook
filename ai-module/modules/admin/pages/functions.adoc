= Настройка функций модуля {ai}

== Исправить\озвучить текст

Для работы с функциями _Исправление текста_ и _Озвучка текста_ администратору необходимо добавить в разметку элемент управления `_Контейнер_` из группы _AI_, поместить в него элемент управления `_Текст_` и отметить эти функции в свойствах.

NOTE: Функции доступны для использования в любых карточках.

== Краткий пересказ, Вопрос по файлу, Анализ и Сравнение файлов

Функции _Краткий пересказ_, _Вопрос по файлу_, _Анализ_ и _Сравнение файлов_ добавляются в систему как пункты контекстного меню элемента управления `_Список файлов_`. Для работы функций необходимо добавить в разметку элемент управления `_Контейнер_` из группы _AI_ и поместить в него элемент управления `_Список файлов_`.

// tag::only-in[]
NOTE: Функциональность доступна для использования только в карточках типа _Документ_ и _Задание_. В заданиях функция доступна только для основных файлов.
// end::only-in[]

== Сгенерировать текст

Для работы функции  _Генерация текста_, нужно добавить в разметку элемент управления `_Кнопка генерации текста_`.

Дополнительно для функции может быть настроено автозаполнение поля сгенерированным текстом и настройки параметров генерации по умолчанию.

Для автозаполнения поля в карточке сгенерированным AI текстом, в настройках разметки, нужно записать в свойство `*Автозаполнять указанное поле*` название текстового ЭУ текущей карточки, которое требуется заполнить сгенерированным текстом.

.Для параметров генерации по умолчанию, в настройках ЭУ, доступны свойства:
* Добавить поля -- учитывать контекст полей карточки;
* Извлекать текст из файлов -- учитывать контекст текста из приложенных файлов.

NOTE: Функция доступна для использования в карточках типа _Документ_ и _Задание_.

== Извлечь атрибуты (для входящих)

Для работы функции "Извлечение атрибутов", нужно добавить в разметку входящих документов элемент управления `*Кнопка извлечения атрибутов (входящие)*`.
В конструкторе разметок у элемента доступны свойства `*ИНН*` и `*Организация*`, которые выполняют роль фильтра при определении атрибутов:

* При извлечении атрибутов происходит поиск всех возможных значений атрибута _Организация-отправитель_ во входящем файле.
* Если в полученных данных есть соответствия значениям из свойств `*ИНН*` и `*Организация*`, они игнорируются.

.Пример заполнения данных
image::attributes.png[Пример заполнения данных]

[WARNING]
====
Функция работает корректно только в документах вида _ДокументУД / Входящий_.
Для заполнения используются поля `documentName`, `senderRegNumber`, `senderDate`, `senderDepartment`, `description`.
====

== Создать протокол

Для работы функции "Создание протокола", нужно добавить в разметку протокола элемент управления `_Кнопка создания протокола_` и два элемента управления типа `_Флажок_` с названиями `timing` и `complexForm`.

WARNING: Данная функция доступна для демонстрации и требует использования специализированных ЭУ и шаблонов файлов. При необходимости обратитесь в техническую поддержку.

== Создать задание голосовым вводом

Чтобы иметь возможность создавать задания "На исполнение" с помощью голосового ввода, необходимо в конструкторе разметок добавить ЭУ `_Кнопка создания задания голосовым вводом_` в корневой блок (`Root`) разметки menu:WebFrame[Главная страница]. Кнопка имеет свойства для изменения CSS классов иконок начала, отмены записи и создания задания. На главной странице {wc}а в правом нижнем углу появится кнопка-иконка image:buttons/mic.png[Микрофон].

WARNING: Для использования функции требуется соединение по протоколу HTTPS.

== Информация о тарифах

Для возможности просмотра информации о текущем тарифе необходимо в конструкторе разметок (menu:WebFrame[Диалог профиля пользователя]) добавить еще одну вкладку и поместить в неё ЭУ `_Подписка_`.

== Обратная связь

Все оценки (лакйки/дизлайки) и комментарии пользователей сохраняются в базе данных в таблице `AiFunctionsFeedback`.

.Структура таблицы:
[cols=",,",options="header"]
|===
|Поле	|Тип данных	|Описание

|FeedbackID	|UNIQUEIDENTIFIER	|Уникальный идентификатор записи
|EmployeeID	|UNIQUEIDENTIFIER	|Идентификатор сотрудника, оставившего оценку
|EmployeeName	|NVARCHAR(100)	|Имя сотрудника
|FeedbackDateTime	|DATETIME	|Дата и время отправки отзыва
|RequestAlias	|NVARCHAR(100)	|Алиас запроса (название промпта)
|Comment	|NVARCHAR(MAX)	|Текст комментария
|IsLike	|BIT	a|Тип оценки: `1` -- Лайк, `0` -- Дизлайк

Пример запроса для просмотра оценок:

 SELECT * FROM AiFunctionsFeedback ORDER BY FeedbackDateTime DESC

|===
