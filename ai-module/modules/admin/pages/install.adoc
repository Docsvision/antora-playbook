= Установка модуля {ai}

. Распакуйте архив `AiExtension.zip` модуля в папку `%Каталог установки {wc}а%\`.
+
NOTE: Информация о загруженных клиентских расширениях отображается в {wc}е в окне "О программе".
+
. Содержимое архива будет распаковано в следующие каталоги:
+
* `AiServerExtension` -- `каталог-установки-{wc}а\Content\Extensions`
* `AiWebExtension` -- `каталог-установки-{wc}а\Content\Modules`
* `AiDesignerExtension` -- `каталог-установки-{wc}а\Plugins`
* `ai.config` -- `каталог-установки-{wc}а\Site`
+
. После распаковки элементов модуля по вышеуказанным путям необходимо выполнить настройки в конфигурационном файле `ai.config`. Все узлы, кроме `AiApiKeyECM`, заполнены по умолчанию. В конфигурационном файле содержится следующая информация:
+
* `AiProvider` -- наименование провайдера, содержащего логику взаимодействия с ИИ-сервисом. В данный момент доступно только одно значение: `EcmAiService`.
* `AiApiKeyECM` -- API-ключ для ИИ-сервиса ECM. Выдается по запросу в `sales@docsvision.com`
* `AiAddressECM` -- адрес подключения к ИИ-сервису ECM.
* `AiServiceECM` -- настройка ИИ-модели. В текущей редакции модуля для обработки запросов могут использоваться только последние модели ChatGPT (используется по умолчанию), DeepSeek, YandexGPT_Pro и Yandex_qwen.
+
WARNING: В случае, если не будет указан AiApiKeyECM, при вызове функций появится сообщение об ошибке:
+
.Предупреждение об отсутствии ключа AiApiKeyECM
image::no-ecm-key.png[Предупреждение об отсутствии ключа AiApiKeyECM]
+
. Перезапустите службу модуля. Расширение программы {kvr} будет зарегистрировано, включая серверное и клиентское расширения.
. Новые элементы управления будут отображаться в библиотеке программы {kvr}, в группе AI.
