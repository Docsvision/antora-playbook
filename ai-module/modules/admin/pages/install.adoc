= Установка модуля "{ai}"

После установки файлы модуля будут распакованы в `Каталог установки {wc}а`. Информация о загруженных клиентских расширениях отображается в {wc}е в окне "О программе".

NOTE: Информация о загруженных клиентских расширениях отображается в {wc}е в окне "О программе".

.Содержимое модуля распаковывается в следующие каталоги:
* `AiServerExtension` -- `каталог-установки-{wc}а\Content\Extensions`
* `AiWebExtension` -- `каталог-установки-{wc}а\Content\Modules`
* `AiDesignerExtension` -- `каталог-установки-{wc}а\Plugins`
*	`AiExtension` --`каталог-установки-модуля-{pl}\Tools\Database`
*	`DocsVision.AI.API` -- `C:\Windows\Microsoft.NET\assembly\GAC_MSIL`
* `ai.config` -- `каталог-установки-{wc}а\Site`
+
// tag::next-to[]
.Конфигурационный файл должен находиться рядом с запускаемым приложением:
** {wc} -- компонент должен быть арспакован в `Каталог-установки-{wc}а\`
** Скрипты {wincl}а -- `каталог-установки-{dv}\Client`
** Серверное расширение {wincl}а -- `каталог-установки-модуля-{pl}\Site`
** Бизнес процессы -- `каталог-установки-модуля-{wf}\`
// end::next-to[]

. Запустите пакет установки `{dv} AI.msi` и проследуйсте инструкциям мастера установки.
. В приветственном окне мастера установки нажмите *Далее*.
+
.Мастер установки модуля "{tw}"
image::install-server-hello.png[Мастер установки модуля "{tw}"]
+
. Примите условия лицензионного соглашения для продолжения установки и нажмите *Установить*.
+
.Условия лицензионного соглашения
image::install-server-license.png[Условия лицензионного соглашения]
+
. Выберите компоненты, которые требуется установить, и нажмите *Далее*.
+
.Выбор устанавливаемых компонентов
image::install-server-components.png[Выбор устанавливаемых компонентов]
+

Общие компоненты::
Обеспечивают взаимодействие с другими сервисами {dv}, обязательны для установки на сервер сервер {wc}а.

[#settings]
== Настройка модуля после установки

. Обновите БД согласно инструкции "xref:6.2@mgmtconsole:servers:db-update.adoc[]" и перезапустите {sss-new}.
. Новые элементы управления будут отображаться в библиотеке программы {kvr}, в группе AI, см. подробнее в разделе "xref:post-config.adoc[]".
. Выполните настройки в конфигурационном файле `ai.config`. Все узлы файла, кроме `AiApiKeyECM`, заполнены по умолчанию. В конфигурационном файле содержится следующая информация:
+
* `AiProvider` -- наименование провайдера, содержащего логику взаимодействия с ИИ-сервисом:
+
* _ChatGPT_ (используется по умолчанию)
* _DeepSeek_
* _Yandex_qwen_
+
* `AiApiKeyECM` -- API-ключ для ИИ-сервиса ECM. Выдается по запросу в `sales@docsvision.com`.
+
WARNING: Если AiApiKeyECM не указан, при вызове функций появится сообщение об ошибке:
+
.Предупреждение об отсутствии ключа AiApiKeyECM
image::no-ecm-key.png[Предупреждение об отсутствии ключа AiApiKeyECM]
+
* `AiAddressECM` -- адрес подключения к ИИ-сервису ECM.
* `AiServiceECM` -- настройка ИИ-модели. В текущей редакции модуля для обработки запросов могут использоваться только последние модели ChatGPT (используется по умолчанию), DeepSeek, Yandex_qwen.
