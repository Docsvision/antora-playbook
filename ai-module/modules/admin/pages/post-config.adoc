= Настройка модуля {ai}

При установке модуля {ai} в систему {dv}, в программе {kvr} будет добавлена новая группа _AI_. включающая элементы управления: `_Кнопка генерации текста_` и `_Контейнер_`.

Данные элементы управления позволяют реализовать функции: _Исправить текст_, _Анализ файла_, _Краткий пересказ_ и _Генерация текста_. Подробное описание приведено в разделе "xref:5.5.17@webclient:layouts:important.adoc[Работа с программой {kvr}]".

.Группа "AI"
image::group.png[Группа "AI"]

.Администратор системы может:
* Добавлять и удалять элементы управления модуля {ai} в разметки карточек.
* Настраивать конфигурационный файл `ai.config`.
+
WARNING: После редактирования конфигурационного файла необходим перезапуск IIS.
+
* Отслеживать использование тарифа (доступно для всех в профиле пользователя).

.Чтобы добавить элементы управления модуля {ai} в разметку необходимо:
. В программе {kvr} перейдите к карточкам BackOffice.
+
В текущей редакции модуля присутствуют ограничения на использование элементов управления группы _AI_ в карточках. Подробнее см. в разделе "xref:functions.adoc[]".
+
. Выберите нужный вид карточки и откройте разметку, для которой требуется добавить новую функцию.
. В библиотеке элементов управления выберите новый элемент управления и добавьте его в структуру карточки.
. Закройте {kvr}, сохранив изменения.
